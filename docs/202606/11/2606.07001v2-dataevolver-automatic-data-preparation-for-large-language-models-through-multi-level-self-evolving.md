## 摘要
高质量的训练数据对大型语言模型（LLM）至关重要，通常需要大量昂贵的人工整理。现有的自动数据准备方法依赖预定义的流水线或定制的人类指令，这限制了它们对不同数据分布的适应性，并且缺乏来自高质量示例的原则性指导。在本文中，我们介绍了DataEvolver，这是第一个自我演进的数据准备系统，能够自动构建流水线，将原始数据转化为高质量数据。DataEvolver采用多级机制来确保流水线的可执行性和有效性。在操作符级别，它逐步扩展操作符集合以构建逻辑计划，同时解决依赖冲突。在流水线级别，它将逻辑计划实例化为可执行代码，并通过反馈循环迭代优化流水线编排，以减少准备数据与高质量示例之间的分布差距。在七个基准上的实验表明，与在原始数据上训练相比，DataEvolver显著提高了数据质量，并使下游LLM性能平均提升10%，凸显了LLM与数据迭代共同进化的新机遇。

## Abstract
High-quality training data is essential to large language models (LLMs) and typically requires extensive and costly manual curation. Existing automatic data preparation methods rely on predefined pipelines or customized human instructions, which limits their adaptability to diverse data distributions and lacks principled guidance from high-quality examples. In this paper, we introduce DataEvolver, the first self-evolving data preparation system that automatically constructs pipelines to transform raw data into high-quality data. DataEvolver employs a multi-level mechanism to ensure both pipeline executability and effectiveness. At the operator level, it incrementally expands the operator set to construct a logical plan while resolving dependency conflicts. At the pipeline level, it instantiates logical plans into executable code and iteratively refines pipeline orchestration through a feedback loop that reduces the distribution gap between prepared data and high-quality examples. Experiments on seven benchmarks show that DataEvolver substantially improves data quality and achieves an average 10\% gain in downstream LLM performance compared with training on original data, highlighting new opportunities for the iterative co-evolution of LLMs and data.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：采用**多级自我演进**（Multi-Level Self-Evolving）框架：操作符级自我演进确保逻辑可执行性，流水线级自我演进确保数据准备有效性。给定原始数据、少量高质量种子数据（Seed Data）和可选的任务描述，系统自动构建最优数据准备流水线。
- **关键技术细节**：
  - **种子引导的数据理解（Seed-Guided Data Understanding）**：从种子数据 S 中抽取结构化数据画像 C，包括目标输出模式、格式约定、质量约束、难度偏好等。画像 C 随经验记忆 M 更新。
  - **操作符级自我演进（Operator-Level Self-Evolving）**：将流水线建模为有向无环图（DAG），节点来自操作符库 O。通过检查依赖缺失、接口不兼容、结构缺陷等，自动修复（插入桥接操作符、替换、重排序、重新布线）。当现有操作符不足时，生成新操作符并入库。迭代直至得到可执行的逻辑计划 G。
    - 演进函数：\( G^{(t+1)}, O^{(t+1)} = f_{\text{op-evolving}}(G^{(t)}, O^{(t)}, C) \)
  - **流水线级自我演进（Pipeline-Level Self-Evolving）**：将逻辑计划实例化为可执行代码（含参数 Θ），先在数据子集 D_s 上试运行，将输出 D'_s 与种子数据 S 比较，生成差异信号并转化为演进经验，存入经验记忆 M。更新后的 M 重新指导数据理解，重复操作符级与流水线级演进，直到试运行输出满足质量要求。
    - 演进函数：\( M^{(t+1)} = f_{\text{pipe-evolving}}(M^{(t)}, \text{Exp}) \)，其中 Exp = \( f_{\text{judge}}(P^{(t)}(D_s), S) \)
- **算法流程**（文字说明）：
  1. 输入原始数据、种子数据、可选描述 → 种子引导数据理解，生成数据画像 C。
  2. 操作符级自我演进：基于 C 和操作符库生成初始 DAG 逻辑计划，检查并修复可执行性问题，必要时合成新操作符 → 得到可执行的逻辑计划 G*。
  3. 流水线级自我演进：将 G* 实例化为具体代码，在子集上试运行，与种子数据比对，提炼经验反馈。
  4. 根据经验更新数据理解和操作符与流水线，重复步骤 2-3 直至满足质量。
  5. 将最终流水线应用于完整原始数据，生成高质量数据用于 LLM 训练。

- DataEvolver 能够自主合成缺失的操作符，增强系统对新领域的适应性。
