## 摘要
现有的信息抽取任务越来越多地采用大型语言模型的上下文学习。然而，当前的方法要么在不同模型规模上表现不一致，要么缺乏系统优化和泛化能力。在此基础上，我们提出了BCL（面向信息抽取的贝叶斯上下文学习框架），这是第一个使用粒子滤波和贝叶斯更新来系统优化信息抽取任务中标签表示的优化框架。通过四个步骤：初始化、观测、权重更新和重采样，BCL可推广到序列标注和关系分类两种范式。大量实验表明，与现有方法相比，BCL取得了显著且一致的改进。

## Abstract
Existing information extraction (IE) tasks increasingly adopt in-context learning (ICL) with large language models. However, current approaches either show inconsistent performance across model scales or lack systematic optimization and generalizability. Building on this, we propose BCL (Bayesian In-Context Learning Framework for Information Extraction), the first optimization framework that uses particle filtering with Bayesian updates to systematically refine label representations across IE tasks. Through four steps initialization, observation, weight update, and resampling, BCL generalizes to both sequence labeling and relation classification paradigms. Extensive experiments demonstrate substantial and consistent improvements over existing approaches.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
- 将粗粒度标签（如“人物”）分解为多个语义离散的子类别原子（如“运动员”“公众人物”），每个子类别作为一条规则（rule/particle）。
- 将规则视为可控的离散变量，通过粒子滤波（particle filtering）结合贝叶斯更新，迭代优化规则分布，最终选择最优规则集合用于ICL推理。

### 关键技术细节与算法流程（四步）
1. **初始化（State Initialization & Rule Extraction）**  
   - 从训练数据中，使用LLM为每个标签提取初始子类别规则（粒子）。  
   - 使用困惑度（perplexity）计算每个粒子的先验权重，越低的困惑度意味着越高的先验概率。

2. **观测（System Observation: Evaluation）**  
   - 对每个粒子，通过在验证批次上执行基于ICL的IE进行似然评价。  
   - 计算条件对数概率（式12），经softmax得到归一化置信度得分 \( y_i^{(t)} \)。

3. **权重更新（System Estimation: Weight Update）**  
   - 采用贝叶斯后验更新：\( \tilde{w}_i^{(t)} = w_i^{(t-1)} \cdot \exp(\beta \cdot y_i^{(t)}) \)，然后归一化。  
   - 结合先验与观测似然，自适应调整粒子权重。

4. **重采样（Control Action: Resampling）**  
   - **第一层（性能选择）**：保留前50%权重的粒子，删除低质量粒子。  
   - **第二层（多样性突变）**：对保留粒子使用LLM进行语义突变（细化、泛化、上下文化），生成新粒子，并基于困惑度赋初始权重。  
   - 合并保留粒子和新粒子进入下一轮迭代。  
   - 终止条件：3次连续迭代相对改进小于3%，或训练数据用完。
