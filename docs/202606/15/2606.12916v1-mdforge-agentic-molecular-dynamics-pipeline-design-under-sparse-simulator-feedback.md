## 摘要
分子动力学（MD）是原子尺度分子科学中经典的计算模拟方法，通过第一性原理物理模拟分子行为。为新型系统设计MD流水线需要大量专家知识：即使在单个分子上运行也成本高昂，排除了试错法。我们利用大语言模型（LLM）智能体来自动化这一专家流水线设计过程。与现有编排预定义工具集的MD智能体不同，我们将流水线设计视为开放式代码生成，智能体的行为通过语言奖励在线重塑。具体而言，我们构建了MDForge——一个LLM智能体，其上下文更新规则通过物理专家之间的多智能体辩论来稀疏化奖励。在三个SAMPL主客体结合自由能基准测试上，MDForge自动设计的MD流水线与人类专家水平相当。在未见候选客体库上部署时，其CB[7]流水线发现了一种新型结合物，湿法竞争核磁共振实验证实其为高亲和力、皮摩尔级别的CB[7]结合物。我们的数据和代码可在https://github.com/Zehong-Wang/MDForge获取。

## Abstract
Molecular dynamics (MD) is the canonical in-silico method for atomistic molecular science, simulating molecular behavior from first-principle physics. Designing an MD pipeline for a new system requires substantial expert knowledge: running it on even one molecule is expensive, ruling out trial-and-error. We automate this expert pipeline-design process with an LLM agent. Unlike existing MD agents that orchestrate a predefined tool set, we treat pipeline design as open-ended code generation in which the agent's behavior is reshaped online by verbal reward. Specifically, we build MDForge, an LLM agent whose in-context update rule densifies the sparse reward via a multi-agent debate among physics experts. On three SAMPL host-guest binding free-energy benchmarks, MDForge automatically designs MD pipelines competitive with human experts. Deployed on a library of unseen candidate guests, its CB[7] pipeline discovers a novel binder that wet-lab competition NMR confirms is a high-affinity, picomolar CB[7] binder. Our data and code are available at https://github.com/Zehong-Wang/MDForge.

## 2. 论文提出的方法论

### 核心思想
- 将MD流水线设计重构为**开放式代码生成**任务，智能体通过**语言强化学习（Verbal RL）** 在线更新行为。每个流水线被写为可执行Python代码，而不是从固定工具箱中选择。
- 面对稀疏且昂贵的奖励（每轮只有一次终端奖励），提出**PRISM（Process-Reward Interpretation via Subsystem Mediation）** 机制将稀疏奖励稠密化：利用MD流水线固有的多阶段结构提取每阶段诊断，并通过多名物理专家（力场、采样、分析）的多智能体辩论生成带类型和子系统归属的批评。

### 关键技术细节
- **POMDP建模**：将设计循环建模为部分可观测马尔可夫决策过程（POMDP）。状态S为设计历史（已尝试的流水线和阶段诊断），动作空间A为开放式程序空间（生成四阶段流水线：准备、平衡、生产采样、分析），观测O为模拟器输出的自然语言文档，奖励R仅在生产运行结束后实现（单标量r* = -平均绝对误差MAE）。
- **Verbal RL更新**：上下文Ct包含任务描述T、当前流水线πt、批评集Kt、历史摘要Ht。通过LLM调用πt+1 ~ LLMθ(·|Ct+1)，Ct+1通过PRISM生成的批评更新。
- **PRISM的具体实现**：
  - **阶段诊断Dπ**：四个阶段（Prep, Equilib, Prod, Analysis）各提取结构化物理诊断（如Prep阶段力场自洽性，Prod阶段遍历性和PME精度，Analysis阶段自由能收敛性）。
  - **多专家辩论**：J=3名专家（力场专家、采样专家、分析专家），各有固定管辖范围。进行两轮辩论：第一轮独立给出意见，第二轮交叉可见后修订。通过声誉加权聚合器Aρ将专家意见合并为单一类型批评（子系统+具体行动），声誉ρ根据预执行与后执行的一致性动态更新。
  - **预执行与后执行调用**：在流水线运行前（便宜筛查）和运行后（基于执行结果）各调用一次专家面板。
  - **代码智能体通过上下文束Ct更新**：生成新流水线时，可优先局部编辑上一流水线，而非完全重写。

### 算法流程（文字说明）
1. 任务初始化：专家面板进行一次设计讨论（带网络搜索），聚合推荐种子初始流水线π0。
2. 在每次试验中：

   - 预执行PRISM面板给出c_pre（建议性）。
   - 工程师运行流水线，提取四阶段诊断Dπt。

## 3. 实验设计

### 数据集/场景
- **基准**：SAMPL宿主-客体结合自由能挑战（广泛使用的MD基准，作为蛋白质-配体结合问题的可处理代理）。
- **三个宿主**：CB[7]（SAMPL4）、OAH（SAMPL4）、CBClip（SAMPL5），各宿主化学性质不同。每个宿主有多个客体分子（CB[7]: 14个，OAH: 9个，CBClip: 10个）。每个宿主分4个训练客体（覆盖实验ΔG范围）和剩余作为测试集。
- **输入**：为每个客体提供对接姿势，实验ΔG不提供给agent。

### Benchmark与对比方法
- **形成能力阶梯的基线**，按反馈类型组织：
  1. **No feedback**：一次代码生成，无批评无执行信号。
  2. **LLM critic**（Madaan et al., 2023）：辅助LLM审查并重写草稿，但代码不执行。
  3. **Step-level feedback**（Yao et al., 2023）：推理过程中工具调用返回中间结果，允许部分恢复，但无跨试验记忆。
  4. **Trial-level feedback**（Shinn et al., 2023）：每完成试验的自然语言摘要条件化下一试验。
  5. **MDForge**（本文）：试验级反馈加PRISM（阶段诊断+多专家辩论）。
- **消融实验**：
  - w/o Multi-expert debate：移除专家辩论，仅用聚合器直接输出批评。
  - w/o Stage diagnostics：移除阶段诊断，仅从终端奖励生成批评。
- **评价指标**：R²、Spearman ρ、Kendall τ（基于秩的指标，以消除方法特定的力场偏移）。在训练集和测试集上分别报告。
- **额外分析**：有效性随轮数变化、成本随轮数变化、失败原因分析、案例研究——PRISM产生类型化管道编辑。

### 湿实验验证
- 将最佳CB[7]管道应用于10个未见候选客体（来自ChEMBL和DrugBank），排名top-1为Bromantane（Brom），进行竞争1H NMR实验，与已知皮摩尔参考（FMTA, Ka≈2×10^12 M^-1）共平衡，测量相对结合常数Krel=4.26，得到Brom的Ka≈8×10^12 M^-1（ΔG≈-17.6 kcal/mol）。

- **主要结论**：MDForge能够自主设计出与人类专家水平相当的MD流水线。在SAMPL CB[7]和CBClip上，其排名信号（Kendall τ）分别为0.56和0.47，是Trial-level基线（0.24和0.20）的两倍以上，达到了SAMPL5人类提交的性能水平。

- **湿实验发现**：MDForge设计的CB[7]管道在未见过库中预测出Bromantane为高亲和力结合物，经核磁共振验证Ka≈8×10^12 M^-1，属于皮摩尔级高亲和力层次。
- **与人类专家的对比**：MDForge的每阶段工具选择（GAFF2+AM1-BCC、APR伞形采样、MBAR）与人类专家pAPRika管道一致，仅在工程可靠性方面有微小修改（如MBAR重叠检查），而AI+非专家管道则选择了不同的方法族（z-PMF），且性能稍逊。

## 8. 不足与局限
