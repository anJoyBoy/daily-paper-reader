## 摘要
微调大型语言模型（LLMs）已成为现代优化的核心应用，使得预训练模型能够适应多样化的下游任务和特定领域数据。大规模微调中的一个主要障碍是反向传播的内存开销，它需要存储激活值、梯度和优化器状态。零阶（ZO）优化提供了一种内存高效的替代方案，但其性能对步长和平滑参数高度敏感，通常需要代价高昂的任务特定调参。无参数（PF）优化通过在没有问题相关常数先验知识的情况下自适应调整算法参数来解决这一问题。此外，大规模微调可以从几何感知的更新中受益，这些更新考虑了参数块的异质结构，可以通过利用线性最小化预言机（LMO）的方法进行建模。在这项工作中，我们研究了基于LMO的ZO优化的PF自适应，并提出了$\texttt{AdaNAGED}$，这是一种统一了无梯度训练、自适应调参和非欧几里得更新几何的方法。我们建立了收敛保证，并在$\texttt{OPT}-1.3\mathrm{B}$模型的大规模LLM微调任务上验证了该方法。

## Abstract
Fine-tuning large language models (LLMs) has become a central application of modern optimization, enabling pretrained models to adapt to diverse downstream tasks and domain-specific data. A major obstacle in large-scale fine-tuning is the memory overhead of backpropagation, which requires storing activations, gradients, and optimizer states. Zeroth-order (ZO) optimization offers a memory-efficient alternative, but its performance is highly sensitive to the stepsize and smoothing parameter, often requiring costly task-specific tuning. Parameter-free (PF) optimization addresses this issue by adapting algorithmic parameters without prior knowledge of problem-dependent constants. Moreover, large-scale fine-tuning can benefit from geometry-aware updates that account for the heterogeneous structure of parameter blocks, which can be modeled through methods that exploit linear minimization oracle (LMO). In this work, we study PF adaptation for LMO-based ZO optimization and introduce $\texttt{AdaNAGED}$, a method that unifies gradient-free training, adaptive tuning, and non-Euclidean update geometry. We establish convergence guarantees and validate the method on large-scale LLM fine-tuning task with $\texttt{OPT}-1.3\mathrm{B}$ model.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：通过沿优化轨迹的局部光滑度自适应估计，动态确定步长和平滑参数，避免对问题常数（如 Lipschitz 常数、初始距离）的依赖。更新方向通过线性最小化预言机（LMO）实现几何感知的更新。
- **关键技术细节**：
  - **局部光滑度估计**：
    \[
    L_t = \frac{\|g_t(x_{t+1}, e_t) - g_t(x_t, e_t)\|_*}{\|x_{t+1} - x_t\|}
    \]
    其中 \(g_t\) 是 ZO 梯度近似（使用同一随机方向 \(e_t\) 以保证稳定性），该估计利用两次点上的函数值差，仅需存储随机种子，保持内存高效。
  - **步长与平滑参数自适应**：
    - 步长：\(\gamma_t = \frac{\sqrt{f(x_0) - \tilde{f}}\,\rho}{\sqrt{S_{t-1}}}\)，其中 \(S_t = S_{t-1} + L_t\)，\(\tilde{f}\) 是目标下界（如 0），\(\rho\) 是 LMO 半径。
    - 平滑参数：\(\tau_t = \rho C_2 \gamma_t\)，保证估计一致有界（Lemma 1），其中 \(C_2\) 是范数等价因子。
  - **LMO 更新**：对于给定范数，\(v_t = \arg\min_{\|v\|\le\rho} \langle g_t, v\rangle\)。不同范数对应不同优化器：\(\ell_\infty\) 范数得到 Sign-SGD，谱范数得到 Muon。
  - **算法流程**（AdaNAGED，Algorithm 1）：
    1. 初始化 \(x_0\)，\(S_{-1}=\xi\)，\(\gamma_0,\tau_0\) 由公式设定。
    2. 每次迭代：采样随机方向 \(e_t\)；计算 ZO 梯度 \(g_t(x_t, e_t)\)；计算 LMO 方向 \(v_t\)；更新参数 \(x_{t+1} = x_t + \gamma_t v_t\)；在新点计算 ZO 梯度 \(g_t(x_{t+1}, e_t)\)；估计 \(L_t\)；更新 \(S_t\) 并计算新的 \(\gamma_{t+1},\tau_{t+1}\)。
  - **AdaMuGED**（Algorithm 2）：对矩阵参数使用谱范数 LMO（极分解），并利用牛顿-舒尔茨（Newton-Schulz）近似加速极分解，避免精确 SVD 的高成本。
- **理论保证**：在假设目标函数为凸、L-光滑、M-Lipschitz 的条件下，Theorem 1 和 2 给出了收敛到 \(\varepsilon\)-稳定点的迭代复杂度，渐近依赖 \(O(1/\varepsilon^2)\)，与最优 ZO 方法一致，并体现了参数自适应引入的额外因子。
