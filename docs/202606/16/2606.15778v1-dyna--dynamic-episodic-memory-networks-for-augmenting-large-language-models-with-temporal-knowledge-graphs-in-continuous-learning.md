## 摘要
大型语言模型（LLM）在吸收新知识时容易遗忘或需要昂贵的重新训练。我们提出DYNA，一种轻量级框架，通过一个时序知识图谱来增强冻结的LLM，其中事件作为节点，时序关系作为带时间戳的有向边。该图谱作为外部可更新记忆。查询时，DYNA通过随机游走和中心性度量检索相关节点，然后增强LLM的响应。在三个时序回忆任务上的评估表明，与微调相比，DYNA将灾难性遗忘降低了约7%，并在时序排序上比标准RAG提升了约5%。较高的图聚类系数与更好的检索性能相关，表明图结构的重要性。贡献：（1）将情景记忆作为时序知识图谱；（2）无需重新训练的LLM增强；（3）图属性作为检索性能的预测指标。

## Abstract
Large Language Models (LLMs) struggle to incorporate new knowledge without forgetting or costly retraining. We propose DYNA, a lightweight framework that augments a frozen LLM with a temporal knowledge graph where events are nodes and temporal relations are directed, timestamped edges. The graph serves as an external, updatable memory. At query time, DYNA retrieves relevant nodes via random walks and centrality measures, then augments the LLM's response. Evaluated on three temporal recall tasks, DYNA reduces catastrophic forgetting by ~7% compared to fine-tuning and improves temporal ordering by ~5% over standard RAG. Higher graph clustering coefficients correlate with better retrieval, showing that graph structure matters. Contributions: (1) episodic memory as temporal KG, (2) retraining-free LLM augmentation, (3) graph properties as predictors of retrieval performance.

## 1. 论文的核心问题与整体含义

- **研究动机**：大型语言模型（LLM）如 GPT、LLaMA 等在训练后难以高效地整合新知识。传统的微调会导致灾难性遗忘（catastrophic forgetting），而完全重新训练成本极高。检索增强生成（RAG）虽能引入外部信息，但将记忆视为非结构化文档，无法显式建模事件之间的时序关系（如先后、同时），因而在时序推理和事件排序任务中表现不佳。
- **整体含义**：本文旨在通过引入一个可动态更新的外部时序知识图谱作为情景记忆，使冻结的 LLM 在不修改参数、不重新训练的前提下，实现持续学习，并提升对事件时序关系的理解能力。这项工作融合了复杂网络科学、知识图谱、认知启发记忆系统与 LLM，为无需重训练的持续知识整合提供了一个轻量级实用框架。

## 2. 论文提出的方法论

- **核心思想**：构建一个时序知识图谱（temporal knowledge graph），将每个事件存储为节点，事件间的时序关系（before、after、co-occurs）表示为带时间戳的有向边。该图谱作为 LLM 的外部可更新记忆，LLM 本身保持冻结不变。
- **关键技术细节**：
  - **图谱构建**：事件节点存储文本描述；根据时间戳添加前继、后继、共现三种关系。边权重采用指数衰减函数：\(w(v_i, v_j) = \exp(-\lambda |t_i - t_j|)\)，其中 \(\lambda\) 为衰减超参数，控制时间敏感性。
  - **图更新与剪枝**：包括基于时间的剪枝（移除早于阈值 \(T_{max}\) 的节点）和基于度的剪枝（移除低连接度节点），以控制图规模。
  - **检索机制**：
    1. **种子节点选择**：用查询的关键词或嵌入匹配最相似的节点。
    2. **随机游走**：从种子节点出发，沿带权边进行多条随机游走，获取时序相邻事件。
    3. **中心性评分**：综合度中心性、接近中心性和游走访问频率，计算节点得分：\(\text{score}(v) = \alpha \cdot \deg(v) + \beta \cdot \text{closeness}(v) + \gamma \cdot \text{visit\_freq}(v)\)。
  - **查询增强与响应生成**：将检索到的事件（含时间戳）与原始查询拼接成增强提示，输入冻结的 LLM 生成回答。
- **算法流程**（文字说明）：
  1. 系统持续接收新事件，动态更新时序知识图谱（添加节点、边，并执行剪枝）；
  2. 收到查询后，进行关键词/语义匹配找到种子节点；
  3. 从种子节点执行多次随机游走，遍历图；
  4. 计算所有访问节点的综合得分，取 Top-K 作为检索结果；
  5. 将检索结果与查询组成增强提示，送入冻结 LLM 生成最终答案。

## 6. 论文的主要结论与发现

- DYNA 在时序推理任务上取得 **TOA 71.42%**，比最强基线 DynaGen（68.14%）高 **3.28 个百分点**，同时遗忘率仅 **1.70%**，远低于微调的 34.81%。

- 在短序列和稀疏图场景下 DYNA 优势不明显，隐含推理任务中提升有限。

## 7. 优点

- **无需重训练**：冻结 LLM，仅更新外部知识图谱，避免灾难性遗忘，计算开销低。
- **显式时序建模**：将时序关系编码为有向边，优于非结构化 RAG。
- **轻量检索**：使用随机游走和简单中心性度量，线性复杂度，适合长期部署。
- **认知启发性**：借鉴人类情景记忆机制，增加模型可解释性。
- **实验透明**：对失败场景和参数敏感性做了详细分析，不回避局限性。

## 8. 不足与局限
