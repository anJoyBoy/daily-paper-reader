## 摘要
现有信息抽取（IE）任务日益采用基于大型语言模型的上下文学习（ICL）。然而，现有方法要么在不同模型规模上表现不一致，要么缺乏系统优化和泛化能力。基于此，我们提出了BCL（面向信息抽取的贝叶斯上下文学习框架），这是首个利用粒子滤波与贝叶斯更新来系统优化IE任务中标签表示的优化框架。通过初始化、观测、权重更新和重采样四个步骤，BCL可泛化至序列标注和关系分类两种范式。大量实验表明，与现有方法相比，BCL取得了显著且一致的改进。

## Abstract
Existing information extraction (IE) tasks increasingly adopt in-context learning (ICL) with large language models. However, current approaches either show inconsistent performance across model scales or lack systematic optimization and generalizability. Building on this, we propose BCL (Bayesian In-Context Learning Framework for Information Extraction), the first optimization framework that uses particle filtering with Bayesian updates to systematically refine label representations across IE tasks. Through four steps initialization, observation, weight update, and resampling, BCL generalizes to both sequence labeling and relation classification paradigms. Extensive experiments demonstrate substantial and consistent improvements over existing approaches.

## 1. 核心问题与整体含义（研究动机和背景）
现有信息抽取（IE）中的上下文学习（ICL）方法面临两个关键问题：一是跨模型规模表现不一致，例如任务迁移方法（ChatIE、CodeIE）在小型模型上性能大幅下降，甚至低于直接一次提示；二是缺乏系统优化和泛化能力，现有基于指导的方法（如GuideNER）仅用于命名实体识别（NER），无法扩展到关系抽取（RE），且其规则选择仅基于频率启发式，未经过优化。为此，本文提出BCL（Bayesian In-Context Learning Framework），首次利用粒子滤波与贝叶斯更新对标签表示进行系统性优化，统一适用于序列标注和关系分类两种范式，实现跨模型规模的稳定性能提升。

## 2. 方法论

### 核心思想
将粗粒度标签（如“Person”）分解为语义精细的原子子类别（如“athlete”、“politician”），这些子类别作为可控离散变量（即“粒子”），通过粒子滤波迭代优化其组合，以对齐数据集的实际标注模式。

### 关键技术细节
- **粒子（Particle）**：一个子类别模式与对应实体标签的配对，如（“athlete”, Person）。
- **规则（Rule）**：粒子附带置信权重，形成整体配置。
- **状态表示**：在时间步 \( t \)，规则配置为 \( R_t = \{(p_i^{(t)}, c_i, w_i^{(t)})\}_{i=1}^N \)。

### 算法流程（四个步骤）
1. **初始化**：使用LLM从训练数据中提取初始子类别模式，并基于困惑度（Perplexity）计算先验权重（困惑度越低，权重越高）。
2. **观测（Evaluation）**：通过ICL推理评估每个粒子在验证集上的似然（标签生成概率），得到置信分数 \( y_i^{(t)} \)。
3. **权重更新（Bayesian Posterior）**：组合先验权重与观测似然：\( \tilde{w}_i^{(t)} = w_i^{(t-1)} \cdot \exp(\beta \cdot y_i^{(t)}) \)，然后归一化。
4. **重采样（Resampling）**：两阶段策略——第一层保留权重前50%的粒子（性能筛选），第二层对保留粒子通过LLM变异生成新粒子（语义突变，包括细化、泛化、语境化三种策略）。新粒子基于困惑度赋予初始权重。

迭代直至验证F1在3次迭代内相对提升<3%或样本耗尽。通常仅需3-5%训练数据即可收敛。

## 6. 主要结论与发现
- BCL在所有模型和数据集上一致优于现有ICL方法，尤其在RE任务上，其他方法（ChatIE、CodeIE）几乎得0分，而BCL保持有效。
- 贝叶斯权重更新是最关键组件（消融下降11 F1），多样性变异次关键。
- BCL数据高效：仅需1%训练数据即可达优秀性能（CoNLL03上69.12 F1），3-5%即趋近最优。
- 优化得到的规则可跨模型迁移：小模型（Llama-8B、Qwen-7B）优化的规则直接用于GPT-3.5-turbo仍能提升性能。
- 小型模型（Qwen-3B）配合BCL可达到更大模型（Llama-8B）一次提示的性能，降低计算门槛。

## 7. 优点
1. **首次系统性优化框架**：将粒子滤波和贝叶斯更新引入IE的ICL优化，具有理论基础。
2. **统一泛化性**：同时适用于NER和RE，而先前方法要么只针对NER，要么在RE上完全失败。
3. **数据高效**：仅需少量训练样本即收敛，大幅降低标注和推理成本。
4. **跨模型迁移能力**：优化的规则可迁移到更强模型，无需重新优化。
5. **轻量级友好**：在小模型上即可取得强性能，降低对超大商业模型的依赖。
6. **实验充分**：多模型、多数据集、多任务、多维度消融和敏感性分析，验证充分。

## 8. 不足与局限
1. **优化计算成本**：优化阶段需要 \( O(K \times M) \) 次LLM调用（K粒子数，M训练样本数），虽然每次推理轻量，但多次迭代仍可能较慢，适合可摊薄成本的场景。
2. **可能偏向高频实体**：粒子滤波可能过度关注常见模式，不过实验显示对长尾实体影响有限（F1差异<2点）。
