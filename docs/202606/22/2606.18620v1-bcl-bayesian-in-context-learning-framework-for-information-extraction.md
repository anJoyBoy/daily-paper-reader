## 摘要
现有信息抽取任务越来越多地采用基于大型语言模型的上下文学习。然而，当前的方法要么在不同模型规模上表现不一致，要么缺乏系统优化和泛化能力。基于此，我们提出BCL（面向信息抽取的贝叶斯上下文学习框架），这是首个利用粒子滤波与贝叶斯更新来系统优化各信息抽取任务中标签表示的优化框架。通过初始化、观测、权重更新和重采样四个步骤，BCL可泛化至序列标注和关系分类两种范式。大量实验表明，BCL相较于现有方法获得了显著且一致的改进。

## Abstract
Existing information extraction (IE) tasks increasingly adopt in-context learning (ICL) with large language models. However, current approaches either show inconsistent performance across model scales or lack systematic optimization and generalizability. Building on this, we propose BCL (Bayesian In-Context Learning Framework for Information Extraction), the first optimization framework that uses particle filtering with Bayesian updates to systematically refine label representations across IE tasks. Through four steps initialization, observation, weight update, and resampling, BCL generalizes to both sequence labeling and relation classification paradigms. Extensive experiments demonstrate substantial and consistent improvements over existing approaches.

## 2. 论文提出的方法论：核心思想、关键技术细节和算法流程

- **核心思想**：将粗粒度的 IE 标签（如 “Person”）分解为多个语义离散的子类别（如 “athlete”、“politician”），每个子类别视为一个“粒子”（particle），粒子带有置信权重。通过粒子滤波的贝叶斯更新框架，在观测（模型在验证集上的表现）与重采样之间迭代，逐步优化粒子的权重和内容，从而获得最优的标签表示（即规则列表）。
- **关键技术细节**：
  - **状态表示**：每个时间步 \( t \) 的规则配置 \( R_t = \{ (p_i^{(t)}, c_i, w_i^{(t)}) \}_{i=1}^N \)，其中 \( p_i \) 为子类别模式（粒子），\( c_i \) 为对应的实体标签，\( w_i \) 为置信权重（归一化概率）。
  - **四步算法流程**：
    1. **初始化与规则提取**：利用 LLM 从训练数据中提取初始子类别规则，并根据困惑度（perplexity）赋予先验权重。
    2. **观测（评估）**：对每个粒子，通过 ICL 方式进行信息抽取，计算其在验证批上的平均对数概率作为置信得分，并通过 softmax 归一化得到观测似然 \( y_i^{(t)} \)。
    3. **权重更新（贝叶斯后验）**：结合先验权重与观测似然，以指数奖励形式更新权重：\( \tilde{w}_i^{(t)} = w_i^{(t-1)} \cdot \exp(\beta \cdot y_i^{(t)}) \)，再归一化。
    4. **重采样**：两级策略——Tier-1 按权重保留前 50% 的粒子；Tier-2 对保留粒子进行 LLM 引导的语义变异（精炼、泛化、语境化），新粒子根据困惑度赋予权重。整合后进入下一轮。收敛条件：连续 3 轮性能相对提升 < 3%，或训练数据耗尽。
