## 摘要
关系结构推理仍然是神经模型面临的重大挑战，尤其是在模型必须将学到的知识系统性地应用于比训练时更困难的问题实例时。由于评估这种泛化能力的困难阻碍了进展，因为先验地，很难判断什么使得一个实例变得困难。我们研究了如何通过使用大型语言模型（LLM）自动化基准生成来解决这个问题，以端到端的方式学习产生越来越有挑战性的实例。具体来说，给定一个由Datalog规则参数化的世界，并以Edge Transformer作为推理评估器，我们使用LLM驱动的进化搜索（基于FunSearch）和自主代理搜索来发现能够生成困难问题实例的采样函数。我们还展示了利用这些数据可以改进Edge Transformer，使其能够很好地泛化到进一步的数据扰动。最后，我们展示了相同的机制可以应用于LLM提出的新世界，为神经关系推理的自主研究打开了大门。

## Abstract
Reasoning about relational structures remains a significant challenge for neural models, particularly when they must systematically apply learned knowledge to problem instances that are harder than those seen in training. Progress is hampered by the difficulty of evaluating such generalization, since a priori, it is rarely clear what makes an instance hard. We study how this issue can be addressed by using large language models (LLMs) to automate benchmark generation, learning to produce increasingly challenging instances in an end-to-end manner. Concretely, given a world parametrized by Datalog rules, and an Edge Transformer as the reasoning evaluator, we use LLM-driven evolutionary search (based on FunSearch) and autonomous agentic search to discover sampling functions that yield hard problem instances. We also show that the Edge Transformer can be improved using this data such that it generalizes well to further data perturbations. Finally, we show that the same machinery can be applied to novel worlds proposed by LLMs, opening the door to autonomous research on neural relational reasoning.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：神经模型在关系结构推理中面临系统泛化挑战，即难以将训练中习得的规则系统地应用到更困难的测试实例上。现有评估依赖先验的难度指标（如推理深度、偏离路径边数等），但这些指标可能存在盲区——某些实例虽简单但实际很难，反之亦然。此外，即使知道哪些指标重要，手动生成符合特定难度结构的实例也很困难。
- **背景**：已有方法如CLUTRR、NoRA等通过构造训练/测试难度划分来评估系统性推理，但往往依赖随机采样或固定策略，无法确保生成的实例真正具有挑战性，且难以发现未知的困难模式。
- **整体含义**：本文旨在利用LLM（大语言模型）来自动发现能产生困难实例的采样函数，从而自动完成基准构建、模型评估与改进，形成闭环。这为神经关系推理的自主研究开辟了新道路。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将基准生成问题转化为学习一个“采样函数”（priority function）的问题，该函数用于逐步构建知识图谱（KG），使得生成的推理实例对目标神经模型（这里是Edge Transformer）的准确率最低。
- **关键技术细节**：
  - **世界定义**：使用Datalog规则集 P 和约束 C 来描述世界中实体间的关系，推理任务是给定部分KG，预测两个实体之间的所有关系。
  - **难度度量**：目标函数为 `difficulty(S; M) = 1 - E[ min_{h,t} min_r M_r(G,h,t) ]`，其中M是模型预测某关系为真的概率。最大化该值意味着生成对模型最困难的实例。
  - **三种LLM驱动策略**：
    1. **进化搜索（FunSearch）**：维护多个“岛屿”数据库，每个岛屿存储候选priority函数。每轮随机选两个高适应度的函数，让LLM生成改进版本；新函数通过采样一定数量的KG并用目标模型评估其困难程度（fitness）来打分。经过多轮迭代（cycles）后保留最佳函数，然后重新训练模型（round）。
    2. **自主研究智能体（Auto-research Agent）**：类似于程序合成，让一个编码智能体（Claude Opus 4.6）反复编辑单个priority函数，目标是降低Edge Transformer的评估准确率，同时保持函数尽可能简单。智能体可以运行代码、分析结果、从上下文学习。
    3. **模型无关的LLM生成策略**：通过与Claude对话直接生成多种采样器（如 hill-climbing、backward chaining、motif-based、混合策略等），这些采样器不依赖具体模型，但可针对特定规则集调整。
- **算法流程（文字描述）**：
  1. 给定目标模型M（预训练的Edge Transformer），初始化priority函数（如直接返回0的基线）。
  2. 重复执行多轮（round）：
     - 在当前priority函数下生成一批KG（实体数5-8，边密度固定）。
     - 对于每个KG，通过priority函数选出最高分候选边来构建查询（query）。
     - 在相同priority函数上采样多组KG，平均得到fitness。
     - 利用进化循环（FunSearch）或智能体直接生成新priority函数（尝试改进当前最优）。
     - 将新priority函数产生的困难实例加入训练集，重新训练Edge Transformer，进入下一轮。
  3. 最终得到的priority函数可用于生成具有挑战性的测试集，同时增强后的模型（Super ET）在更多源上训练后变得更鲁棒。
