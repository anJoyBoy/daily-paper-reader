## 摘要
思维链（CoT）提示已成为在大语言模型（LLMs）中引发推理的主流范式，但它通过迫使模型将中间推理步骤外部化为离散标记，产生了大量的计算开销。最近的潜在推理方法试图在连续隐藏状态内内化这一过程。在潜在推理领域的最新进展中，Tiny递归模型（TRMs）擅长符号推理，但在自然语言设置中难以保持语义连贯性。为弥合这一差距，我们引入了ReLIT（递归潜在隐式Transformer），一种混合框架，将深度递归推理植根于基础模型的丰富语义表示中。ReLIT用一个轻量级、可训练的递归块增强冻结的LLM骨干（TinyLlama-1.1B），该递归块在提交最终输出之前迭代地细化其潜在思维（z），从而在结构上区分语言直觉与算法处理，并通过梯度隔离的循环实现“深度思考”，而无需显式标记生成的延迟。实验上，ReLIT在GLoRE逻辑推理基准上实现了高参数效率，在ProofWriter和RuleTaker等具有挑战性的任务上，尽管监督极简，仍能达到或超越显著更大的模型。这些结果表明，推理能力可以通过递归深度而非参数宽度高效扩展，为基于语义的隐式推理提供了一个原则性框架。

## Abstract
Chain-of-Thought (CoT) prompting has become the dominant paradigm for eliciting reasoning in Large Language Models (LLMs), yet it creates substantial computational overhead by forcing models to externalize intermediate reasoning steps as discrete tokens. Recent latent reasoning approaches attempt to internalize this process within continuous hidden states. One of the latest advancements in the field of latent reasoning, Tiny Recursive Models (TRMs) excel at symbolic reasoning but struggle to preserve semantic coherence in natural language settings. To bridge this gap, we introduce ReLIT (Recursive Latent Implicit Transformer), a hybrid framework that grounds deep recursive reasoning within the rich semantic representations of a foundational model. ReLIT augments a frozen LLM backbone (TinyLlama-1.1B) with a lightweight, trainable recursive block that iteratively refines its latent thinking (z) before committing to a final output, structurally solving linguistic intuition from algorithmic processing and enabling "deep thinking" via gradient-isolated recurrent loops without the latency of explicit token generation. Empirically, ReLIT achieves high parameter efficiency on the GLoRE logical reasoning benchmark, matching or outperforming significantly larger models on challenging tasks such as ProofWriter and RuleTaker despite minimal supervision. These results demonstrate that reasoning capability can be scaled efficiently through recurrent depth rather than parameter width, offering a principled framework for semantically grounded implicit reasoning.

## 2. 方法论

### 2.1 核心思想

ReLIT 采用"三明治"式混合架构：**冻结的 LLM 骨干（TinyLlama-1.1B） + 可训练的递归 ReLIT 块 + 解码头**。推理过程在连续潜在空间中进行，不需要生成任何中间推理 token。核心是通过三个向量状态的迭代交互完成推理：

| 状态 | 名称 | 作用 |
|------|------|------|
| **x** | 语义锚点（Semantic Anchor） | 由冻结 LLM 提取的静态语义表示，为整个推理过程提供语言基础，防止语义漂移 |
| **y** | 答案状态（Answer State） | 动态演化的当前假设向量，逐步收敛到最终答案 |
| **z** | 潜在草稿本（Latent Scratchpad） | 内部"隐藏思维"向量，自由探索抽象逻辑路径，无需映射到合法输出 |

### 2.2 关键技术细节

- **残余状态细化（Residual State Refinement）**：区别于 TRM 的直接状态替换，ReLIT 每次迭代学习的是一个"逻辑增量"（logical delta），而非从头重建状态：
  - zₙ₊₁ = RMSNorm(zₙ + ReLIT(Linear([x; yₙ; zₙ])))
  - 这种残余依赖保证了梯度流动顺畅，防止在深层"思考"中语义信息消失。
- **递归转移函数**：定义 hₜ = Wc[x; yₜ; zₜ] + eₜ（eₜ 为步嵌入），然后更新 zₜ₊₁ 和 yₜ₊₁，ReLIT 内部使用 RMSNorm + 多头注意力 + SwiGLU 前馈网络，保证表达力。
- **Recall-Then-Learn 协议（梯度隔离的深度递归）**：
  - **Phase I（回忆/热身）**：在禁用梯度的条件下执行 T-1 次递归更新，使系统稳定到固定点附近；
  - **Phase II（学习/优化）**：在成熟状态上执行一次启用梯度的更新。
  - 这相当于截断 BPTT，在支持深度递归的同时避免了完整 Backpropagation Through Time 带来的巨大内存开销。
- **Adaptive Computation Time（ACT）**：通过一个 Halt Head 预测置信度，动态决定何时停止推理，使模型根据任务复杂度自适应调整"思考深度"。
- **深度监督（Deep Supervision）**：在每次宏步（macro-step）对中间状态 yₜ 计算交叉熵损失，促使各中间状态保持与目标对齐。
- **投影与推断**：使用冻结的 LLM 输出投影头将最终答案状态映射回词表空间（也可选用可训练解码头进行任务定制）。

### 2.3 训练流程（文字描述）

输入提示 → 经冻结 TinyLlama 获得语义锚点 x → 初始化 y₀ = x、z₀ 为高斯噪声 → 循环执行 ReLIT 块迭代细化和潜在状态更新（梯度关闭）→ 最后一次梯度开启的更新 → 通过冻结模型头投影到词表 → 计算任务损失（交叉熵）与 ACT 损失（二元交叉熵，预测是否可停止）。

### 3.5 语义漂移与状态演化分析

- 论文通过可视化中间状态 yₜ 在语义空间中的演化轨迹，发现 ReLIT 在推理过程中：

## 4. 讨论与开放性思考

### 4.1 为什么"隐式推理"能超越显式 CoT？

论文给出的解释是：显式 CoT 将推理过程硬编码为离散 token 序列，每一步都必须可读、可解释，但同时也引入了"语言化的瓶颈"。ReLIT 的潜在状态可以在高维连续空间中自由组合信息，不受词表约束，从而能表达文本无法简洁描述的抽象逻辑操作。此外，递归结构天然适合链式逻辑（如 A→B→C），而 T-step 递归恰好模拟了 T 步链式推理的深度，这一点在 ProofWriter 和 RuleTaker 上体现得最为明显。

### 4.2 局限性

- **自然语言理解瓶颈仍然存在**：ReLIT 强依赖冻结 LLM 的语义提取质量，对需要丰富常识或复杂语义歧义消解的 NLI 任务（NaN-NLI、TaxiNLI）优势不明显。
- **可解释性不足**：潜在推理过程无法直接转换为人类可读的推理步骤，不利于需要审计或解释的场景。
- **基线选择存在争议**：论文对比的基线中，QwQ-32B 和 o1-mini 等模型并非专门针对这些逻辑数据集微调，而 ReLIT 使用了训练样本进行训练，这种"微调 vs 零样本"的不公平对照可能夸大了 ReLIT 的优势。
- **扩展性问题**：递归深度增加时显存和训练时间成本仍呈线性增长，尽管 Recall-Then-Learn 缓解了部分压力，但实际部署时深度限制仍需考虑。

### 4.3 潜在影响

- 该工作为"用小模型实现大模型推理能力"提供了一条可行途径，可能推动高效边缘推理设备上的复杂逻辑应用。
- 若未来能将潜在推理过程部分解码为可读解释，或结合"先潜在思考、再显式输出"的混合机制，有望兼顾性能与可解释性。
- 论文提出的"语义锚点 + 递归潜在细化"范式是否可迁移到视觉-语言、多模态推理等场景，也是一个值得探索的方向。

## 5. 结论

ReLIT 通过将轻量递归块嵌入冻结 LLM 的潜在语义空间，并配合语义锚点、残余状态细化、Recall-Then-Learn 梯度隔离和自适应计算时间，成功在逻辑推理任务上实现了超越大模型的效果。它证明了"深度思考"不一定要通过输出 token 来实现，**递归计算本身就能赋予模型强大的推理能力**，且所需参数极少。尽管在自然语言理解密集型任务上仍有不足，但为下一代高效推理架构提供了新的设计范式。
