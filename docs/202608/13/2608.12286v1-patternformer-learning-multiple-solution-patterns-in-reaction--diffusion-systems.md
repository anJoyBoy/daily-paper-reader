## 摘要
许多物理学、化学和生物学中的非线性模型对于相同的参数表现出多个解，而捕捉整个解集对于理解图案形成系统至关重要。然而，现有的学习代理从根本上说是单值的：神经算子将每个参数映射到单个输出，物理信息神经网络则收敛到一个分支。我们开发了PatternFormer（PF），一个基于大型语言模型的框架，用于学习非线性偏微分方程的多个解。通过将无序的共存解转换为规范序列，PF在单次自回归传递中生成结构化的解集，对于有限族自动终止，并对无界族强制执行物理残差约束。在非线性椭圆问题上，它在一次推理步骤中恢复所有解分支；在Gray-Scott问题上，它生成共存的图灵图案，包括参考数据中不存在的且超出训练范围的物理有效状态。PF还可以在多稳态系统间进行顺序微调，朝着解景观的通用基础模型发展。

## Abstract
Many nonlinear models across physics, chemistry, and biology exhibit multiple solutions for the same parameters, and capturing this entire solution set is essential for understanding pattern-forming systems. Yet existing learned surrogates are fundamentally single-valued: neural operators map each parameter to a single output, and physics-informed neural networks converge to one branch. We develop \textbf{PatternFormer} (PF), a large language model-based framework for learning the multiple solutions of nonlinear partial differential equations. By transforming unordered coexisting solutions into canonical sequences, PF produces structured solution sets in a single autoregressive pass, terminating automatically for finite families and enforcing physical residual constraints for unbounded ones. On nonlinear elliptic problems it recovers all solution branches in one inference step; on Gray--Scott it generates coexisting Turing patterns, including physically valid states absent from the reference data and beyond training. PF can also be sequentially fine-tuned across multistable systems, toward general foundation models for solution landscapes.

## 1. 核心问题与整体含义

- **研究背景**：许多物理、化学和生物系统中的非线性偏微分方程（PDE）在相同参数下具有多个共存稳态解，即多稳态现象。刻画完整的解集（解景观）对理解图案形成至关重要，例如 Gray–Scott 反应-扩散系统具有丰富的图灵（Turing）斑图结构。
- **现有方法的局限**：
  - 传统数值方法（多初值模拟、同伦延拓、deflection 技术）虽然能找到多解，但计算成本高、难以扩展到高维参数空间。
  - 神经算子（Neural Operator）和 PINN 等机器学习代理本质上是单值映射：每个参数只能输出一个解，或收敛到单一分支，无法直接表示“参数→多个共存解”的关系。
  - 生成式模型在 PDE 中多表示不确定性或随机变异性，而非确定性的多个稳态解。
- **论文目标**：提出 **PatternFormer (PF)**——一个基于大语言模型（LLM）的框架，学习**集合值算子** \( G: p \mapsto S(p)=\{u_1,\dots,u_{K(p)}\} \)，用单次自回归前向传播生成同一参数下的完整解集，甚至能生成训练数据之外的全新有效解。
- **整体含义**：将“求解单个解”转变为“生成整个解景观”，为多稳态系统提供一种潜在的通用基础模型范式。

## 2. 方法论

### 2.1 核心思想
- **集合到序列的转化**：由于共存解是无序集合，PF 通过解的范数（例如一维问题用 \(\Phi(u)=\int_0^1 u\,dx\)，Gray–Scott 用激活场空间平均）进行规范化排序，将无序解集转换为规范序列，从而可以用因果自回归模型生成。
- **利用预训练 LLM**：使用 Qwen2.5-7B 作为骨干，但不用文本 tokenizer，而是将连续科学表示直接投影到 LLM 嵌入空间，通过 LoRA 适配，使其成为序列生成器。
- **物理约束与开放发现**：对无界解族（如 Gray–Scott）采用固定预算生成（fixed-budget），尾部槽位用铰链式物理残差损失驱动，发现超出训练数据的新解。

### 2.2 关键技术细节
- **连续潜空间**：冻结的卷积自编码器将解场 \(u\) 压缩为 256 维潜向量 \(z=E(u)\)，解码器 \(D(z)\) 重构解场。
- **结构嵌入**：定义起始标记 \(v_s\)、解分隔标记 \(v\)、终止标记 \(v_p\)。
- **匹配层**：输入匹配层 \(g_{\text{in}}\)（两层 MLP）将 \([z; p]\) 映射到 LLM 嵌入空间；参数单独输入时令 \(z=0\)。输出匹配层 \(g_{\text{out}}\) 将隐状态映射回潜空间。
- **LoRA 适配**：秩 \(r=16\)，只微调注意力投影层，原 LLM 权重冻结。
- **序列构造**：每个参数块 \(B(p) = [v_s, g_{\text{in}}(0,p), v, \tilde{z}_1, v, \tilde{z}_2, \dots, v, \tilde{z}_K, v_p]\)，训练时前面附加上下文示例块 \(B(p_1),\dots,B(p_M)\)，最后是目标块 \(B(p^*)\)。
- **损失函数**：
  - 已知多重性时（stop-token 设计）：
    \[
    L_{\text{stop}} = \sum_{k=1}^{K(p)} \left[\lambda_{\text{mse}}\|\hat{u}_k-u_k\|^2 + \lambda_{\text{pde}}\,\text{ReLU}(R(\hat{u}_k;p)-\epsilon)\right] + \lambda_{\text{ce}} L_{\text{marker}}
    \]
  - Gray–Scott 固定预算设计（无终止标记）：头部分槽位用参考解监督（field + latent MSE），尾部槽位自由生成，仅用铰链式物理残差约束：
    \[
    L = \sum_{k=1}^{K}\left[ \left(\lambda_{\text{mse}}\|\hat{u}_k-u_k\|^2+\lambda_{\text{lat}}\|\hat{z}_k-z_k\|^2\right)\mathbf{1}[k\le K_t] + \lambda_{\text{pde}}\text{ReLU}(R(\hat{u}_k;p)-\epsilon) \right]
    \]
- **训练流程**：
  1. 预训练自编码器（重建损失），然后冻结。
  2. With-context 阶段：输入含上下文示例块，训练模型理解解景观。
  3. No-context 阶段：去掉上下文，仅从目标参数自回归生成。
  - 使用多种性加权采样，增加高解数参数的采样概率。
- **推理与后处理**：
  - 自回归生成 \( \hat{z}_k = G_\theta(p^*, \hat{z}_1,\dots,\hat{z}_{k-1}) \)，解码为解场。
  - 可选牛顿精化：以生成解为初值，快速收敛到机器精度。
  - 开放探索：向潜变量注入高斯噪声，多次前向传播并去重（相对 L2 > 0.15 视为不同解），累积发现更多新解。

## 6. 主要结论与发现

- **单次前向恢复完整解景观**：对非线性椭圆问题，PF 在给定参数下一次性生成所有共存分支，直接输出中位相对 L2 误差约 \(10^{-2}\)，经少量 Newton 迭代（中位 3~4 步）达到 \(10^{-8}\) 以下，收敛率 99% 以上。
- **捕获分岔结构**：PF 学到的分支图与参考分岔图一致，能重建 fold 分岔位置和分支数量。
- **Gray–Scott 开放发现**：确定性 fixed-K 生成平均每参数恢复 2.90 个解，超过随机初值求解器（0.91）和 stop-token 设计（1.86）；加入噪声增强后平均达 8.39 个解，并在代表性参数发现 63 个不同稳态斑图，其中 61 个是参考数据中不存在的新解，且所有输出满足残差 < \(10^{-9}\)。
- **外推能力有限但可通过初始化延拓扩展**：直接外推只能覆盖训练边界附近；但用 PF 在边界解集作为初值，通过单跳或步进延拓可把解集传输到远超过训练范围的参数（Example 1 到 \(p=100\)，超过训练最大值 5 倍；Example 2 覆盖整个参数平面）。
- **预训练和 warm-start 有效**：预训练 LLM 比随机初始化收敛更快、误差更低；从 Example 2 warm-start 到 Example 3 降低了验证损失和直接误差；Gray–Scott 中 warm-start 模型每参数解数从预训练模型的 3.23 提升到 5.18，参考覆盖率从 0.22 到 0.34。
- **解发现与数值精化解耦**：直接生成已经确定解分支，Newton 精化只是提高数值精度，不改变解的构成。

## 7. 优点

- **问题建模新颖**：首次将多稳态 PDE 解集学习形式化为“集合值算子”，并利用 LLM 的自回归能力一次性生成多个解。
- **连续潜空间设计**：避免了离散 tokenization 的信息损失，用自编码器 + 匹配层与 LLM 嵌入空间衔接，具有通用性。
- **物理约束驱动探索**：铰链式残差损失既能防止平凡解，又能引导尾部槽位发现训练数据中未出现的新稳态解。
- **跨方程迁移能力**：通过 warm-start 在多类方程间顺序微调，展示了向科学基础模型发展的路径。
- **高效计算**：作为求解器初始化，PF 在细网格上比传统多尺度求解器快一个到两个数量级。
- **消融充分**：区分了直接生成与数值精化的作用，并量化了预训练和 warm-start 的贡献。

## 8. 不足与局限

- **外推范围有限**：纯前馈生成在远离训练区域时退化，必须借助同伦延拓或步进法才可扩展到远处参数，且扩展能力依问题方向而变化。
- **依赖高质量参考数据**：训练数据由经典多解求解器生成；对于 Gray–Scott 这类无界解族，参考集不完整，模型能发现新解，但“覆盖率”只能作为相对指标，无法验证是否穷尽所有解。
- **单一离散化训练**：模型在固定网格分辨率上训练（虽然可插值到其他分辨率），未真正实现离散化无关泛化；作者也承认向异构网格扩展是未来工作。
- **算力信息缺失**：未报告 GPU 型号、数量、训练时间，无法评估方法的资源成本；Qwen2.5-7B 即使仅 LoRA 微调，对一般科研团队仍有相当硬件门槛。
- **对称性处理依赖领域知识**：D4 对称性约简需要人工预处理，限制了方法的自动化程度。
- **与现有多解学习方法的对比不足**：未与 homPINNs、Newton-informed neural operator 等专门的多解神经网络方法做定量基准比较，说服力稍弱。
