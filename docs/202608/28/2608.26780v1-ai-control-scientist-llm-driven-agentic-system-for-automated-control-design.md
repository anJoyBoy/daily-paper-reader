## 摘要
控制系统设计对现代工业至关重要，例如化工过程温度调节和航空发动机控制。然而，传统的控制设计流程严重依赖专家知识和大量手动参数调节，导致效率和可扩展性受限。为此，本文提出了AI控制科学家（AICS），这是第一个能够根据语言设计需求自动生成优化控制器的大语言模型（LLM）驱动的智能体。具体来说，任务建模智能体将用户需求解释为工程约束；控制器设计智能体生成候选控制器结构和可执行代码；参数调节智能体在闭环性能标准下优化控制器参数。实验表明，所提出的智能体系统能够自动生成多种具有代表性的控制系统，在设计成功率和优化效率方面均优于现有的自动化基线方法。这项工作有望将控制系统设计从人工驱动转变为智能体驱动，为模型预测控制及其他先进控制系统的设计铺平道路。

## Abstract
Control system design is critical for modern industry, such as chemical process temperature regulation and aero-engine control. However,traditional control design workflows rely heavily on expert knowledge and extensive manual parameter tuning, resulting in limited efficiency and scalability. To this end, this paper proposes AI Control Scientist (AICS), the first large language model (LLM)-driven agent capable of automatically generating optimized controller from language design requirements. Specifically, a Task Modeling Agent interprets user requirements to engineering constraints; a Controller Design Agent generate candidate controller structures and executable code; and a Parameter Tuning Agent refine controller parameters under closed-loop performance criteria. Experiments demonstrate that the proposed agentic system can automatically generate multiple representative control systems, outperforms existing automated baselines in both design success rate and optimization efficiency. This work has the potential to transform control system design from human-driven to agent-driven, paving the way for model predictive control and other advanced control systems design.

- **LLM自动化的机遇与鸿沟**：大语言模型（LLM）在代码生成、推理和自主决策上展现出强大能力，但直接将其应用于控制工程面临三大关键挑战：
  1. **NLP-to-Control 结构性差距**：用户的自然语言需求（如"避免超调"）是模糊的，难以自动映射为严格的数学优化目标和约束；

提出**AICS（AI Control Scientist）**——首个LLM驱动的多智能体控制系统，将控制设计从"人工驱动"转变为"智能体驱动"，实现从自然语言需求到已验证优化控制器的端到端自动化。

## 2. 方法论：AICS多智能体架构

### 核心思想
将控制设计视为高维约束非凸优化问题，通过**"语义形式化—代码生成—参数整定"**三段式流水线解耦该问题，由三个专业化智能体协同完成，融合LLM的符号推理能力与外部数值优化器的高精度计算能力。

### 三大智能体关键设计

**（1）任务建模智能体（TMA）——语义形式化与系统验证**
- 利用翻译知识库将自然语言需求映射为确定性的系统动态模型 \( M \) 和约束集 \( C_{constraint} \)（物理执行边界 \( C_{phys} \) + 动态性能指标 \( C_{perf} \)）；
- 调用控制标准函数库进行系统验证分析（如LTI系统的开环极点位置稳定性判断、物理可行性检查），输出无歧义的规范化结果 \( S_{spec} \)。

**（2）控制器设计智能体（CDA）——逻辑引导的代码生成**
- 采用**"特性驱动设计范式"**：先对系统关键动态特征（时滞、阻尼比、奇异值等）进行推理，生成**设计蓝图（\( B_{logic} \)）**，再基于蓝图并结合控制知识库生成控制器代码；
- 采用**"后向修正"闭环迭代**：验证工具同时执行语法检查（\( V_{syn} \)）和控制理论验证（\( V_{theory} \)，如可控性判据），一旦失败则构造错误反馈 \( E_k \) 回传LLM重新生成，直至通过验证（可视为马尔可夫决策过程）。

**（3）参数整定智能体（PTA）——规划器-求解器双循环优化**
- 提出**"符号推理与数值计算解耦"的元优化范式**：LLM充当高层"规划器"，基于历史试验信息 \( H_k \)（包括历史搜索配置和对应性能指标），通过上下文学习动态设计奖励函数 \( R_k \) 和参数搜索空间 \( \Omega_k \)（即元配置 \( \Phi_k = \{R_k, \Omega_k\} \)）；
- 底层数值优化器充当"求解器"，在给定元配置下通过代理模型和采集函数最大化（如 \( \theta_{t+1} = \arg\max_{\theta \in \Omega_k} \alpha(\theta; D_{1:t}) \)）进行高效采样搜索，在有限仿真预算内获得最优参数 \( \theta^*_k \)；
- 通过双层迭代（外层LLM元配置精炼 + 内层数值优化），实现参数整定的全自动闭环优化（见算法1：DoubleLoop）。
