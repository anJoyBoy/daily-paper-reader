## 摘要
事件抽取旨在识别事件触发词、分类事件类型并抽取论元，以构建结构化的事件表示。尽管在领域内表现强劲，但由于上下文表达和事件模式的差异，开发能够跨领域稳健泛化的模型仍然具有挑战性。先前的统一和多任务方法提高了领域内准确性，但在应用于未见领域时灵活性有限。即使是基于大型语言模型的方法，在推理时提供完整事件本体，其性能也往往不如较小规模的、针对特定任务微调的模型。我们提出一个统一的多领域多任务训练框架，在单个模型中建模异构事件模式。我们的方法引入领域条件信号，并与任务特定提示相结合，使得无需在推理时提供完整事件标签集即可动态适应数据集特定的模式。该框架同时支持流水线式和端到端式抽取设置，促进高效的任务级和领域级迁移。在多个事件抽取基准上的实验表明，我们的方法在保持领域特定精度的同时，实现了具有竞争力的性能、强跨领域泛化能力和实用的可扩展性。

## Abstract
Event extraction aims to identify event triggers, classify event types, and extract arguments to construct structured event representations. Despite strong in-domain performance, developing models that generalize robustly across domains remains challenging due to variations in contextual expressions and event schemas. Prior unified and multi-task approaches improve in-domain accuracy but exhibit limited flexibility when applied to unseen domains. Even large language model-based methods that provide full event ontologies at inference time often underperform compared to smaller, task-specific fine-tuned models. We propose a unified multi-domain and multi-task training framework that models heterogeneous event schemas within a single model. Our approach introduces domain conditioning signals, jointly with task-specific prompts, enabling dynamic adaptation to dataset-specific schemas without requiring complete event label sets at inference time. The framework supports both pipeline and end-to-end extraction settings, facilitating efficient task- and domain-level transfer. Experiments on diverse event extraction benchmarks demonstrate that our method achieves competitive performance, strong cross-domain generalization, and practical scalability, while preserving domain-specific precision.

## 一、论文核心问题与整体含义

- **研究背景**：事件抽取（Event Extraction, EE）旨在从非结构化文本中识别事件触发词、分类事件类型、抽取论元，构建结构化事件表示。传统判别式模型和近期统一生成模型在**领域内**表现良好，但跨领域泛化能力不足——不同领域在上下文表达、事件模式、标注模式上差异显著。
- **核心问题**：现有统一/多任务方法虽能提升领域内准确率，但对**未见领域的灵活性有限**；基于大语言模型（LLM）的方法即便在推理时提供完整事件本体，其性能仍经常**不如小型任务专用微调模型**。
- **论文目标**：提出一个**统一的多领域多任务生成框架**，在单模型中建模异构事件模式；通过轻量级**领域条件信号**（domain indicator）与**任务特定提示**（task-specific prompt），使模型无需在推理时提供完整事件标签集/本体，即可动态适配不同数据集的事件模式。

## 二、方法论

- **总体架构**：采用基于 T5-Base 的 text-to-text 多任务生成框架，将事件抽取重新表述为**条件文本生成**问题。
- **输入条件化**：每个输入序列 S 前拼接领域指示符（如 `Domain: Geneva.`）和任务提示 πt（如 `Identify trigger words`），形成条件序列 `d + πt + S`。
- **核心思想**：
  - **领域指示符**提供轻量级领域语义信号，帮助模型区分不同领域的事件类型和角色模式；
  - **任务提示**将不同子任务（触发词识别、类型分类、论元抽取）统一到同一生成框架中；
  - 二者结合实现**动态适配**，无需显式 schema 或完整事件本体。
- **训练目标**：最小化多任务多领域联合负对数似然：
  pθ(y | d, πt, S) = ∏ pθ(yi | y<i, d, πt, S)
- **多任务模式（Table 1）**：定义了五种输入-输出模式：
  - **ED-P1**：触发词识别（TI），输入含领域+任务提示+文本，输出触发词；

- **两种推理模式**：
  - **Pipeline 模式**：ED（TI → TC）→ EAE。优点在于每个输入对应单一事件实例，可显式利用事件类型实例化的 **schema 约束**（合法论元角色列表），提高抽取精度；缺点是存在**错误传播**问题。
  - **End-to-End 模式**：一步生成完整事件结构，减少级联错误，但缺乏显式 schema 约束，对角色结构的隐式学习要求更高。
- **后处理**：对生成的线性化文本进行确定性解析，恢复触发词跨度、事件类型、论元及偏移量，形成标准化的层级 JSON 输出结构。

## 六、主要结论与发现

- **多领域学习的收益**：联合训练一个模型在多数情况下达到或超过单领域模型，尤其在 Genia2013 和 WikiEvents 等资源有限/模式多样的领域提升显著——表明高资源领域知识可**有效迁移**至低资源领域。
- **论元抽取比触发词抽取收益更大**：多领域训练对 AI/AC 的提升大于对 TI/TC 的提升，因为论元角色和语义模式跨域更可迁移，而触发词更具领域特异性。
- **Pipeline/ED-e2e 优于完全端到端**：完全端到端在论元抽取（AI/AC）上大幅下降，原因在于缺乏显式 schema 约束，难以生成一致合法的论元角色；而 pipeline 模式可利用事件类型实例化合法角色列表。
- **ED-e2e 与 ED-pipeline 触发词性能相当**，且 ED-e2e 结合 schema 约束的论元抽取可兼顾精度与鲁棒性。
- **细粒度事件类型是核心挑战**：RAMS 的多层级类型（Levels 4-8）数据稀疏，整层匹配 F1（31.25%）远低于 Level 1（77.42%）。
- **触发词定位是主要性能瓶颈**：从 ED-gold 到预测触发词设置的显著性能落差证明触发词识别错误会级联影响下游论元抽取。
