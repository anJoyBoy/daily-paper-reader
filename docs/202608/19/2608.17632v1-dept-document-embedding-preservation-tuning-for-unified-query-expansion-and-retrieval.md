## 摘要
大型语言模型（LLM）既能扩展不明确的查询，也能将文本编码为稠密表示，这暗示了查询扩展与检索可采用统一模型。现有系统通常依赖提示式扩展、独立训练的模块或分阶段优化，导致生成的扩展仅与评判其的检索损失间接对齐。我们端到端训练单个仅解码器LLM，使同一模型既生成扩展，又对扩展后的查询和候选文档进行编码。这种统一设置带来了移动目标问题：检索监督应改善查询侧扩展，但同一次更新也会改变作为检索目标的文档嵌入。我们引入了文档嵌入保持调优（DEPT），在允许检索梯度通过直通式解码传入生成器的同时，保持调优后的文档嵌入接近缓存的初始嵌入。DEPT将查询-文档的联合移动转化为针对近似稳定的白化文档嵌入的查询侧适应，从而支持索引复用和在线难负样本挖掘。在BEIR基准的五个数据集上，使用Qwen3-4B-Instruct-2507和LLaMA-3.2-3B-Instruct进行的实验表明，DEPT相较于无需训练、独立训练和分阶段统一的基线，平均检索质量有所提升，而消融实验隔离了保持、白化、端到端扩展训练和在线负样本各自的效果。代码可在https://github.com/ILSparkle/DEPT获取。

## Abstract
Large language models (LLMs) can both expand underspecified queries and encode text as dense representations, suggesting a unified model for query expansion and retrieval. Existing systems usually rely on prompted expansions, independently trained modules, or staged optimization, leaving generated expansions only indirectly aligned with the retrieval loss that judges them. We train a single decoder-only LLM end to end, where the same model generates the expansion and encodes both the expanded query and candidate documents. This unified setting creates a moving-target problem: retrieval supervision should improve query-side expansion, but the same update also shifts the document embeddings that serve as retrieval targets. We introduce Document Embedding Preservation Tuning (DEPT), which keeps tuned document embeddings close to cached initial embeddings while allowing retrieval gradients to pass through straight-through decoding into the generator. DEPT converts joint query--document movement into query-side adaptation against approximately stable, whitened document embeddings that support index reuse and online hard-negative mining. Experiments with Qwen3-4B-Instruct-2507 and LLaMA-3.2-3B-Instruct on five datasets in BEIR benchmark show that DEPT improves average retrieval quality over training-free, independently trained, and staged unified baselines, while ablations isolate the effects of preservation, whitening, end-to-end expansion training, and online negatives. Code is available at https://github.com/ILSparkle/DEPT.

# DEPT：面向统一查询扩展与检索的文档嵌入保持调优

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 查询扩展与稠密检索是信息检索中两个互补的组成部分：查询扩展将不明确的查询改写为暴露缺失实体、约束或主题线索的文本，而稠密检索则把扩展后的查询和文档映射到同一向量空间中进行高效匹配。
- 大型语言模型（LLM）既能生成流畅的扩展文本，也能提供稠密表示，这使得"单一模型同时完成查询扩展与检索"成为一个自然且极具吸引力的设想。这种统一模型的优势包括：扩展成为可训练的检索行为而非提示式预处理步骤；生成的文本保持可检查性，使检索决策可通过文本输出被审查。
- 现有方法存在根本性局限：无训练方法（HyDE、Query2Doc）在生成器失效时无法调整；独立训练方法（InPars、Promptagator）中生成器与检索器通过分离接口优化；分阶段统一方法（UniRAG）虽减少架构分离，但增强和表示仍分阶段训练——这些方法的共同问题在于：**生成组件没有被最终的检索对比损失直接塑造**。

**核心困难（移动目标问题）：**
- 直接端到端训练统一模型会产生新问题：检索损失希望改进查询侧扩展，但同一次参数更新也会改变作为检索目标的文档嵌入。梯度分解显示，查询-文档分数对共享参数的梯度包含两项：期望的查询侧更新项 `(∇θ qi)ᵀd` 与有害的文档移动项 `qiᵀ(∇θ d)`。
- 更新过程中文档嵌入和扩展行为同时漂移，模型可通过重组文档嵌入来降低检索损失，而不是学习真正改善排名的查询扩展，导致生成能力退化、最终检索增益受限。

## 2. 论文提出的方法论

**核心思想：** DEPT 遵循"查询侧激进适应，文档侧保持稳定"的非对称训练原则。同一解码器 LLM 既生成扩展又编码查询与文档，但通过文档嵌入保持（DEP）损失将文档嵌入约束在初始参考附近，使检索梯度主要作用于查询侧的扩展与表示学习。

**关键技术细节：**

1. **直通式扩展训练（Straight-Through Expansion）**
   - 前向传播中使用贪心解码的离散 token 嵌入，反向传播时使用 top-k 软嵌入（式 9-11）的梯度
   - 具体公式：
     - `π(v) = exp(ℓ(v)) / Σ_{u∈K} exp(ℓ(u))`，K 为 top-k token 集合
     - `ee = Σ_{v∈K} π(v)E(v)`（软嵌入）
     - `eST = ee + sg(E(ŷ) − ee)`（直通估计，sg 为停止梯度）
   - 检索梯度通过扩展嵌入更新生成 logits 和查询表示

2. **文档嵌入保持损失（DEP Loss）**
   - 预计算缓存参考嵌入 `d0 = fθ0(d)`（初始模型编码，训练中不更新）
   - 定义角度漂移 `δ(d) = 1 − cos(d, d0)`
   - 损失形式：`LDEP = (1/B) Σᵢ (1/|Sᵢ|) Σ_{d∈Sᵢ} (s·δ(d))ᵖ`，其中 s>0 为尺度，p>1 强调大漂移
   - 控制文档嵌入漂移，避免移动目标问题，同时作为轻量级功能 rehearsal 保持生成能力

3. **固定白化变换（Fixed Whitening）**
   - 由于解码器 LLM 原始嵌入存在各向异性（Ethayarajh 2019），在缓存文档嵌入上拟合固定白化变换，训练期间不更新
   - 公式：`W = U(Λ + εI)^(−α)`，映射 `ẑ = norm(Wᵀ(z − μ))`
   - 白化仅在 DEP 损失保持文档嵌入接近缓存的条件下才保持有效

4. **端到端检索训练**
   - 检索损失为白化空间中的 InfoNCE：`LRET = −(1/B) Σᵢ log[exp(q̂ᵢᵀd̂⁺ᵢ/τ) / Σ_{d∈Cᵢ} exp(q̂ᵢᵀd̂/τ)]`
   - 最终目标：`LDEPT = LRET + λ·LDEP`
   - 采用 LoRA 参数高效微调

5. **索引复用与在线难负样本挖掘**
   - 文档嵌入稳定使训练前构建的索引可直接用于推理，无需重新编码语料库
   - 训练时用当前模型生成的查询嵌入搜索固定 FAISS 索引，在排名高位区间采样难负样本（避开最顶部可能包含误标正例的项）

## 6. 论文的主要结论与发现

1. **DEPT 在平均检索质量上取得最优**：长扩展 DEPT 在 Qwen 和 LLaMA 骨干上均取得最高平均 nDCG@10（42.59 和 39.60），DEPT-K 以极短扩展（~9 tokens）仍保持竞争力（41.45 和 38.73）。
2. **增益并非简单的长度效应**：无训练方法生成更长文本但因未优化嵌入评分器而表现更差；检索损失直接训练扩展路径是关键。
3. **DEP 损失超出索引复用价值**：即使重新编码文档，移除 DEP 损失仍会伤害性能（50.82 → 46.95），说明保持通过稳定优化目标本身改善学习。
4. **白化是最重要的单一因素**：移除白化使平均分降至 42.09，降幅最大。
5. **直通式扩展训练有效**：分离扩展或移除扩展均显著降低性能，验证了端到端检索梯度对扩展训练的必要性。
6. **缓存索引接近可用**：DEPT 下缓存索引检索与重新编码性能接近；无 DEP 损失时缓存索引完全失效。
7. **生成能力保持**：DEPT 在 GSM8K/IFEval/MMLU-Pro 上接近基线的生成能力（77.56 → 76.28），而标准对比学习崩溃至 9.32。

## 8. 不足与局限

- **实验规模有限**：BEIR 仅覆盖 5 个子集（SciFact、ArguAna 等规模较小），缺乏大规模检索基准（如 MS MARCO passage ranking、Natural Questions 等更大规模任务）或域外数据的验证；训练数据与 5 个 BEIR 数据集间存在部分主题重叠（如训练集中的 FEVER、NQ 与推理数据相关），可能对零样本评估的纯粹性产生一定影响
- **缺乏统计严谨性**：单次运行无种子重复、无方差/置信区间报告，部分性能差距可能不显著
- **基线生态尚不完整**：缺少与专门训练的最先进稠密检索模型（如 GTR、E5 微调版）的对比，UniRAG 和 ExpandR 为重实现，可能存在细微差异

- **扩展-性能权衡未充分刻画**：DEPT-K 与 DEPT 在不同数据集上各有胜负（如 SCIDOCS 上 DEPT 低于 DEPT-K），论文未深入分析何时应选何种扩展风格；扩展长度控制仅通过 prompt 实现，缺乏更精细的机制
- **白化稳定性依赖**：α=0.5 的白化强度基于 1,024 个文档估计，在更大或分布不同的语料上效果未验证；白化变换对不同领域的泛化性存疑
- **时间标注异常**：论文标注发表于 2026 年且版权为 2027 AAAI，但使用 2507 版模型权重，时间线略显超前
