## 摘要
科学命名实体识别（SciNER）在从科学文本中提取信息和发现知识方面发挥着关键作用。近年来，大型语言模型（LLMs）已展现出以最少人工投入实现有竞争力的SciNER性能的能力。现有研究强调了在提示中纳入候选实体类型信息对于LLMs准确识别和分类实体的重要性。然而，当提示中提供的候选实体类型过多时，LLMs在科学文本中准确识别和标注实体会遇到困难，因为科学文本中的实体类型比通用领域更为复杂。为应对这一挑战，我们提出了TdSciNER，一种类型驱动的方法，有效利用实体类型信息来提升SciNER性能。在TdSciNER中，我们首先设计了一个实体类型过滤模型，以识别给定句子中最可能出现的实体类型。随后，我们在多任务学习框架中引入了一个辅助的多类实体分类任务，与SciNER共同进行，以获得更丰富的上下文表示。然后，我们开发了一种基于句子相似度和实体类型多样性的新颖演示选择策略，以激活LLMs的上下文学习能力，从而提高跨不同科学领域的实体识别准确性。在三个数据集上的实验表明，我们的方法达到了与全监督模型相当的性能。进一步的分析验证了TdSciNER中每个实体类型驱动组件对SciNER性能提升的贡献。这项工作为未来SciNER和科学文本挖掘中更广泛的信息抽取任务的进展提供了有价值的见解。

## Abstract
Scientific named entity recognition (SciNER) plays a crucial role in information extraction and knowledge discovery from scientific texts. Recently, large language models (LLMs) have demonstrated the capacity to achieve competitive SciNER performance with minimal human effort. Existing research highlights the importance of incorporating candidate entity type information for accurate entity recognition and classification by LLMs. However, when too many candidate entity types are provided in the prompt, LLMs struggle to accurately recognize and label entities in scientific texts, where entity types are more complex than in general domains. To address this challenge, we propose TdSciNER, a type-driven approach that effectively leverages entity type information to enhance SciNER performance. In TdSciNER, we first design an entity type filter model to identify the most likely entity types present in a given sentence. Subsequently, we introduce an auxiliary multi-class entity typing task within a multi-task learning framework alongside SciNER to obtain richer contextual representations. Then, we develop a novel demonstration selection strategy based on sentence similarity and entity type diversity to activate the in-context learning capabilities of LLMs, thereby improving entity recognition accuracy across diverse scientific domains. Experiments on three datasets demonstrate that our method achieves performance comparable to fully supervised models. Further analysis validates that each entity type-driven component in TdSciNER contributes to the improvement of SciNER performance. This work provides valuable insights for future advancements in SciNER and broader information extraction tasks in scientific text mining.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

TdSciNER 的总体框架由三大核心组件构成：

1. **实体类型过滤模型（Entity Type Filter, ETF）**
   - 目的：从原始候选类型集合 \(C=\{c_1,c_2,\dots,c_n\}\) 中筛选出与输入句子最相关的实体类型子集 \(C'\)，从而缩小 LLM 的候选类型空间。
   - 实现思路：
     - 使用 GPT-4 为每个实体类型生成领域描述集合 \(D=\{d_{c_1},d_{c_2},\dots,d_{c_n}\}\)；
     - 从训练集中选取只包含单一实体类型的句子，构成示例集合 \(S=\{S_{c_1},S_{c_2},\dots,S_{c_n}\}\)；
     - 用 BERT 类编码器对输入文本 \(x\) 编码得到向量 \(h_x\)；
     - 分别计算 \(h_x\) 与类型描述、类型示例集的余弦相似度，并按权重 \(w\) 进行组合：
       \[
       f_{\text{filter}} = w \cdot f_{\text{filter}}(h_x, d_{c_i}) + (1-w) \cdot f_{\text{filter}}(h_x, S_{c_i})
       \]
     - 通过阈值 \(\delta\) 过滤掉相似度较低的实体类型，得到缩小的候选集合 \(C'\)。
   - 该 BERT 类编码器通过对比学习进行微调，损失函数为：
     \[
     \mathcal{L}_{\text{filter}} = -\sum_{t_+ \in \mathcal{P}_x} \log \frac{e^{\text{sim}(x,t_+)/\tau}}{\sum_{t \in \mathcal{P}_x \cup \mathcal{N}_x} e^{\text{sim}(x,t)/\tau}}
     \]
     其中 \(t_+\) 为正例类型，\(\mathcal{N}_x\) 为负例类型。

2. **辅助实体分类任务（Auxiliary Entity Typing Task, AT）**
   - 在多任务学习框架中，将实体分类作为辅助任务与主 SciNER 任务联合训练。
   - 输入：给定文本及其已标注的实体（抽取自原始数据集），要求 LLM 从候选类型集合 \(C\) 中为每个实体分配正确类型标签。
   - 该任务不引入额外标注成本，因为实体类型标签已存在于原始数据集中。
   - 损失函数为标准的交叉熵损失：
     \[
     \mathcal{L}_i = -\sum_{c \in C} y_{i,c} \log(\hat{p}_{i,c})
     \]
     总辅助损失为所有实体损失之和：
     \[
     \mathcal{L}_{\text{entity typing}} = \sum_{i=1}^{n} \mathcal{L}_i
     \]
   - 总损失为：
     \[
     \mathcal{L} = \mathcal{L}_{\text{SciNER}} + \lambda \mathcal{L}_{\text{entity typing}}
     \]
     其中 \(\lambda\) 为辅助任务权重。

3. **基于相似度与多样性的演示选择策略（ICL Demonstration Selection）**
   - 从训练集中随机挑选中等长度句子构成候选示例集 \(K_{\text{candidate}}\)。
   - 对每个候选示例 \(k_i\)，分别计算：
     - 与输入文本 \(x\) 的余弦相似度 \(\text{Sim}(x,k_i)\)；
     - 实体类型多样性分数 \(\text{div}_{\text{type}}(x,k_i)\)（基于过滤模型计算）；
     - 结构多样性分数（基于句法解析树的树编辑距离 TED）：
       \[
       \text{div}_{\text{struct}}(x,k_i) = \frac{\text{TED}(x,k_i)}{\max(|x|,|k_i|)}
       \]
   - 综合排序得分：
     \[
     \text{ICL}_{\text{top}k} = \alpha \cdot \text{Sim}(x,k_i) + \beta \cdot \text{div}_{\text{type}}(x,k_i) + \gamma \cdot \text{div}_{\text{struct}}(x,k_i)
     \]
     其中 \(\alpha, \beta, \gamma\) 为权重系数。
   - 选择 top-k 示例作为 few-shot 演示，激活 LLM 的 ICL 能力。

- TdSciNER 在 SciERC 和 JNLPBA 上取得最高 F1（70.58% 和 79.34%），在 BC5CDR 上达到 89.83%，与全监督模型（SciBERT/BioBERT）性能相当，明显优于其他 LLM-based 方法。
