## 摘要
科学命名实体识别（SciNER）在从科学文本中提取信息和发现知识方面发挥着关键作用。近年来，大型语言模型（LLMs）已展现出以最少人工投入实现具有竞争力的SciNER性能的能力。现有研究强调在提示中纳入候选实体类型信息对于LLMs准确识别和分类实体的重要性。然而，当提示中提供的候选实体类型过多时，LLMs难以准确识别和标注科学文本中的实体，因为科学文本中的实体类型比通用领域更为复杂。为应对这一挑战，我们提出了TdSciNER，一种类型驱动的方法，有效利用实体类型信息来提升SciNER性能。在TdSciNER中，我们首先设计了一个实体类型过滤模型，以识别给定句子中最可能出现的实体类型。随后，我们在多任务学习框架中引入了一个辅助的多类实体分类任务，与SciNER共同训练以获取更丰富的上下文表示。然后，我们开发了一种基于句子相似度和实体类型多样性的新型演示选择策略，以激活LLMs的上下文学习能力，从而提高跨不同科学领域的实体识别准确性。在三个数据集上的实验表明，我们的方法达到了与全监督模型相当的性能。进一步的分析验证了TdSciNER中每个实体类型驱动组件都有助于提升SciNER性能。这项工作为未来在科学文本挖掘中推进SciNER及更广泛的信息抽取任务提供了有价值的见解。

## Abstract
Scientific named entity recognition (SciNER) plays a crucial role in information extraction and knowledge discovery from scientific texts. Recently, large language models (LLMs) have demonstrated the capacity to achieve competitive SciNER performance with minimal human effort. Existing research highlights the importance of incorporating candidate entity type information for accurate entity recognition and classification by LLMs. However, when too many candidate entity types are provided in the prompt, LLMs struggle to accurately recognize and label entities in scientific texts, where entity types are more complex than in general domains. To address this challenge, we propose TdSciNER, a type-driven approach that effectively leverages entity type information to enhance SciNER performance. In TdSciNER, we first design an entity type filter model to identify the most likely entity types present in a given sentence. Subsequently, we introduce an auxiliary multi-class entity typing task within a multi-task learning framework alongside SciNER to obtain richer contextual representations. Then, we develop a novel demonstration selection strategy based on sentence similarity and entity type diversity to activate the in-context learning capabilities of LLMs, thereby improving entity recognition accuracy across diverse scientific domains. Experiments on three datasets demonstrate that our method achieves performance comparable to fully supervised models. Further analysis validates that each entity type-driven component in TdSciNER contributes to the improvement of SciNER performance. This work provides valuable insights for future advancements in SciNER and broader information extraction tasks in scientific text mining.

**研究意义：** 该工作填补了"如何在 LLM 框架下系统利用实体类型信息提升 SciNER 性能"这一研究空白，为科学文本挖掘和大规模文献信息抽取提供了新思路。

## 二、方法论详解

论文提出 **TdSciNER**，一个类型驱动的多任务学习框架，包含三个核心组件：

### 1. 实体类型过滤模型（Entity Type Filter）

- 利用 GPT-4 为每个候选实体类型生成领域特定的语义描述（描述集 D）；
- 从训练集中随机抽取仅包含单一实体类型的句子作为类型示例集（S）；
- 使用 BERT 类编码器（如 SciBERT、BioBERT）对输入文本进行编码，分别计算输入句与类型描述的余弦相似度、以及与类型示例句的余弦相似度；
- 按权重 w 加权融合两种相似度得分，并通过阈值 δ 筛选出最可能出现在输入句中的候选类型集合 C′；
- 该模块在句子-类型相关性判别上采用对比学习训练，使模型能区分相关类型与无关类型。

### 2. 多任务学习框架（辅助实体分类任务）

- 在主任务（SciNER 生成式序列标注）之外，设计了一个辅助的多类实体分类任务：给定输入文本中的实体（来自原标注数据），要求模型从候选类型集合中为每个实体分配正确类型标签；
- 两个任务共享底层模型参数，联合优化总损失：
  - **Loss = Loss_SciNER + λ × Loss_EntityTyping**
- 辅助任务不需要额外的人工标注，直接复用原始数据集的实体类型标注，训练阶段通过对比 SciNER 任务共享上下文表示，增强模型区分相近实体类型的能力。

### 3. 演示选择策略（相似性-多样性结合的 ICL 样本选择）

- 从训练集中随机选取句子长度适中的候选样本（约 100 条），构建候选池；
- 对每个候选样本计算三个指标：
  - **句子语义相似度**（与测试输入文本的余弦相似度）；
  - **实体类型多样性**（候选样本中涵盖的实体类型数量，经归一化处理）；
  - **结构多样性**（利用句法解析树计算 Tree Edit Distance (TED)）；
- 综合打分公式：**ICL_topk = α·Sim(x, k) + β·div_type(x, k) + γ·div_struct(x, k)**，选取 Top-k 样本作为演示；
- 通过精心挑选的演示样本激活 LLM 的上下文学习（ICL）能力，使模型在低资源场景下仍能准确把握任务要求。

## 六、主要结论与发现

1. **性能卓越**：TdSciNER（Flan-T5-11B）在三个数据集上分别取得 F1 = 70.58%（SciERC）、79.34%（JNLPBA）、89.83%（BC5CDR），达到了与领域专用的全监督模型（如 SciBERT、BioBERT）相当甚至更优的性能，并在 SciERC 和 JNLPBA 上超越所有对比的 LLM 方法。
2. **类型信息是核心驱动力**：实体类型过滤模块、辅助类型分类任务、类型多样性感知的演示选择均能独立带来性能提升，消融实验确认了各组件对整体效果的积极贡献。
3. **实体类型越多，改进越明显**：在实体类型数较多的 SciERC（6类）和 JNLPBA（5类）上，各模块带来的性能提升幅度显著高于仅含 2 类实体的 BC5CDR，说明类型驱动的策略在复杂类型场景下价值更大。
4. **领域预训练编码器优势明显**：在实体类型过滤模块中，SciBERT 和 BioBERT 等领域相关模型优于通用编码器（即使后者的参数量更大）。
5. **ICL 的作用随类型数量增加而增强**：在实体类型较多的数据集上，增加演示样本数量（从 1-shot 到 20-shot）带来持续稳定的性能提升。
6. **推断开销可接受**：TdSciNER 仅比 GPT-3.5-turbo 增加了 0.17 秒/样本的推断时间，却带来了大幅度的 F1 提升（如 SciERC 上 +49.78 个百分点）。

## 七、优点

1. **问题切入准确**：抓住了 LLM 进行 SciNER 时"候选类型过多导致性能下降"这一关键痛点，具有明确的实际应用含义。

## 八、不足与局限

1. **未全面超越领域专用预训练模型**：在某些数据集上仍与 SciBERT/BioBERT 存在小幅差距，主要原因在于后者在大规模领域语料上预训练，对科学术语的捕获能力更强。
2. **数据集覆盖有限**：实验仅涉及计算机科学和生物医学领域；法律、金融、材料等其他科学领域的泛化能力尚未验证。

4. **辅助任务范围较窄**：仅使用了实体类型分类作为辅助任务，未探索关系抽取、核心指代消解等其他信息抽取任务作为辅助任务的可能性。
