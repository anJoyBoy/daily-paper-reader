## 摘要
科学命名实体识别（SciNER）在从科学文本中提取信息和发现知识方面起着至关重要的作用。近年来，大型语言模型（LLMs）已展现出以最少人力投入实现具有竞争力的SciNER性能的能力。现有研究强调了在提示中纳入候选实体类型信息对于LLMs准确进行实体识别和分类的重要性。然而，当提示中提供过多候选实体类型时，LLMs难以准确识别和标注科学文本中的实体，因为科学文本中的实体类型比通用领域更为复杂。为应对这一挑战，我们提出了TdSciNER，一种类型驱动的方法，有效利用实体类型信息来增强SciNER性能。在TdSciNER中，我们首先设计了一个实体类型过滤模型，以识别给定句子中最可能存在的实体类型。随后，我们在多任务学习框架中引入了一个辅助的多类实体类型分类任务，与SciNER并行，以获得更丰富的上下文表示。然后，我们提出了一种基于句子相似性和实体类型多样性的新颖演示选择策略，以激活LLMs的上下文学习能力，从而在不同科学领域提高实体识别准确性。在三个数据集上的实验表明，我们的方法达到了与全监督模型相当的性能。进一步的分析验证了TdSciNER中每个实体类型驱动的组件都有助于提升SciNER性能。这项工作为未来SciNER及科学文本挖掘中更广泛的信息抽取任务的进展提供了宝贵的见解。

## Abstract
Scientific named entity recognition (SciNER) plays a crucial role in information extraction and knowledge discovery from scientific texts. Recently, large language models (LLMs) have demonstrated the capacity to achieve competitive SciNER performance with minimal human effort. Existing research highlights the importance of incorporating candidate entity type information for accurate entity recognition and classification by LLMs. However, when too many candidate entity types are provided in the prompt, LLMs struggle to accurately recognize and label entities in scientific texts, where entity types are more complex than in general domains. To address this challenge, we propose TdSciNER, a type-driven approach that effectively leverages entity type information to enhance SciNER performance. In TdSciNER, we first design an entity type filter model to identify the most likely entity types present in a given sentence. Subsequently, we introduce an auxiliary multi-class entity typing task within a multi-task learning framework alongside SciNER to obtain richer contextual representations. Then, we develop a novel demonstration selection strategy based on sentence similarity and entity type diversity to activate the in-context learning capabilities of LLMs, thereby improving entity recognition accuracy across diverse scientific domains. Experiments on three datasets demonstrate that our method achieves performance comparable to fully supervised models. Further analysis validates that each entity type-driven component in TdSciNER contributes to the improvement of SciNER performance. This work provides valuable insights for future advancements in SciNER and broader information extraction tasks in scientific text mining.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
构建三个类型驱动组件来增强LLM的SciNER性能：
1. **实体类型过滤模型**（Entity Type Filter, ETF）：在推理前筛除与输入句子无关的候选实体类型，缩小候选集空间。
2. **辅助实体类型分类任务**（Auxiliary Entity Typing Task）：在多任务学习框架中与主SciNER任务联合训练，丰富上下文表示。
3. **相似性-多样性平衡的演示选择策略**：为上下文学习（ICL）选择最优的few-shot示例。

### 2.2 关键技术细节

**（1）实体类型过滤模型（ETF）**
- 使用GPT-4为每种实体类型生成领域特定描述（类型描述集D）。
- 从数据集中随机抽取子集构建**单类型句子集**（S），每个子集只含某一实体类型的标注文本，避免其他类型干扰。
- 采用BERT类编码器编码输入，计算输入文本与类型描述、类型示例集的余弦相似度，加权融合：
  - f_filter = w · cos(句子, 类型描述) + (1−w) · cos(句子, 类型示例集)
- 通过阈值δ过滤低相似度类型，得到过滤后的候选类型集C′。
- 微调阶段使用对比学习损失：正样本为句子中实际出现的类型，负样本为未出现的类型，使用InfoNCE风格损失函数。

**（2）辅助实体类型分类任务（多任务学习）**
- 辅助任务输入为句子及其已标注实体，要求LLM从候选类型集中为每个实体分配类型标签。
- 与主任务共享参数，使用交叉熵损失：
  - L_entity_typing = −Σ Σ y_ij · log(p̂_ij)
- 总损失为：L_total = L_SciNER + λ · L_entity_typing，λ为控制权重（最优为0.1或0.07）。
- 无需额外标注，直接复用SciNER数据集的类型标签。

**（3）演示选择策略（ICL）**
- 从训练集中随机选取中等长度的候选样本，构成候选集K_candidate。
- 对每个候选样本计算三个指标：
  - **语义相似度** Sim(x, k)：输入与候选句的余弦相似度；
  - **实体类型多样性** div_type(x, k)：候选样本中实体类型的归一化数量；
  - **结构多样性** div_struct(x, k)：输入与候选句的句法解析树编辑距离（TED），归一化到[0,1]。
- 综合排序得分：ICL_topk = α·Sim + β·div_type + γ·div_struct（最优比例为α=0.4, β=0.4, γ=0.2）。
- 选取top-k个样本作为演示，激活LLM的上下文学习能力。

## 6. 论文的主要结论与发现

- **总体性能**：TdSciNER在SciERC和JNLPBA上取得最高F1（70.58%和79.34%），在BC5CDR上达到89.83%，与全监督领域预训练模型（SciBERT、BioBERT）性能相当，显著超越其他LLM-based方法。
- **实体类型过滤的有效性**：去除ETF导致F1下降0.41%~2.81%，表明缩小候选类型空间能有效减少错误赋值，实体类型越多的数据集上收益越明显。
- **辅助任务的有效性**：去除辅助分类任务导致F1下降0.36%~0.99%，多任务学习能提供更丰富的上下文表示；在类型更多、更细粒度时收益更大。
- **演示选择策略**：相似度+多样性平衡策略优于任何单一策略；20-shot达到最佳性能（平均F1 79.87%）；数据集实体类型越多，ICL带来的提升越大。
- **领域匹配的编码器更重要**：领域预训练模型（SciBERT/BioBERT）优于通用模型（甚至超越更大参数量的模型），说明领域预训练对SciNER至关重要。
- **跨领域适应性**：TdSciNER在计算机科学和生物医学两个领域均表现优异；在未见领域中δ≈0.65可作为合理默认阈值。

## 7. 优点

1. **方法论创新性**：首次系统性地将实体类型信息整合到LLM-based SciNER中，设计了三个相互补充的类型驱动组件（过滤、辅助任务、演示选择），思路完整且逻辑自洽。
2. **设计精巧高效**：

   - 演示选择综合考虑相似度、实体类型多样性和结构多样性，比以往只考虑单一维度的策略更全面。
3. **实验充分且严谨**：横跨多个维度（编码器、阈值、权重、shot数、策略组合、模型规模等）的系统性分析，消融完整，提供了深入的技术洞察。

5. **跨领域普适性**：在计算机科学和生物医学两个差异明显的领域均验证有效，具有较好的通用性。
6. **启示价值**：为科学文本挖掘中如何利用领域特定知识（实体类型信息）增强LLM提供了可复用的范式。

## 8. 不足与局限

1. **性能尚未全面超越领域预训练模型**：在某些数据集上（如BC5CDR），TdSciNER（89.83%）仍未超越BioBERT（92.64%），作者承认领域预训练模型在特定领域仍具优势。
2. **实验领域覆盖有限**：仅覆盖计算机科学和生物医学两个领域，未涉及法律、金融、材料学等其他科学领域，通用性验证不足。
3. **提示设计的主观性**：手工设计提示模板可能引入主观偏差，作者也承认需要探索更系统化的自动提示生成方法，以降低人工干预引入的偏差。
4. **辅助任务仅限实体类型分类**：未探索其他信息抽取任务（如关系抽取）作为辅助任务的可能性，辅助任务设计尚有扩展空间。
5. **数据污染风险**：T5/Flan-T5可能在预训练阶段已包含实验数据集，尽管作者指出相对比较仍有效，但绝对性能可能受污染影响。
6. **计算成本**：相比纯粹的零样本或少量样本GPT方法，TdSciNER需要额外的模型微调阶段（LoRA），增加了训练复杂度，论文对训练时长和总能耗未作详细披露。
7. **阈值依赖标注分布**：最优阈值（δ）需依赖验证集调整，跨领域应用时需人工设定（作者建议默认0.65），可能在实际应用中产生性能波动。
8. **人工评估比例有限**：论文主要依赖自动指标（F1），人工评估仅有一个案例分析，对模型输出质量的定性理解不够全面。
