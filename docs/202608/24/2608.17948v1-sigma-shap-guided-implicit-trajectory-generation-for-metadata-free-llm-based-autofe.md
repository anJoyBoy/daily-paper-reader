## 摘要
近期研究利用大型语言模型（LLM）通过语义描述和基于轨迹的提示来增强自动特征工程（AutoFE）。然而，存在两个挑战限制了其在长期优化中的适用性和可扩展性：（1）在许多实际场景中，语义元数据不可用；（2）轨迹积累增加了超出上下文窗口的风险，而如果没有轨迹，生成过程可能变得不稳定，导致陷入局部最优和生成特征的高重复率。为此，我们提出了一种SHAP增强的隐式轨迹生成方法，用于无元数据自动特征工程（SIGMA），这是一种可扩展的恒定上下文优化框架。SIGMA利用SHAP值提供任务感知信号来指导组特征生成，而不是语义信息。此外，我们采用了一种暴露特征隐式轨迹（EXIT）方法，其中提示中的暴露特征隐式地代表轨迹。实验结果表明，SIGMA在几乎恒定的提示长度下，实现了与最先进（SOTA）LLM基线相当的性能。值得注意的是，EXIT显著降低了生成特征的重复率，从37.2%降至6.8%。同时，SIGMA平均仅使用5.4个特征即可匹配传统SOTA性能，展示了在特征利用方面的显著效率提升。

## Abstract
Recent research has leveraged Large Language Models (LLMs) to enhance Automated Feature Engineering (AutoFE) through semantic descriptions and trajectory-based prompting. However, there exist two challenges that limit their applicability and scalability in long-horizon optimization: (1) semantic metadata is unavailable in many practical settings, and (2) trajectory accumulation increases the risk of exceeding the context window, while without it, the generation process can become unstable, leading to becoming stuck in the local optima and a high duplicate rate of generated features. To this end, we propose a SHAP-enhanced Implicit-trajectory Generation for Metadata-free AutoFE (SIGMA), a scalable constant-context optimization framework. SIGMA leverages SHAP values to provide task-aware signals for guiding group feature generation instead of semantic information. In addition, we adopt an EXposed-feature Implicit Trajectory (EXIT) approach, where the exposed features in the prompt implicitly represent the trajectory. Empirical results demonstrate that SIGMA achieves performance comparable to the state-of-the-art (SOTA) LLM baselines with a nearly constant prompt length. Notably, EXIT significantly reduces the duplicate ratio of generated features from 37.2% to 6.8%. At the same time, SIGMA matches traditional SOTA performance with only 5.4 features on average, demonstrating substantial efficiency gains in feature utilization.

### 1. 核心问题与整体含义（研究动机与背景）
- **背景**：传统 AutoFE（如 DFS、OpenFE、AutoFeat）依赖预定义的变换搜索空间，虽在充足预算下表现良好，但搜索空间设计复杂、生成特征数量庞大且可解释性差。近期 LLM 被引入 AutoFE，利用语义描述和轨迹式提示进行特征生成，如 CAAFE、OCTree。
- **核心挑战**：
  - 许多实际场景（如医疗隐私数据、传感器日志）中**语义元数据不可用或不可靠**，语义依赖式方法受限。
  - 优化过程中**轨迹累积会导致提示长度不断增长**，有超出上下文窗口的风险；若不使用显式轨迹，LLM 容易生成重复特征或陷入局部最优。
- **研究目标**：提出一种**无元数据、恒定上下文**的 LLM-based AutoFE 框架，使优化过程可扩展、高效且稳定。

### 2. 方法论：SIGMA
SIGMA 包含三个关键步骤，整体流程见 Algorithm 1。

- **SHAP 特征分组（SHAP-based Feature Grouping）**：
  - 在原始特征集中加入一个高斯噪声列，计算所有特征（含噪声）的 SHAP 值，并做 min-max 归一化。
  - 以噪声特征的 SHAP 值作为阈值，将特征分为三组：
    - **top 组**：SHAP 值排名前 10%（至少 2 个特征）；
    - **useful 组**：SHAP 值高于噪声阈值但不在 top 组的特征；
    - **weak 组**：SHAP 值低于噪声阈值的特征。
  - 相比固定比例分组，噪声阈值可以自适应不同数据集的特征重要性分布，从而动态调节 LLM 对不同特征组的注意力。

- **组内与跨组生成（Intra-Group and Cross-Group Generation）**：
  - 每一步要求 LLM 生成**两个新特征**：
    - 一个组内特征：在同一个组内进行深度变换或多特征交互，挖掘已有高影响信号的隐藏模式；
    - 一个跨组特征：桥接高重要性与弱信号特征，构建跨组协同，增强弱特征表现。
  - 生成后由下游模型评估，只接受能带来正向提升的特征。

- **EXposed-feature Implicit Trajectory（EXIT）**：
  - 核心思想：**用提示中“可见特征集合”隐式表示优化轨迹**，而不是在提示中显式列出历史特征和操作记录。
  - 对被选作源特征的特征施加**掩码（mask）**，在后续若干步内从提示中移除：
    - top 组掩码间隔最短（2^0 = 1 步）；
    - useful 组为 2^1 = 2 步；
    - weak 组为 2^2 = 4 步。
  - 当连续 P = 5 步没有特征被接受时，重置掩码空间，恢复所有冻结特征，帮助跳出局部最优。
  - 同时跟踪失败的生成中使用的操作，在提示中禁止当前最频繁的 top-2 操作，避免 LLM 反复使用同一简单操作。但若某个操作持续带来性能提升，则不会被禁止。

### 3. 实验设计
- **数据集**：16 个公开表格二分类/多分类数据集，来自 OpenML 和 Kaggle，涵盖不同规模（最小约 736 样本，最大 50,000 样本），如 eucalyptus、diabetes、compass、jungle_chess、electricity、covertype 等。
- **数据划分**：训练/测试 8:2，使用 3 个随机种子重复划分。
- **评估指标**：主要采用 F1-score，补充 ACC 和 AUC-ROC。
- **下游模型**：XGBoost（GPU 版）。
- **基线方法**：
  - LLM-based：**CAAFE**（语义型，使用特征描述）、**OCTree**（无语义，使用树结构轨迹）。
  - 传统 AutoFE：**AutoFeat**、**DFS**（Deep Feature Synthesis）、**OpenFE**。
- **统一设置**：
  - SIGMA 和传统 AutoFE 均不提供语义信息（隐藏特征名、编码值），仅在共同操作空间（加减乘除、对数、平方根、绝对值、比率等）内进行。

### 6. 主要结论与发现
- SIGMA 在平均 F1 上与语义型 SOTA CAAFE 相当（79.80 vs 79.78），优于同属无语义的 OCTree（79.02），平均排名为 2.06，为该组最佳。
- **提示长度近乎恒定**，对比 CAAFE 和 OCTree 的轨迹不断增长，SIGMA 支持长时优化且不会超过上下文窗口。
- **EXIT 显著降低重复率**：从约 37.2% 降至 6.8%，有效提高生成效率；不带 EXIT 时约有 36.6% 生成特征是重复的。
- 与传统方法相比，SIGMA 平均仅需 **5.4 个被接受特征**即可获得约 0.8% 的性能提升；在 K=20 预算下与 OpenFE 的平均 F1 差距仅约 0.2%（79.80 vs 80.01），但用到的特征数远少于 20，特征效率更高。
- SIGMA 能生成递归复用已有特征的深层结构（最深达 9 层），传统方法难以达到。
- 更大更强的 LLM（如 Llama3.1-70B）在**小数据集上更容易过验证集**，平均 F1 反而略低于 Qwen3-4B；但在大型数据集中更强模型通常能持续提升。

### 7. 优点
- **无元数据依赖**：适合隐私敏感、无特征语义描述的真实场景。
- **恒定上下文长度**：利用 EXIT 避免轨迹累积造成的上下文窗口溢出，支持可持续的长周期优化。
- **任务感知引导**：用 SHAP 值代替语义信息提供重要度信号，既保持可解释性，又自适应不同数据集特征分布。
- **重复率大幅降低**：通过掩码暴露特征、限制高频操作，有效提升生成多样性。
- **特征高效**：用远少于传统方法的特征数量获得相当或更好的性能，便于实际部署和解释。
- **实验较为全面**：同时对比了 LLM 基线和传统 AutoFE，并做了消融、不同 LLM 规模、特征效率分析等。
