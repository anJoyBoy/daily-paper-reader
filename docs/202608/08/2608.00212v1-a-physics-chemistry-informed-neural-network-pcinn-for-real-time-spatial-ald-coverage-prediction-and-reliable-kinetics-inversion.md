## 摘要
空间原子层沉积（SALD）是工业ALD的一种领先的大气压、高通量路线，但设计和控制受限于预测表面覆盖度的成本：高保真CFD对于操作窗口扫描来说太慢，而解析模型忽略了诸如气帘之类的传输调制。我们提出了一种物理-化学信息神经网络（PCINN），一种混合代理模型，具有CFD级别的精度和实时速度：一次查询在约7毫秒内返回覆盖度，比CFD求解快约5×10^4倍，仅从30个跨越四个数量级覆盖度的训练案例中，测试R^2_log = 0.998（留一法R^2_raw = 0.974）。该架构不是黑箱：一个小型网络仅学习从操作条件到近壁浓度闭合，而已知的表面动力学是一个硬编码的、可训练的化学层，沿衬底轨迹积分。这个单标量瓶颈使其在稀疏数据下保持准确、可解释且可逆。我们进行了完整的可辨识性分析（费希尔信息、剖面似然）。吸附能E_ads和解吸速率k_des是稳健可辨识的；k_ads在单一温度下不能单独辨识（只有k_ads*c_wall可以）。在四个温度下，指前因子nu和E_ads沿一条弱可辨识的简并谷结合，其斜率为0.065 eV/decade，解析推导为k_B T_eff ln(10)，并转化为可靠性诊断：一个七化学失配矩阵表明，它在任何单一阿伦尼乌斯失配下不变，只有当第二个热激活过程出现时才发生偏移，因此斜率偏离表明存在未建模的位点异质性。数据来自模拟，其真实值由相同的动力学形式反演，因此该研究验证了流程的自洽性和可辨识性边界，而非真实参数。

## Abstract
Spatial atomic layer deposition (SALD) is a leading atmospheric-pressure, high-throughput route to industrial ALD, but design and control are limited by the cost of predicting surface coverage: high-fidelity CFD is far too slow for operating-window scans, while analytic models miss transport modulation such as the gas curtain. We present a physics-chemistry-informed neural network (PCINN), a hybrid surrogate with CFD-level accuracy at real-time speed: a query returns coverage in about 7 ms, roughly 5x10^4 times faster than a CFD solve, reaching a test R^2_log = 0.998 (leave-one-out R^2_raw = 0.974) from only 30 training cases spanning four orders of magnitude in coverage.   The architecture is not a black box: a small network learns only the operating-condition to near-wall concentration closure, while the known surface kinetics is a hard-coded, trainable chemistry layer integrated along the substrate trajectory. This single-scalar bottleneck keeps it accurate under sparse data, interpretable and invertible.   We add a full identifiability analysis (Fisher information, profile likelihood). The adsorption energy E_ads and desorption rate k_des are robustly identifiable; k_ads is not separately identifiable at a single temperature (only k_ads*c_wall is). Across four temperatures the prefactor nu and E_ads bind along a weakly identifiable degeneracy valley of slope 0.065 eV/decade, derived analytically as k_B T_eff ln(10) and turned into a reliability diagnostic: a seven-chemistry mismatch matrix shows it is invariant under any single-Arrhenius mismatch and shifts only when a second thermally activated process appears, so a slope departure flags unmodelled site heterogeneity.   Data come from simulation with known ground truth inverted by the same kinetic form, so the study verifies pipeline self-consistency and the identifiability boundary, not real parameters.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：空间原子层沉积（SALD）是工业 ALD 的重要路线，通过衬底在空间上经过由惰性气帘分隔的前驱体区域来实现原子层级的薄膜沉积。其设计与控制依赖于对衬底表面覆盖度（θ）的快速、准确预测，以及从覆盖度观测中反演吸附/解吸动力学参数。
- **核心矛盾**：现有两类模型存在本质局限——
  - **高保真 CFD 模型**：能精确解析流动-扩散-表面反应耦合，但单次求解约 357 秒，无法支撑操作窗口扫描、在线推理或迭代反演；
  - **经典解析模型**（如 Yanguasil-Elam 塞流模型）：极快但依赖"充足供给"假设，无法表示气帘对流场和近壁浓度的输运调制。
- **核心问题**：能否构建一个兼具 CFD 精度、解析模型速度和动力学反演可解释性的混合代理模型？
- **整体含义**：论文的核心论点不是"AI 替代物理仿真"，而是**物理约束下的 AI 代理可以同时具备实时速度和"自我认知"**——即明确知道自身反演结果的可靠边界。这种自我认知通过参数空间的简并几何而非拟合能力来界定，并可解析预测、统计检验，从而成为可迁移的可靠性诊断工具。

## 2. 方法论

### 2.1 核心思想：按"已知 vs 未知"拆分自由度

PCINN 将自由度严格拆分：

- **物理分支（学习）**：小型神经网络（2→64→64→64→64→1，SiLU 激活，softplus 输出保证非负）学习从操作条件 `(v*, U*)` 到**有效近壁浓度标度 C*s** 的映射——这是昂贵且难以推导的输运闭合；
- **化学分支（硬编码）**：已知的 Langmuir 表面动力学被编码为可训练的硬编码化学层，沿衬底轨迹积分得到覆盖度。

数据驱动自由度被压缩为 **单一标量 C*s**，其余全部由已知物理承载。公式化表示为：

```
(v*, U*) → [物理分支 MLP] → C*s → [化学分支：轨迹积分] → θ̄A
```

### 2.2 关键公式与算法流程

- **物理控制方程**：稳态不可压缩 Navier-Stokes 方程 + 稀物质输运方程 ∇·(−D∇c + uc) = 0；表面覆盖度服从空间平流方程：

```
Γs · vsub · ∂θ/∂x = kads·cwall·(1−θ) − kdes·Γs·θ
kdes = ν·exp(−Eads/kBT)
```

- **两段式轨迹耦合**：集成分 A 区暴露段（长度 5 mm，cwall = C*s·C0）和下游解吸段（长度 22.5 mm，cwall = 0），进行衬底平均覆盖度的积分。采用前向欧拉格式（NA = 120, Ndown = 200），与精确线性 ODE 解对照验证，最坏相对误差 1.4%，低于 5% 标签噪声。
- **损失函数**（全部在 log10 空间）：

```
L = Ldata + wC·LCs + wm·Lmono + wp·Lprior
（wC = 0.1, wm = 0.1, wp = 0.01）
```

包括：数据项（对数空间关键，因覆盖度跨越四个数量级）、近壁浓度监督、单调性先验（气帘越强近壁浓度越低）、弱动力学先验（仅单温度使用）。

### 2.3 可辨识性分析方法

- Fisher 信息矩阵：Gauss-Newton 近似，基于自动微分梯度；
- 剖面似然：固定目标参数，重新优化其余参数，考察损失曲线形状；
- 初始值漂移测试：改变参数初值观察收敛位置；
- 关键发现——退化谷斜率解析推导：

```
dEads/d(log10ν) = kB·Teff·ln10
（Teff 为采样温度的调和平均 ⟨1/T⟩⁻¹）
```

- 对 {300, 320, 340, 360} K，理论预测 0.0652 eV/decade，与观测值 0.0647 吻合至 0.7%。

## 3. 实验设计

### 3.1 数据生成（COMSOL 多物理场建模）

- **几何**：二维矩形，长 L = 30 mm，间隙高度 H = 0.2 mm；顶部有前驱体 A 入口、惰性气帘入口、前驱体 B 入口；底部为移动衬底。
- **单温度数据集**：vsub ∈ {0.05, 0.1, 0.2, 0.3, 0.5, 0.8, 1.2, 2.0} m/s × Ucurtain ∈ {0.5, 1, 2, 4, 8, 16} m/s 全交叉 = **48 例**。
- **多温度数据集**：T ∈ {300, 320, 340, 360} K × 8×3 = **96 例**。
- **数据分割**：30 训练 / 9 验证 / 9 测试（固定分割）；另做留一法交叉验证（LOOCV）。
- **标签**：衬底平均覆盖度 θ̄A（主标签，约四数量级）；近壁浓度（辅助监督）；峰值/出口覆盖度（诊断）。

### 3.2 对比方法

- **结构无关 MLP**：直接回归 log10θ̄A，同等容量和训练配置；
- **高斯过程（GP）回归**：各向异性 Matérn 核，(v*,U*) → log10θ̄A；
- **Yanguasil-Elam 塞流解析模型**：假设充足供给 c = C0 的经典基线；
- **消融实验**：改变/移除 kdes 先验、网格粗化、噪声水平变化。

### 3.3 模型失配测试矩阵（七化学 × 三机制）

- Temkin 解吸侧（β = 2, 3, 4）；
- Freundlich 吸附侧（n = 0.5, 1.5）；
- 双位点模型（能量间隔 ΔE = 0.04, 0.083, 0.148 eV）；
- 非 Fick 输运失配（浓度依赖扩散系数）。

## 6. 主要结论与发现

1. **代理精度**：仅 30 个训练案例，测试 R²log = 0.998（8 种子平均 0.9975 ± 0.0005），R²raw ≈ 0.989；LOOCV R²raw = 0.974；查询速度比 CFD 快约 5×10⁴（独立）至 1.1×10⁶ 倍（摊销）；
2. **可辨识性结论**：
   - **可辨识**：Eads = 0.773 ± 0.001 eV（真值 0.774）；kdes = 1.04 ± 0.03 s⁻¹（真值 1.0）；
   - **单温度不可辨识**：kads 仅以乘积 kads·cwall 可辨识（结构性简并，有解析证明）；
   - **多温度不可辨识**：ν 和 Eads 沿退化谷结合（斜率 ≈ 0.065 eV/decade），无法分离；χ²₁ 95% 区间约 0.6 decade；条件于 ν 后 Eads 可恢复至 0.3% 误差；
   - **关键负面发现**：多温度并不能打破 ν–Eads 简并，只是压缩为弱可辨识区间；
3. **物理约束的价值重定位**：物理约束的核心收益不在插值精度（GP 在稠密数据下逼近 PCINN），而在于稀疏数据稳定性、可反演物理参数、沿结构已知轴（停留时间）的外推能力和可辨识性边界刻画；
4. **退化斜率诊断**：斜率偏移（> μ + 1.64σ = 0.0695 eV/decade）可检测第二个热激活过程（如位点异质性），在双位点中间能量间隔处达 +4.2σ；斜率在单一 Arrhenius 过程失配下不变，可证伪未建模位点异质性；
5. **模型失配鲁棒性**：单 Arrhenius 失配（Temkin/Freundlich）下简并几何几乎不变；强失配通过拟合崩坏自报；只有双 Arrhenius（双位点）结构才移动斜率。

## 7. 优点

- **"已知物理 + 学习闭合"的硬编码架构**：将数据驱动自由度压缩为单一标量，既保证了稀疏数据下的精度，又保留了完整的可解释性和可反演性，这是混合建模中少见的优雅设计；
- **严谨且诚实的可辨识性分析**：三重证据（Fisher 信息、初始值漂移、剖面似然）系统区分了结构简并、初始值依赖和监督锚定偏置三种机制；
- **解析退化斜率定律**：将经验观察提升为可预测、可检验的理论（kBTeff ln10），并转化为带统计校准误报率的操作性诊断工具；
- **主动报告负面结果**：如"沿 Ucurtain 外推失败，两模型均无效"、"多温度不能分离 ν 和 Eads"、""自由反演点估计不可信"——这些诚实的负面发现比正面结果更有方法论价值；
- **丰富的鲁棒性验证**：包括先验消融、LOOCV、自举重采样、粗网格 LHS 重生成、噪声容忍度、模型失配矩阵等，结论扎实；
- **模型失配矩阵为诊断方法提供了预测边界**：七个化学 × 三机制 × 能量间隔扫描，系统刻画了斜率诊断的敏感范围；
- **实践指导**：末尾提供了可直接套用的从业者检查清单（剖面扫描、条件报告、几何设计工具等）。

## 8. 不足与局限

- **合成数据局限**：所有数据由模拟生成，以已知 Langmuir-Arrhenius 真实值并以相同动力学形式反演，属于"管道自洽性验证"而非真实系统参数的发现；定量标定和真实表面化学验证留待未来工作；
- **kads 不可辨识**：kads 只能以有效值报告（带弱先验），无法在单温度下独立确定；
- **ν 的绝对标定需要额外信息**：多温度仅将 ν–Eads 压缩为约 0.6 decade 的弱可辨识区间，需要独立 ν 先验或空间分辨覆盖度监督才能打破；
- **两段式集成的结构近似**：假设 A 区下游 cwall = 0；在弱气帘条件下下游前驱体串扰可能被低估；饱和端系统性欠预测 13%–36%（单标量闭合的表示能力极限）；
- **单调性先验风险**：若真实流场存在非单调特征（如回流引起的再吸附），先验会引入偏置；
- **模型范围有限**：单物种（S1）、二维稳态、等温假设（除 kdes 外参数温度无关）；未考虑温度依赖的输运参数（D(T)、μ(T)），这是作者明确承认的边界；
- **近壁浓度网格不收敛**：⟨c⟩/C0 在网格加密下不收敛（67% 跳跃），虽经论证不污染 Eads 反演，但仍需谨慎；
- **GPU 未充分利用**：串行化学积分无法利用 GPU 并行，且未尝试更高效的并行实现；
- **与真实工业数据的距离**：未与真实 SALD 膜厚/覆盖度数据对比，工程可用性仍有待验证。
