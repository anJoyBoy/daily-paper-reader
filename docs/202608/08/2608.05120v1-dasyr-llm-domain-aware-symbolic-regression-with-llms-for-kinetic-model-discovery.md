## 摘要
动力学模型发现是化学工程中的一个核心挑战，因为准确的速率表达式对于理解和控制化学与生物过程至关重要。符号回归（SR）已成为识别可解释动力学模型的一种强大的数据驱动方法，但通常在缺乏领域知识的情况下运行，经常探索物理化学上不合理的模型。大语言模型（LLM）为将领域专业知识注入这一搜索过程提供了一条有前景的途径。在此，我们提出了一种LLM引导的SR框架，将LLM模块嵌入迭代SR算法中，用于自动化动力学模型发现。LLM在每次迭代中扮演两个角色：（1）对最佳SR候选模型进行定性的物理化学评述；（2）在SR生成模型和嵌入的化学知识指导下提出新的候选速率表达式。我们的框架在四个复杂度递增的计算机模拟案例研究中进行了评估，涵盖多相催化和生物过程系统。结果表明，与最先进的SR框架相比，LLM引导的框架将识别真实模型的迭代次数减少了$41.7-79.3\%$，并且在超过一半的引导运行中，LLM直接提出了正确的模型结构。在实际场景中，每次迭代通常需要进行新的湿实验，这意味着实验工作量大幅减少。两种方法在独立验证集上的预测性能相当，所有案例研究的$R^2>0.98$。消融研究表明，SR组件和LLM规模都对这一性能有所贡献，其中缩小规模的LLM在很大程度上保持了发现效率。这些发现表明，LLM能够有效地将领域知识注入科学模型发现中，为全自动、领域感知的动力学建模流程铺平道路。

## Abstract
Kinetic model discovery is a central challenge in chemical engineering, as accurate rate expressions are essential for understanding and controlling chemical and biological processes. Symbolic regression (SR) has emerged as a powerful data-driven approach for identifying interpretable kinetic models, but usually operates without domain knowledge, often exploring physicochemically implausible models. Large language models (LLMs) offer a promising avenue for injecting domain expertise into this search. Here, we introduce an LLM-guided SR framework, embedding an LLM module within an iterative SR algorithm for automated kinetic model discovery. The LLM performs two roles at each iteration: (1) a qualitative physicochemical critique of the best SR candidates, and (2) the proposal of new candidate rate expressions guided by the SR-generated models and embedded chemical knowledge. Our framework is evaluated on four in silico case studies of increasing complexity, spanning heterogeneous catalysis and bioprocess systems. Results show the LLM-guided framework reduces iterations to identify the ground-truth model by $41.7-79.3\%$ versus a state-of-the-art SR framework, with the LLM directly proposing the correct model structure in over half of the guided runs. In practical settings, where each iteration typically requires a new wet-lab experiment, this translates into a substantial reduction in experimental effort. Predictive performance on an independent validation set is equivalent between both approaches, with $R^2>0.98$ in all case studies. Ablation studies indicate that both the SR component and the LLM scale contribute to this performance, with a reduced-size LLM largely retaining discovery efficiency. These findings demonstrate that LLMs can effectively inject domain knowledge into scientific model discovery, paving the way toward fully automated, domain-aware kinetic modelling pipelines.

- **关键洞察**：大语言模型（LLM）具备强大的推理能力和内嵌的科学先验知识，可以充当"领域知识注入器"，引导符号回归搜索走向更有物理化学意义的候选结构。
- **研究目标**：将 LLM 嵌入迭代式 SR 发现回路中，通过"定性批判 + 生成新候选"两种角色，缩小有效搜索空间，**减少所需的实验迭代次数**——因为在湿实验场景中，每次迭代对应一次真实的物理实验，成本极高。
- **整体含义**：该工作填补了一个研究空白——在已有的 SR+MBDoE 框架中，没有任何工作引入 LLM 对候选模型进行定性机理评估；而在 LLM 引导的方法中，LLM 要么只管生成、要么只管评估，从未同时承担两种角色并与 MBDoE 驱动回路结合。

## 2. 论文提出的方法论

### 2.1 核心思想
在 ADoK-S（强形式化动力学自动发现框架）的基础上，嵌入一个 LLM 模块，形成九步迭代工作流（DASyR-LLM）。LLM 不替代 SR，而是作为知识引导组件，对 SR 的最优候选进行评述并生成新结构，与 SR 候选一起参与同等的 AIC 模型选择流程。

### 2.2 算法流程（九步）
1. **数据生成**：用地面真值模型在两组初始条件下模拟，添加高斯噪声（σ=0.1）模拟实验测量。
2. **浓度轨迹 SR**：对每个物种用 PySR（PySRRegressor）拟合解析浓度轨迹 h(t)。
3. **AIC 选择**：选出每个物种每轮实验的最佳浓度模型。
4. **数值微分**：对拟合轨迹求导得到速率估计 ĥ(t)。
5. **速率表达式 SR**：以估计速率为回归目标、浓度为输入变量，搜索候选速率定律 r = m(C, θ)。
6. **参数估计**：对 SR 生成的速率模型，以 PySR 内部参数为初值，通过 ODE 积分 + L-BFGS-B 多起点（20 个随机起点）优化 SSE。
7. **LLM 模块**（核心创新）：
   - **Step 1（模型评述）**：LLM 接收 top-5 个 SR 候选模型的符号结构、参数值、AIC/NLL 指标，进行定性物理化学合理性评估（反应机理、参数量级、化学一致性等）。
   - **Step 2（模型提出）**：基于评述结果，LLM 提出 3 个新的候选速率表达式，要求结构上与现有候选不同、机理上可解释。
   - 并行执行 nLLM=3 个 LLM 实例，每轮至多产生 9 个 LLM 候选。LLM 使用 Qwen3-14B（开源），开启思考模式，温度 0.6、top-p 0.95、top-k 20。
8. **模型选择**：所有候选（SR + LLM 提出）经参数估计后按 AIC 排名（AIC = 2·NLL + 2d）。
9. **MBDoE**：若未找到真实模型，用 top-2 模型通过 Hunter-Reiner 准则优化新的初始条件，最大化两模型预测轨迹的差异，生成新实验数据加入数据集，循环直至找到真实模型或 12 次迭代预算耗尽。

### 2.3 关键公式
- 系统动态：Ċ(t) = f(C(t))
- 参数估计目标：SSE(m) = Σ‖C⁽ⁱ⁾ − Ĉₘ(t⁽ⁱ⁾; C₀, θₘ)‖²_Q
- NLL 计算（含逐物种方差估计）
- AIC = 2·NLL + 2d
- MBDoE 优化：C₀⁽ⁿᵉʷ⁾ = argmax ∫‖Ĉₘ₁ − Ĉₘ₂‖² dτ

- **计算开销数据**：LLM 推理每轮约 293–998 秒（随案例和迭代变化）；LLM 引导框架的单轮总耗时显著高于基线（LLM 推理 + LLM 候选参数估计是主要增量），但与节省的物理实验成本相比是可接受的权衡。

## 5. 实验数量与充分性

- **主实验**：4 个案例 × 2 种算法 × 4 次独立重复 = **32 次完整发现运行**。
- **消融实验**：LLM-Only Discovery（2 变体 × 2 次）+ Reduced-Size LLM（4 次）= **8 次消融运行**。
- **总计约 40 次完整的迭代式发现实验**，另有每个模型的参数置信区间、显著性检验和独立验证集评估。
- **充分性评估**：
  - ✅ 案例覆盖了从简单（异构化）到复杂（Monod 耦合 ODE）的递增难度，涵盖多相催化和生物过程两个领域。
  - ✅ 每次运行有 4 次独立重复，能反映随机性影响；LLM 的并行实例（3 个）也提供了生成多样性。
  - ✅ 消融设计能分离 SR 组件和 LLM 规模的贡献。
  - ⚠️ 局限性：全部为合成数据，未涉及真实湿实验；3/4 案例来自已发表的文献体系，LLM 可能曾在预训练中接触过这些反应（作者对此有讨论）；LLM-Only "带数据"变体给 LLM 提供了原框架中刻意不给的原始数据，属于上界场景而非公平对比。

## 6. 主要结论与发现

1. **显著加速发现**：LLM 引导框架相比基线 SR，收敛迭代次数平均减少 **41.7%–79.3%**（甲苯加氢脱烷基 50.0%、N₂O 分解 73.7%、异构化 41.7%、细菌蛋白生产 79.3%），直接对应湿实验次数的缩减。
2. **LLM 直接贡献**：16 次 LLM 引导运行中，**9 次最终模型由 LLM 直接提出**，7 次 LLM 引导搜索方向后由 SR 恢复正确结构。
3. **基线失败的对照**：N₂O 分解案例中，基线 SR 有 2/4 次运行在 12 轮预算内未收敛（得到线性近似而非正确的非线性抑制结构），而 LLM 引导在 1–4 轮内全部收敛。
4. **预测性能不损失**：两种算法在所有案例上的验证集 R² 均 >0.98，分布相似——加速发现不以牺牲模型精度为代价。
5. **参数显著性分析**：LLM 引导运行中发现的模型，非显著项移除后即得到真实速率定律，说明其收敛到正确的函数形式。
6. **消融结论**：
   - 移除 SR 后（纯 LLM），无数据访问时 1/2 运行未收敛、另 1 次需 6 轮——SR 为 LLM 提供了数据支撑的候选结构，是效率的重要组成部分。
   - 给 LLM 直接提供数据可部分补偿 SR 缺失（1/2 运行在第 1 轮直接提出正确结构）。
   - 缩小 LLM（Qwen3-8B）仍能在 2–5 轮内全部收敛，基本保持效率优势，说明框架不依赖超大模型。

## 7. 优点

- **方法设计的创新性**：首次在 SR+MBDoE 迭代回路中让 LLM 同时承担"定性机理评述"和"候选生成"双重角色，将领域知识以推理形式而非静态约束注入搜索，填补了表 1 中系统化的研究空白。
- **模块化架构**：LLM 模块与 SR、参数估计、MBDoE 解耦，可替换底层 SR 策略或 LLM 模型，扩展性好。
- **分离式提示设计**：先评述后生成的两步提示策略经过预实验验证，比直接让 LLM 生成候选更有效。
- **实验设计严谨**：每案例 4 次重复、独立验证集（含边界和外推区域）、参数置信区间与显著性检验、计算成本逐轮分解，统计刻画较完整。
- **实际意义明确**：每轮迭代对应一次湿实验，迭代数减少直接转化为实验成本节省，对资源受限的湿实验室场景有很强的实用价值。
- **消融设计有针对性**：能清晰回答"SR 组件是否有用"和"LLM 规模是否关键"两个问题。
- **可复现性**：提供了完整代码仓库（Zenodo DOI）、LLM 提示模板、逐轮日志，开放程度高。

## 8. 不足与局限

- **数据层面局限**：全部为合成数据，假设所有物种可测、噪声为零均值高斯分布、无系统偏差或缺失观测，与实际湿实验室条件存在差距。
- **LLM 预训练污染风险**：3/4 案例来自化学工程经典文献，LLM 可能在预训练中见过这些反应体系（虽然作者论证了框架设计缓解了记忆效应，但无法完全排除）。
- **计算成本较高**：LLM 引导方案每轮计算成本显著高于基线（LLM 推理 + 额外参数估计），虽然物理实验节省可补偿，但纯计算场景（如大规模筛选）中优势可能减弱。
- **人工干预环节**：LLM 输出为自由文本，需要手动解析为结构化表达式，尚未实现全自动化；结构化输出（JSON）被刻意放弃以保证推理灵活性。
- **参数估计的脆弱性**：多起点 L-BFGS-B 不保证全局最优；LLM 提出的候选没有初始参数值，差的初始化可能导致结构正确的模型被 AIC 误淘汰。
- **消融实验范围有限**：消融仅在单个案例（细菌蛋白生产）上进行，LLM-Only 变体每个配置只有 2 次运行，统计功效有限。
- **缺少真实世界验证**：没有在真实实验数据上评估，实际湿实验中的噪声模型、不可测变量、系统误差等挑战尚未验证。
- **无提前停止准则**：论文明确表示未采用 AIC 差分阈值等提前停止规则，而在真实应用中（真实模型未知）何时停止迭代仍是一个未解决的开放问题。
