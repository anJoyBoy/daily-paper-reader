## 摘要
尽管大型语言模型（LLMs）取得了显著进展，从文本中进行本体学习仍然具有挑战性，因为LLMs可能会产生幻觉领域术语、生成不一致的格式，并且更倾向于层级关系而非关联关系。在LLMs4OL 2026挑战赛中，我们使用离线检索增强的少样本提示流水线，同时处理端到端旗舰任务（任务A）和本体扩展复用任务（任务B）。我们的系统采用Qwen2.5-14B-Instruct和all-MiniLM-L6-v2进行演示检索，为任务A选择前5个示例，为任务B选择前2个示例。左侧截断的上下文窗口策略在长提示中保留了任务指令。对于任务B，生成的三元组经过确定性词汇约束过滤，当至少一个端点属于样本的封闭术语/类型词汇表时保留三元组，并移除初始本体中的重复项。该方法在任务B上实现了0.8692的语义图相似度、0.9200的术语类型标注F1和0.8540的分类发现F1，而任务A实现了0.7416的语义图相似度。然而，没有提取非分类关系，这突显了封闭的、面向分类的关系词汇表的局限性。

## Abstract
Ontology learning from text remains challenging despite significant progress in Large Language Models (LLMs), which can hallucinate domain terms, produce inconsistent formats, and favor hierarchical over associative relations. In the LLMs4OL 2026 Challenge, we address both the End-to-End Flagship Task (Task A) and Ontology Extension Reuse Task (Task B) using an offline retrieval-augmented few-shot prompting pipeline. Our system employs Qwen2.5-14B-Instruct with all-MiniLM-L6-v2 for demonstration retrieval, selecting the top-5 examples for Task A and top-2 for Task B. A left-truncated context-windowing strategy preserves task instructions within long prompts. For Task B, generated triples undergo deterministic vocabulary-constrained filtering, retaining triples when at least one endpoint belongs to the sample's closed term/type vocabulary and removing duplicates of the initial ontology. The approach achieves Semantic Graph Similarity of 0.8692, Term-Typing F1 of 0.9200, and Taxonomy Discovery F1 of 0.8540 on Task B, while Task A achieves 0.7416 Semantic Graph Similarity. However, no non-taxonomic relations are extracted, highlighting limitations of closed, taxonomy-oriented relation vocabularies.

## 2. 论文提出的方法论

### 2.1 总体框架
- 提出一种**离线检索增强生成（Offline RAG）框架**，无需微调 LLM 参数，仅通过动态检索语义相似的训练示例构造少样本提示。
- 核心组件：密集语义检索 → 提示构建 → LLM 推理 → （Task B）混合抽取与词汇约束过滤 → 输出符合挑战格式的 JSON。

### 2.2 Dense Semantic Retrieval（密集语义检索）
- 使用 `sentence-transformers/all-MiniLM-L6-v2` 模型将训练文档和输入文档编码为固定长度向量。
- 通过**余弦相似度**度量输入文档与训练示例的语义相关性：
  \[
  \text{sim}(q, d_i) = \frac{e_q \cdot e_i}{\|e_q\| \|e_i\|}
  \]
- 检索 top-k 相似示例作为上下文演示：**Task A 取 top-5，Task B 取 top-2**。原因：Task A 需要覆盖更广的推理范围（术语抽取、类型标注、分类发现、关系抽取），而 Task B 已提供候选词汇表和部分本体作为额外上下文，因此减少演示数量以降低提示截断风险。

### 2.3 提示构建与本体生成
- 使用 **Qwen2.5-14B-Instruct** 模型进行推理，16-bit 精度、贪心解码（关闭采样）、batch size 为 10。
- 输出预算：Task A 最大 900 token（适应更长输出），Task B 最大 320 token。
- 输入截断：虽然模型支持 32,768 token 的上下文窗口，但为了控制 KV cache 内存和 logits 尖峰，将输入长度限制为 **3,072 token**，采用**左截断策略**：若提示超长，优先丢弃最旧的检索演示，保证系统指令和目标查询完整保留在提示末尾。
- 为 Task A 和 Task B 设计不同的系统提示：
  - Task A：要求从段落中抽取所有三元组，并**逐字复制**主语/宾语，将自然语言关系短语映射到封闭关系集合；
  - Task B：要求**只预测直接父关系**，将术语连接到最具体的正确类型。
- 响应解析：采用三级回退解析器（直接 JSON 解析 → 正则提取首个数组 → 逐行正则恢复引号三元组），并去除重复三元组和自反自环。

### 2.4 Task B 的混合抽取与词汇约束过滤
- **第一步（混合抽取）**：将 LLM 生成结果与**基于邻近度的术语类型启发式规则**合并。该规则扫描文档，当预定义术语与类型的句级共现距离落在高置信阈值内时，分配 instance-of 关系，作为召回率提升器。
- **第二步（词汇约束过滤）**：
  - 三元组 [h, r, t] 仅当**至少一个端点（h 或 t）**属于该样本的已知词汇表（提供的术语 ∪ 提供的类型 ∪ 初始本体中出现过的实体）时才保留；
  - 丢弃与初始本体重复的三元组；
  - 这是严格的精确匹配过滤，不进行词汇修复或近似匹配。

### 2.5 输出生成
- 将验证后的三元组转换为挑战官方 JSON 格式；Task B 只输出新增三元组，保留初始本体结构。

## 6. 论文的主要结论与发现

- 提出的离线 RAG + 词汇约束过滤框架在 Task B 上表现优异，**语义图相似度 0.8692**，**Term-Typing F1 0.9200**，**Taxonomy Discovery F1 0.8540**，表明在封闭词汇约束下，词汇过滤可有效防止越界词汇幻觉。

- 整体上，检索增强与确定性词汇对齐的组合是可行且有效的本体学习方案，但非分类关系抽取仍需混合神经符号方法、受约束解码等手段来改进。
