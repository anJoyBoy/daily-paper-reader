## 摘要
事件抽取旨在识别事件触发词、分类事件类型并抽取论元，以构建结构化事件表示。尽管在领域内表现强劲，但由于上下文表达和事件模式的差异，开发跨领域稳健泛化的模型仍具挑战性。先前的统一多任务方法提高了领域内准确性，但在应用于未见领域时灵活性有限。即使是在推理时提供完整事件本体的大语言模型方法，通常也逊色于较小的、任务特定的微调模型。我们提出一个统一的多领域多任务训练框架，在单个模型中建模异构事件模式。我们的方法引入领域条件信号，与任务特定提示联合使用，能够动态适应数据集特定的模式，而无需在推理时提供完整事件标签集。该框架支持流水线和端到端提取设置，促进有效的任务和领域级迁移。在多样的事件抽取基准上的实验表明，我们的方法实现了有竞争力的性能、强跨领域泛化和实用可扩展性，同时保持了领域特定的精确性。

## Abstract
Event extraction aims to identify event triggers, classify event types, and extract arguments to construct structured event representations. Despite strong in-domain performance, developing models that generalize robustly across domains remains challenging due to variations in contextual expressions and event schemas. Prior unified and multi-task approaches improve in-domain accuracy but exhibit limited flexibility when applied to unseen domains. Even large language model-based methods that provide full event ontologies at inference time often underperform compared to smaller, task-specific fine-tuned models. We propose a unified multi-domain and multi-task training framework that models heterogeneous event schemas within a single model. Our approach introduces domain conditioning signals, jointly with task-specific prompts, enabling dynamic adaptation to dataset-specific schemas without requiring complete event label sets at inference time. The framework supports both pipeline and end-to-end extraction settings, facilitating efficient task- and domain-level transfer. Experiments on diverse event extraction benchmarks demonstrate that our method achieves competitive performance, strong cross-domain generalization, and practical scalability, while preserving domain-specific precision.

- **研究问题**：事件抽取（Event Extraction, EE）跨领域泛化困难。不同领域（如网络安全、生物医学、新闻、维基百科）在事件模式、上下文表达、事件本体（event schema）上存在显著差异，导致一个模型在多个异构领域间迁移时性能大幅下降。
- **现有方法的不足**：
  - 传统判别式方法为每个领域训练单独的模型，缺乏共享和扩展性。

  - 基于大语言模型（LLM）的零样本或指令微调方法，即使推理时提供完整事件本体，仍比经过微调的小规模专用模型性能差（F1 更低），且存在模式遵循（schema adherence）薄弱、输出格式不稳定等问题。
- **论文的核心主张**：通过在统一文本到文本（text-to-text）生成框架中引入**显式的领域条件信号**（domain conditioning）和**任务特定提示**（task-specific prompts），使单个模型能够动态适应不同数据集的异构事件模式，同时不依赖推理时提供完整事件标签集，从而兼顾多领域覆盖、任务灵活性和部署效率。

### 二、论文提出的方法论

- **整体框架**：基于编码器-解码器（encoder-decoder）的 T5-Base 模型，将所有事件抽取子任务统一建模为条件文本生成问题。输入序列由三部分组成：
  - **领域指示符**：如 `[Domain: Geneva]`，提供轻量级领域上下文信号，指示模型按目标领域的事件语义和模式生成输出。
  - **任务提示**：如 `[Task: TI]`（触发词识别）、`[Task: TC]`（触发词分类）、`[Task: EAE]`（论元抽取）、`[Task: EE]`（端到端事件抽取）等，通过固定自然语言模板控制不同子任务。
  - **输入文本 S**（在流水线模式下还包含中间预测结果如 `<trigger>` 或 `(w, t)`）。
- **目标函数**：采用多任务联合负对数似然（NLL）损失，条件概率形式为：
  - pθ(y | d, π_t, S) = ∏ pθ(y_i | y_{<i}, d, π_t, S)
  - 在全部任务和领域上联合优化，使模型学习共享结构表示，同时保持领域特定性能。
- **多任务模式设计**（见原文表 1）：
  - **流水线模式（Pipeline）**：
    - ED–P1：触发词识别（TI），输入 `[Domain][Task:TI] S`，输出 `<trigger> w`；
    - ED–P2：触发词分类（TC），输入 `S + <trigger>`，输出 `w = t`；
    - EAE–P：论元抽取，输入 `S + (w, t)`，输出 `a1=r1; a2=r2`。此模式下 EAE 可显式使用从预测类型和领域实例化的角色约束，提升论元抽取的精确度，但存在错误传播问题。
  - **端到端模式（End-to-End）**：
    - ED–E2E：联合触发词识别与分类（TI+TC），输入 `[Task: TI+TC] S`，输出 `<trigger> w = t`；
    - ED+EAE–E2E：完全端到端生成，输入 `[Task: EE] S`，一步生成完整事件结构 `w=t|a1=r1;a2=r2`，不借助中间结果，减少级联错误，但缺乏显式模式约束。
- **后处理**：采用确定性解析程序，将生成文本线性序列解析为结构化事件记录（触发词跨度、类型、偏移量 + 论元文本、角色、偏移量），保证评估的一致性。
