## 摘要
科学命名实体识别（SciNER）在从科学文本中进行信息抽取和知识发现中发挥着关键作用。近年来，大语言模型（LLMs）已展现出以最少人力投入实现具有竞争力的SciNER性能的能力。现有研究强调了在提示中纳入候选实体类型信息对于LLMs准确识别和分类实体的重要性。然而，当提示中提供过多候选实体类型时，LLMs难以准确识别和标注科学文本中的实体，因为科学文本中的实体类型比通用领域更为复杂。为应对这一挑战，我们提出了TdSciNER，一种类型驱动的方法，有效利用实体类型信息来增强SciNER性能。在TdSciNER中，我们首先设计了一个实体类型过滤模型，以识别给定句子中最可能出现的实体类型。随后，我们在多任务学习框架中引入了一个辅助的多类实体类型标注任务，与SciNER共同训练，以获得更丰富的上下文表示。然后，我们开发了一种基于句子相似度和实体类型多样性的新颖演示选择策略，以激活LLMs的上下文学习能力，从而提高跨不同科学领域的实体识别准确性。在三个数据集上的实验表明，我们的方法达到了与全监督模型相当的性能。进一步的分析验证了TdSciNER中每个实体类型驱动组件都对SciNER性能的提升有所贡献。这项工作为未来SciNER以及科学文本挖掘中更广泛的信息抽取任务的进展提供了宝贵的见解。

## Abstract
Scientific named entity recognition (SciNER) plays a crucial role in information extraction and knowledge discovery from scientific texts. Recently, large language models (LLMs) have demonstrated the capacity to achieve competitive SciNER performance with minimal human effort. Existing research highlights the importance of incorporating candidate entity type information for accurate entity recognition and classification by LLMs. However, when too many candidate entity types are provided in the prompt, LLMs struggle to accurately recognize and label entities in scientific texts, where entity types are more complex than in general domains. To address this challenge, we propose TdSciNER, a type-driven approach that effectively leverages entity type information to enhance SciNER performance. In TdSciNER, we first design an entity type filter model to identify the most likely entity types present in a given sentence. Subsequently, we introduce an auxiliary multi-class entity typing task within a multi-task learning framework alongside SciNER to obtain richer contextual representations. Then, we develop a novel demonstration selection strategy based on sentence similarity and entity type diversity to activate the in-context learning capabilities of LLMs, thereby improving entity recognition accuracy across diverse scientific domains. Experiments on three datasets demonstrate that our method achieves performance comparable to fully supervised models. Further analysis validates that each entity type-driven component in TdSciNER contributes to the improvement of SciNER performance. This work provides valuable insights for future advancements in SciNER and broader information extraction tasks in scientific text mining.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：科学命名实体识别（SciNER）是科学文本挖掘、知识图谱构建、智能问答等下游应用的基础任务，涉及生物医学、计算机科学、材料学等多个领域。传统的深度学习方法需要大量标注数据，而基于预训练语言模型（如 SciBERT、BioBERT）的方法虽有所提升，仍依赖领域标注数据，跨领域泛化受限。
- **核心问题**：使用大语言模型（LLMs）进行 SciNER 时，现有方法通常在提示中列出全部候选实体类型。然而，科学文本中的实体类型远比通用领域更细粒度、更专业，且大多数句子只包含少数几种实体类型。在提示中提供过多无关候选类型，会降低 LLM 的识别与分类准确率。此外，LLM 的生成式特征与 SciNER 的序列标注任务存在错配。
- **研究动机**：尽管实体类型信息在通用领域 NER 中被证明有效，此前尚无工作系统地在 LLM 中利用实体类型信息来增强 SciNER。TdSciNER 旨在填补这一空白，通过过滤无关类型、丰富上下文表征、激活上下文学习能力，在不增加标注成本的前提下逼近全监督模型性能。

## 2. 方法论

论文提出 **TdSciNER**（Type-driven SciNER），一个类型驱动的多任务学习框架，包含三个核心组件：

### （1）实体类型过滤模型（Entity Type Filter）
- **目的**：为每个输入句子筛选最可能出现的实体类型，缩小候选类型空间，减少 LLM 的类型混淆。
- **构建方式**：
  - 使用 GPT-4 为每个实体类型生成领域描述（描述集 D）。
  - 从原始数据集随机抽取只含单一实体类型的句子构建类型例句集 S，以捕获类型语义特征。
  - 采用 BERT-like 编码器（如 SciBERT、BioBERT）对输入文本进行编码。
  - 分别计算输入句子与类型描述、类型例句的余弦相似度，并按权重 w 加权融合（公式 7）。
  - 通过阈值 δ 剔除相似度较低的类型，生成过滤后的候选类型集 C′。
- **训练**：基于对比学习进行微调（公式 8），将句子中实际出现的实体类型作为正样本，未出现的作为负样本，优化相似度排序。
- **提示策略**：在提示中先让 LLM 识别所有潜在科学实体，再用 C′ 作为引导注记（Note），软性提示可能的类型分布，并不会遗漏正确的实体类型。

### （2）辅助实体类型标注任务（Auxiliary Entity Typing Task）
- **目的**：通过多任务学习增强模型的上下文表征能力，帮助 LLM 更准确地将实体分配到正确类型。
- **机制**：在微调阶段，将实体类型分类作为辅助任务，与主 SciNER 任务共享模型参数。对于输入文本中已标注的每个实体，模型需从候选类型集中为其分配类型标签。
- **损失函数**：辅助任务使用交叉熵损失（公式 9、10），总损失为 主任务损失 + λ × 辅助任务损失（公式 11）。λ 为辅助任务权重，经实验确定最优值为 0.1（SciERC、JNLPBA）和 0.07（BC5CDR）。
- **关键优势**：不需要任何额外的标注数据，实体类型标签在原有 SciNER 数据集中已存在。

### （3）演示选择策略（Demonstration Selection for ICL）
- **目的**：在推理阶段激活 LLM 的上下文学习（ICL）能力，通过精选 few-shot 示例提升识别性能。
- **选择指标**（三个维度）：
  1. **句子语义相似度** Sim(x, k_i)：候选示例与输入句子的余弦相似度。
  2. **实体类型多样性** div_type(x, k_i)：候选示例包含的实体类型数量（归一化）。
  3. **句法结构多样性** div_struct(x, k_i)：基于句法解析树之间的 Tree Edit Distance（公式 12）。
- **组合策略**（公式 13）：ICL_topk = α·Sim + β·div_type + γ·div_struct，通过加权排序选取 top-k 个示例。
- **候选池构建**：从训练集中随机抽取适量中等长度的句子，避免过长或过短带来的负面影响。最佳权重组合为 α=0.4、β=0.4、γ=0.2（在 JNLPBA 上验证）。

## 6. 主要结论与发现

- **整体性能**：TdSciNER（Flan-T5-11B）在 SciERC（F1=70.58%）、JNLPBA（79.34%）上达到最优，在 BC5CDR（89.83%）上接近最优，与全监督强基线（SciBERT、BioBERT）水平相当。TdSciNER 的 3B 版本甚至超过 7B 的 UniNER，展示了方法的高效性。
- **实体类型过滤有效**：去除 ETF 导致 F1 下降 2.26%（SciERC）、2.81%（JNLPBA）、0.41%（BC5CDR）；实体类型越多，ETF 的收益越明显。

- **ICL 演示选择有效**：在 TdSciNER 基础上替换为随机演示选择时，三个数据集上的 F1 均有明显下降（SciERC −1.52%、JNLPBA −0.98%、BC5CDR −0.37%）；采用综合相似度与多样性的选择策略后，性能达到最佳，且最佳 shots 数在不同数据集上存在差异（SciERC 为 5，JNLPBA 为 10，BC5CDR 为 20），说明示例选取确实能够激活 LLM 的上下文学习能力。
- **模型规模效应明显**：将 Flan-T5 从 small 增至 XXL（11B），F1 持续提升，其中 XXL 相比 large 提升最大（SciERC +3.12%、JNLPBA +2.45%、BC5CDR +1.89%），验证了大模型容量对 SciNER 性能的关键作用。

- **类型过滤模型选择**：SciBERT/BioBERT 作为实体类型过滤器的底座优于通用 BERT，且 7 种编码器的对比表明，领域语义匹配对过滤质量至关重要；阈值 δ 的最优值随实体类型数量和数据复杂度变化，简单固定阈值虽略降但总体稳定。

## 7. 局限性与未来工作

- **对候选类型过滤的依赖**：TdSciNER 的性能高度依赖实体类型过滤模型的准确性；若过滤阶段未能召回真实出现的类型，后续 LLM 将无法正确识别，导致误差传播。当前过滤模型的召回率虽高但并非完美，未来可引入更鲁棒的负采样或迭代过滤策略。
- **类型描述与例句的质量**：类型描述依赖 GPT-4 生成，例句从原始数据集中单一类型句子抽取，质量受限于数据集标注质量；在实体类型定义模糊或标注噪声大时，过滤模型可能产生偏差。
- **计算开销**：尽管推理阶段与 GPT-3.5-turbo 相当，但训练阶段仍需微调 Flan-T5-XXL 等大规模模型，对 GPU 显存要求较高；同时实体类型过滤模型和句法多样性计算引入了额外预处理成本。
- **演示选择策略的适用性**：Tree Edit Distance 需要解析句法树，对低资源语言或非英语文本的适配性尚未验证；加权组合参数（α、β、γ）目前仅在 JNLPBA 上调优，在不同领域或数据集上可能需重新搜索。
- **评估范围的限制**：仅验证了三个英文科学数据集，且实体类型数均在 2~6 之间；对于实体类型更多（如数十种）或嵌套/重叠实体的场景（如 GENIA 的更多类型），TdSciNER 的有效性有待进一步评估。
- **未来工作**：探索将大模型直接用于类型过滤（而非仅用 BERT 类编码器）；引入交互式提示或自适应演示选择；在更多领域（如材料、化学）和更多语种上扩展验证；研究类型过滤模型与主模型联合训练的可能性，以缓解误差传播。

## 8. 总结

TdSciNER 通过实体类型过滤、辅助多任务学习和基于多样性的演示选择三个组件，系统性地在 LLM 中引入类型信息来解决科学命名实体识别问题。实验表明，该方法在多个科学数据集上达到与全监督预训练模型相当甚至更优的性能，同时显著优于通用 LLM 基线。该工作为 LLM 在科学信息抽取中的应用提供了“类型驱动”的新范式，尤其在候选类型众多、数据标注有限的场景下具有很强的实用价值。
