## 摘要
尽管大型语言模型（LLMs）取得了显著进展，但从文本中进行本体学习仍然具有挑战性，因为LLMs可能产生虚构的领域术语、生成不一致的格式，并且偏向于层级关系而非关联关系。在LLMs4OL 2026挑战赛中，我们使用离线检索增强的少样本提示流水线，同时处理端到端旗舰任务（任务A）和本体扩展复用任务（任务B）。我们的系统采用Qwen2.5-14B-Instruct与all-MiniLM-L6-v2进行示例检索，为任务A选择前5个示例，为任务B选择前2个示例。一种左截断的上下文窗口策略可在长提示中保留任务指令。对于任务B，生成的三元组经过确定性的词汇约束过滤，当至少一个端点属于样本的封闭术语/类型词汇表时保留该三元组，并移除初始本体中的重复项。该方法在任务B上实现了0.8692的语义图相似度、0.9200的术语类型标注F1和0.8540的分类法发现F1，而任务A实现了0.7416的语义图相似度。然而，没有提取出非分类关系，这凸显了封闭的、面向分类法的关系词汇表的局限性。

## Abstract
Ontology learning from text remains challenging despite significant progress in Large Language Models (LLMs), which can hallucinate domain terms, produce inconsistent formats, and favor hierarchical over associative relations. In the LLMs4OL 2026 Challenge, we address both the End-to-End Flagship Task (Task A) and Ontology Extension Reuse Task (Task B) using an offline retrieval-augmented few-shot prompting pipeline. Our system employs Qwen2.5-14B-Instruct with all-MiniLM-L6-v2 for demonstration retrieval, selecting the top-5 examples for Task A and top-2 for Task B. A left-truncated context-windowing strategy preserves task instructions within long prompts. For Task B, generated triples undergo deterministic vocabulary-constrained filtering, retaining triples when at least one endpoint belongs to the sample's closed term/type vocabulary and removing duplicates of the initial ontology. The approach achieves Semantic Graph Similarity of 0.8692, Term-Typing F1 of 0.9200, and Taxonomy Discovery F1 of 0.8540 on Task B, while Task A achieves 0.7416 Semantic Graph Similarity. However, no non-taxonomic relations are extracted, highlighting limitations of closed, taxonomy-oriented relation vocabularies.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：本体（Ontology）是知识表示的核心载体，为异构信息系统提供语义互操作与自动推理能力。传统手工本体构建成本高、难扩展，自动本体学习（Ontology Learning, OL）应运而生。
- **现有挑战**：尽管大型语言模型（LLMs）在零样本/少样本推理上表现优异，但在本体学习任务中仍存在三大核心问题：
  - **幻觉问题**：生成不在预定义本体词汇表中的虚构或词汇不一致的领域术语；
  - **格式不一致**：生成结果缺乏结构化格式，难以直接集成到本体工程流程；
  - **关系偏好**：LLM明显偏向层级关系（如subclass-of）的预测，而在识别复杂语义关联关系上表现不佳。
- **研究意义**：本文面向LLMs4OL 2026挑战赛（第3届本体学习国际评测），聚焦两个集成性任务——端到端旗舰任务（Task A）和本体扩展复用任务（Task B），旨在构建自动化、无幻觉、格式合规的本体学习流水线，推动LLM在本体工程中的可靠落地。

### 2. 提出的方法论

#### 2.1 总体框架：离线检索增强生成（Offline RAG）
- **核心思想**：不微调LLM，而是通过稠密语义检索动态选出语义相似的训练示例，构造检索增强的少样本提示，引导LLM生成结构化本体三元组。
- **整体流程**：输入文档 → 稠密语义检索 → 提示构造 → LLM推理 → 后处理过滤 → 挑战合规JSON输出。

#### 2.2 关键模块与技术细节

**（1）稠密语义检索（Dense Semantic Retrieval）**
- 使用 `sentence-transformers/all-MiniLM-L6-v2` 将训练文档和输入文档编码为固定长度向量；
- 以余弦相似度衡量语义相关性：
  \[
  \text{sim}(q, d_i) = \frac{e_q \cdot e_i}{\|e_q\| \|e_i\|}
  \]
- 按相似度排序，选取top-K示例作为上下文演示：**Task A取top-5**（旗舰任务需更广覆盖），**Task B取top-2**（因已有候选词汇和部分本体作为额外上下文，减少演示数量可降低截断风险）。

**（2）提示构造与LLM推理**
- 使用 **Qwen2.5-14B-Instruct** 作为生成模型，16位精度，贪心解码（禁用采样），批量大小为10；
- 输出预算：**Task A最大900个新token**，**Task B最大320个新token**；
- **左截断上下文窗口策略**：最大输入长度限制为3,072 token（因80GB VRAM的KV缓存和logits扩展约束）。若提示超长，优先丢弃最旧的检索演示，确保系统指令和末尾的目标查询完整保留。

**（3）任务B的混合提取与词汇约束过滤**
- **第一步——混合提取**：为弥补LLM在分类判断上的遗漏，引入基于邻近度的术语类型启发式规则：扫描文档，若预定义术语与类型在句级共现且词汇距离低于高置信阈值，则分配 instance-of 关系，与LLM输出合并作为召回增强；
- **第二步——词汇约束过滤**：三元的任一端点（头或尾）必须精确匹配样本已知词汇表（提供的术语 ∪ 提供的类型 ∪ 初始本体中的实体），否则直接丢弃；同时删除与初始本体重复的三元组；不进行词汇模糊修复，严格精确匹配。

**（4）输出解析**
- 三段式回退解析器：直接JSON解析 → 正则提取第一个良构数组 → 逐行正则恢复引号三元组；
- 移除重复三元组和自反自环（trivial self-loops）。

### 6. 主要结论与发现

- **Task B（复用任务）结果显著**：
  - Semantic Graph Similarity **0.8692**；
  - Term-Typing F1 **0.9200**（Precision 0.9324，Recall 0.9079）；
  - Taxonomy Discovery F1 **0.8540**（Precision 0.9369，Recall 0.7846）。
- **Task A（旗舰任务）结果中等**：
  - Semantic Graph Similarity **0.7416**，Exact Match仅0.5353，二者差距达20个百分点，说明模型语义理解能力强，但词汇精确复现能力弱。
- **关键失败**：两类任务的 **Non-Taxonomic Relation Extraction F1均为0.0000**，这是最大的瓶颈。原因有二：(1) 提示中将关系映射限制为6个严格分类/类型关系字符串（is-a, instance-of, disjoint with, equivalent class, part of, has part）；(2) 无法判定黄金数据中非分类关系本身的占比。
- **核心结论**：离线RAG + 确定性词汇约束过滤能有效防止越界词汇幻觉，提高语义一致性，尤其适合封闭词汇场景；但面向开放关系词表的关系抽取仍是LLM本体学习的关键瓶颈。

### 7. 优点

2. **左截断上下文策略**：解决长提示下指令丢失问题，且考虑了VRAM约束，是工程上的务实设计；
