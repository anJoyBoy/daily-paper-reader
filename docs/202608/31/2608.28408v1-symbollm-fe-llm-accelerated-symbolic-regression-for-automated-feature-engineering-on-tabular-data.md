## 摘要
表格数据作为机器学习中的核心数据格式，往往由于特征信息量不足而缺乏高性能建模所需的判别能力。自动化特征工程（AutoFE）通过自动化特征生成和选择来克服这一问题，确保模型性能和运行效率。然而，传统的AutoFE通常因为依赖盲目的数学变换而产生可解释性较差的特征，而基于大语言模型（LLM）的AutoFE则面临需要昂贵的多轮迭代来生成高效用特征以有效提升模型性能的挑战，并且存在固有的偏差和幻觉风险。在本文中，我们将符号回归与LLM相结合用于特征工程（SymboLLM-FE），以解决这些挑战。我们通过符号回归提取与目标强相关且能增强模型性能的数学表达公式，然后利用具有丰富先验知识的LLM对其进行精炼，以确保可解释性。在六个真实世界数据集和四个Kaggle竞赛上的实证结果表明，SymboLLM-FE优于现有的AutoFE。SymboLLM-FE还通过采用基于统计先验的LLM精炼机制和单位数次的LLM调用，解决了可解释性差和迭代次数多这两大挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

- **现有 AutoFE 的两难困局**：
  - **传统 AutoFE**（如 AutoFeat、OpenFE）依赖盲目的数学变换和启发式搜索，虽能提升性能，但生成特征缺乏语义、可解释性差，难以满足金融因子挖掘等需要业务逻辑验证的场景。
  - **LLM-based AutoFE**（如 CAAFE、OcTree、FEBP）利用大模型先验知识生成语义清晰的特征，但需要多轮迭代与下游模型交互（如 OcTree 需约 50 轮）才能收敛，成本高；同时存在幻觉、隐性偏差、生成无效特征的风险。
- **研究目标**：设计一种既能高效生成高性能特征、又能保证特征可解释性的 AutoFE 框架，同时避免 LLM 的高迭代开销和幻觉问题。

## 2. 方法论：SymboLLM-FE

### 2.1 核心思想
- 将**符号回归**与**LLM**协作：符号回归负责从数据中挖掘与目标强相关、数学上显式的候选公式；LLM 负责将这些“不透明”公式精炼为语义清晰、业务可解释的代码特征。
- 关键定位：LLM 不是“生成器”，而是“精炼器 / 语义过滤器”，其输入被锚定在符号回归的统计结果上，从而消除幻觉和随意生成。

### 2.2 第一级：基于符号回归的公式构建
- **特征排序**：先计算每个特征与目标的 Spearman 相关系数，按系数升序排列得到有序特征序列。
- **扩展-滑动窗口策略**：
  - 初始窗口大小 `k = ⌊n/2⌋`；
  - **扩展阶段**：`k` 从 `⌊n/2⌋` 逐步增加到 `n`；
  - **滑动阶段**：对每个固定的 `k`，窗口以步长 1 向右滑动，生成不同特征子集。
  - 该策略将子集数量从指数级 `O(2^n)` 降到多项式级 `O(n²)`，公式为：
    - n 为偶数时：`(n+2)(n+4)/8`
    - n 为奇数时：`(n+3)(n+5)/8`
- **符号回归建模**：对每个生成的特征子集训练一个符号回归模型（基于 gplearn 遗传编程），得到从子集到目标的显式公式 `τ_i`，并记录性能 `P_f(S_i)`，最终形成公式仓库 `R = {(S_i, P_f(S_i), τ_i)}`。
  - 操作符集包含 14 种受保护算术和超越函数（如 `add`, `mul`, `div`, `sqrt`, `log`, `sin`, `cos`, `tan`, `max`, `min` 等），确保数值稳定。
  - 使用 parsimony 惩罚（奥卡姆剃刀）控制复杂度，防止过拟合和膨胀。

### 2.3 第二级：基于 LLM 的特征生成与精炼
- **LLM 引导的代码生成**：将公式仓库中的每个公式转换为自然语言描述，与任务背景和代码生成提示拼接，LLM 通过思维链生成可执行的 Python/Pandas 特征工程代码。
- **下游预测器性能验证**：执行生成代码，得到新特征并合并到原始数据集，训练下游预测器（如 CatBoost、TabPFN），在验证集上评估性能。
- **迭代式特征精炼**：将性能反馈、已用特征和代码回传给 LLM，进行多轮优化，直到获得相对最优性能。
- **特征控制与去冗余**：
  - 动态剪枝：对导致验证性能下降的特征进行删除；
  - 去冗余：LLM 作为语义过滤器，识别符号回归公式与现有特征之间的数学等价性，移除多重共线性；
  - 限制 LLM 仅在统计验证的子空间内操作，抑制幻觉和噪声。

### 2.4 数据划分与防泄漏
- 严格采用交叉验证框架：训练集仅用于符号回归的公式构建；验证集用于 LLM 反馈调参；测试集仅用于最终评估。
- 下游模型架构和参数固定，与验证阶段隔离，避免信息泄漏。

## 6. 讨论与深入分析

### 6.1 为什么符号回归 + LLM 能优于纯 LLM？
- 纯 LLM 生成特征时缺乏数据驱动的锚定，容易产生“看似合理但统计无效”的特征；符号回归提供与目标强相关的数学公式，相当于给 LLM 一个“高置信候选集”。
- LLM 在精炼时只做语义解释、代码实现和冗余筛除，不在开放语义空间中自由创造，从根本上抑制幻觉和隐性偏差。
- 符号回归的显式公式天然具有可解释性，LLM 的语义翻译进一步拉近了特征与业务知识的距离，使金融、医疗等高风险场景可以人工审查。

### 6.2 为什么能减少 LLM 调用？
- 符号回归仓库一次性生成大量候选公式（15–190 个），信息密度远高于 LLM 自举生成的同等数量特征；
- 将“迭代-验证”循环从“LLM 生成→下游评估”变成“符号回归批处理→LLM 一次翻译→下游评估”，LLM 只做最后一步精炼，因此调用次数可压缩到 4 次；
- 在反馈精炼阶段，采用“保留高绩效公式 + 增量优化”策略，避免了盲目重启整个搜索流程。

### 6.3 局限性
- 符号回归受特征维度和样本量限制：当特征数 >50 时，窗口数量仍达数百，gp 训练时间线性增长，论文承认在高维数据（如基因表达）上可能存在效率瓶颈；
- 受保护运算符（如 log(abs(x)) 中的绝对值）虽保证数值稳定，但会掩盖原始数据的符号语义，LLM 翻译时需额外注意；
- 公式仓库中若存在大量等价的变异公式，可能增加 LLM 去冗余的负担；
- 对非线性强、无显式闭式表达的真实关系，符号回归可能失效，此时 LLM 的补充生成依然有限。

## 7. 结论
- SymboLLM-FE 提出了一种“符号回归先挖掘、LLM 后精炼”的两级 AutoFE 范式，兼顾高效、高性能与可解释性。
- 在 6 个 OpenML/Kaggle 数据集 + 4 个 Kaggle 竞赛上的大量实验中，该方法全面优于现有 AutoFE 与 LLM-based 特征工程方法，同时将 LLM 调用减少到单位数，显著降低计算成本。
