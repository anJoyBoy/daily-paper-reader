## 摘要
热力学积分（TI）被广泛用于计算自由能和相图。然而，由机器学习原子间势（MLIP）驱动的TI计算在技术上仍然具有挑战性，因为它们需要为每个相和状态点精心设计可逆积分路径以及许多密切相关的分子动力学（MD）任务。为了应对这些挑战，我们提出了dpti，一个开源的Python包，它可自动化基于MLIP的相图计算的TI工作流。dpti通过可逆积分路径将具有解析已知自由能的参考系统与MLIP描述的原子和分子固体及液体连接起来。给定JSON输入文件，dpti生成并运行所需的MD任务，计算自由能贡献，估计误差，并将共存点传播到相边界。我们通过两个由深度势能模型驱动的示例演示了dpti的用法：涉及β-石英、柯石英和熔体的二氧化硅相图，以及冰Ih-液态水相边界。dpti为通过MLIP建模的材料的自动化相图计算提供了一个有用的工具。

## Abstract
Thermodynamic integration (TI) is a widely used approach for computing free energies and phase diagrams. However, TI calculations driven by machine learning interatomic potentials (MLIPs) remain technically challenging because they require careful design of reversible integration paths and many closely related molecular dynamics (MD) tasks for each phase and state point. To address these challenges, we present dpti, an open-source Python package that automates TI workflows for phase diagram calculations with MLIPs. dpti connects reference systems with analytically known free energies to MLIP-described atomic and molecular solids and liquids through reversible integration paths. Given JSON input files, dpti generates and runs the required MD tasks, computes free energy contributions, estimates errors, and propagates coexistence points into phase boundaries. We demonstrate the usage of dpti with two examples driven by Deep Potential models: a silica phase diagram involving beta-quartz, coesite, and melt, and the ice Ih-liquid water phase boundary. dpti provides a useful tool for automated phase diagram calculations of materials modeled by MLIPs.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 通过**可逆积分路径**连接具有**解析已知自由能的参考系统**（如爱因斯坦晶体、理想气体、分子参考态）与MLIP描述的目标系统。
- 将整个相图计算分解为五个独立阶段，每个阶段可独立运行，最后将相边界组合。
- 关键参数通过JSON文件指定，dpti自动生成LAMMPS输入文件、提交任务（通过DPDispatcher）、收集结果、计算自由能、估计误差，并传播相边界。

### 关键技术细节

- **五阶段工作流**：
  1. **NpT平衡**（Stage 1）：确定相在给定(p₀,T₀)下的平衡密度/晶胞。
  2. **NVT平衡**（Stage 2）：在固定晶胞下平衡构型，为HTI做准备。
  3. **哈密顿量热力学积分（HTI）**（Stage 3）：通过耦合参数λ从参考哈密顿量H₀过渡到目标H₁，计算Helmholtz自由能差ΔA = ∫⟨U₁-U₀⟩_λ dλ，再转化为Gibbs自由能G = A + p⟨V⟩。
  4. **温度/压力热力学积分（TTI/pTI）**（Stage 4）：将Gibbs自由能从锚点状态点传播到其他温度和压力（TTI利用Gibbs-Helmholtz方程，pTI通过体积积分）。
  5. **Gibbs-Duhem积分（GDI）**（Stage 5）：从一个已知共存点出发，利用Clausius-Clapeyron方程沿相边界传播。

- **参考系统设计**：
  - 原子固体：爱因斯坦晶体（Frenkel或Vega公式），添加质心/固定粒子修正。
  - 原子液体：理想气体参考，通过三步HTI（软核LJ打开→目标势能打开→软核LJ关闭）。
  - 水（分子固体）：冰用爱因斯坦晶体+质子无规熵修正；液态水用理想分子参考（O-H键谐波束缚，无角度限制），通过三步HTI（角度+LJ打开→目标势能打开→键+角度+LJ关闭）。

- **积分路径设计**：
  - 原子固体：支持一步、两步、三步路径。推荐三步（先打开辅助LJ，再打开目标势，最后关闭弹簧+LJ），以保持可逆性并避免MLIP在远离目标构型时失效。
  - 液体/水：专门的三步路径。

- **误差估计**：
  - **统计误差**：通过块平均传播到积分结果。
  - **积分误差**：根据曲率估计各区间误差，并**自适应细化**λ网格（通过`refine`命令，将区间误差与容忍度比较，自动插入新点）。

- **一致性检查**：通过在不同温度/压力做HTI，再用TTI/pTI传播，比较两条独立曲线是否一致，验证采样充分性和路径可逆性。

### 公式或算法流程（文字说明）
1. 对每个相，在选定(p₀,T₀)下运行NpT MD获得平均体积。
2. 在平均体积下运行NVT MD获得平衡构型。
3. HTI：在NVT系综下，沿λ网格（如0→1）运行多个MD任务，采集⟨U₁-U₀⟩_λ；用Simpson或梯形法则积分得到ΔA；加上p₀⟨V⟩得G(p₀,T₀)。
4. TTI/pTI：在等压线上沿温度网格运行NpT MD采集⟨H⟩，按Gibbs-Helmholtz积分；或等温下沿压力网格采集⟨V⟩积分。
5. GDI：从共存点出发，对每一步运行两个相的NpT MD，采集⟨H⟩和⟨V⟩，计算dP/dT或dT/dP，用ODE求解器沿相边界推进。

- **体系覆盖有限**：目前仅支持原子固体/液体和分子水，不支持更复杂的分子晶体（如药物晶体）、聚合物、离子液体等。对分子固体的处理（如质子无序）仍需用户手工提供熵修正。
- **路径设计依赖经验**：虽然提供了默认路径，但用户需要针对新体系判断路径是否可逆（例如，是否存在一阶相变或MLIP外推失效），缺乏自动检测机制。
- **未处理混合自由能**：对于取代无序（如Al-Si有序无序）、空位等，dpti不自动计算混合自由能。论文中提及需额外结合簇展开+蒙特卡洛方法（未集成）。
- **MLIP鲁棒性隐忧**：当HTI路径上的中间构型远离训练域时，MLIP可能产生不可靠的力和能量，导致自由能偏差。论文建议路径尽量靠近目标态，但未提供自动保护。
- **有限尺寸误差**：文中提到有限尺寸误差约1 meV/atom（千原子级），但dpti未自动估计该误差。对于高精度相图可能需外推。
- **算力未量化**：论文未报告实际计算成本（GPU时数、总模拟时间等），用户难以预估资源需求。
- **结果依赖底层DFT**：相图精度受限于训练MLIP所用的DFT泛函（如R2SCAN、revPBE-D3），无法判断是MLIP还是DFT的误差占据主导。论文仅归因于DFT，未做系统对比。
