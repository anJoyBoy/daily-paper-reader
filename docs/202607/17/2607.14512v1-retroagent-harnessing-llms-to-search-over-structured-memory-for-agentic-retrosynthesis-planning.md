## 摘要
多步逆合成规划旨在通过一系列可行反应将目标分子分解为市售构建块。巨大的组合搜索空间使得即使对于专业化学家来说，这项任务也极具挑战性。传统方法将树搜索与离线训练的价值网络相结合，这些网络孤立地对候选物进行评分，而不考虑完整多步路线的推理。最近的研究利用大型语言模型（LLM）来完成这项任务，但依赖于限制全面搜索空间探索的简单接口。我们引入了 RetroAgent，这是一个通过带有结构化记忆的框架将符号搜索和神经推理联系起来的 LLM 智能体。通过记忆和化学工具，智能体观察完整的搜索状态，包括已探索的路线、可用的替代方案和中间体的属性，从而能够基于全局进展和领域知识做出明智的决策。在分布内和分布外基准上的实验表明，RetroAgent 具有强大的性能和泛化能力。

## Abstract
Multi-step retrosynthesis planning seeks to decompose a target molecule into commercially available building blocks through a sequence of feasible reactions. The vast combinatorial search space makes this task challenging even for expert chemists. Traditional methods combine tree search with offline-trained value networks that score candidates in isolation, without reasoning about complete multi-step routes. Recent work leverages Large Language Models (LLMs) for this task, but relies on simple interfaces that limit exploration of the full search space. We introduce RetroAgent, an LLM agent that bridges symbolic search and neural reasoning through a harness with structured memory. Through memory and chemistry tools, the agent observes the full search state, including explored routes, available alternatives, and properties of intermediates, enabling informed decisions grounded in both global progress and domain knowledge. Experiments on in-distribution and out-of-distribution benchmarks demonstrate that RetroAgent delivers strong performance and generalization.

## 2. 方法论
**核心思想**：将逆向合成规划建模为一个LLM智能体（Agent）与结构化记忆环境（AND-OR图）交互的序贯决策问题。智能体通过工具调用驱动搜索，环境自动维护图状态（节点状态、前向传播、循环检测），智能体专注于学习搜索策略。

### 关键技术细节：
- **结构化记忆环境**：
  - 搜索树采用 **AND-OR图**：分子节点（OR语义——任一子反应成功即解决），反应节点（AND语义——所有子分子都解决才成功）。
  - 每个节点携带状态 \( \sigma \in \{ \text{Open}, \text{Solved} \} \)。构建块自动标记为Solved。
  - 环境自动执行状态传播（Algorithm 1）：向上传播状态变化，O(d)复杂度。
- **工具接口**（共8个工具）：
  - **记忆工具**（4个）：`predict_templates`（查询单步模型，返回最多20个候选，含构建块标注）、`expand`（应用一个或多个反应，创建新节点）、`get_frontier`（获取当前开放前沿节点）、`inspect_node`（查看节点详情）。
  - **化学工具**（4个）：`get_molecule_info`、`search_building_blocks`、`calculate_synthetic_accessibility`、`calculate_scscore`，提供启发式指导。
- **多扩展设计（Multi-expand）**：允许智能体在一次调用中应用多个候选反应（如“P1,P3,P5”），平衡探索与利用。这是与Retro-R1（每次只选一个）和搜索方法（展开所有）的关键区别。
- **训练与奖励**：
  - 使用 **GSPO**（Group Sequence Policy Optimization）强化学习，无批评家网络。每个批次32个目标×8条轨迹，组内归一化优势。
  - **奖励函数**（式1）：成功+1.0，失败-1.0（纯格式错误-1.5）；加入预算惩罚 \(\delta_N\) 和深度惩罚 \(\delta_D\)（超出20后每单位-0.02，上限-0.3）；工具错误或无效调用每回合-0.05。
  - KL正则化（式5）防止奖励饱和，使用低方差估计器 \(k_3\)。

### 算法流程（Algorithm 1）：
```

  创建反应节点R，添加边(m,R)
```

## 6. 主要结论与发现
1. **性能领先**：在USPTO-190上Pass@1达53.26%（超过Retro-R1的50.00%），在ChEMBL-1000上Pass@1达73.82%（超过Retro-R1的68.52%和所有搜索方法）。分布外泛化能力突出。
2. **RL训练至关重要**：Zero-shot（无RL）Pass@1仅4.42%，表明结构化接口本身不提供性能，必须通过RL学习搜索策略。
3. **多扩展是关键设计**：去除多扩展后Pass@1从53.26%降至40.63%，宽度1.81（成功）vs 1.65（失败）说明智能体学会在关键节点选择性分支。
4. **深度惩罚提升效率**：去除深度惩罚后成功路线常达到最大深度30，浪费预算；加入后找到的路线更短（38.3个目标比参考路线短，优于其他变体）。
5. **学习到的行为**：化学工具使用率迅速降至近零（构建块标注足够）；多扩展使用率从0上升至超70%；搜索树呈广度优先趋势（深度浅、节点多）。
6. **失败模式**：~96%失败因预算耗尽（max_turns或no_progress），而非候选不足或死前哨。

## 7. 优点
- **结构化记忆框架**：环境自动维护图一致性和状态传播，将搜索策略学习与图管理分离，降低LLM推理负担。
- **灵活的多扩展机制**：可在一个工具调用中应用1-n个候选反应，权衡探索与利用，且宽度自适应。
- **可解释的行为分析**：通过工具使用率和搜索树结构可视化，揭示智能体学到的策略（广度优先、预算高效）。
- **泛化能力强**：在ChEMBL-1000（96.2%骨架新颖）上仍超越所有方法，说明策略不依赖记忆训练集模式。
- **模型效率**：使用4B参数模型（小于Retro-R1的7B）达到更优结果，表明接口和训练方法而非模型规模驱动性能。
- **数据效率**：仅用20K训练目标，少于搜索方法使用的全量数据。
- **代码与模型开源**。

## 8. 不足与局限
- **推理成本高**：LLM每次搜索步骤都需推理（数十次调用、数千token），远贵于传统搜索方法（毫秒级评分）。论文认为在合成规划中可接受（一次离线规划数分钟），但高吞吐场景下仍有劣势。
- **化学实用性有限**：路线仅保证模板有效性，未考虑产率、选择性、反应条件、保护基策略等实际因素。虽经专家审查合理，但缺乏系统性实验验证。
- **单步模型依赖**：所有方法共用相同模板基单步模型（MLP），泛化受限于该模型的覆盖率和质量。若单步模型预测偏差，智能体策略可能失效。
- **搜索预算定义差异**：与搜索方法对比时，相同预算下搜索方法展开全部候选（最多50个），而RetroAgent平均只选1.71个，导致搜索方法探索空间更大，因此高预算下PDVN占优。尽管论文指出这一点，但对比仍非完全公平。
- **失败集中于深度目标**：大部分失败由预算耗尽导致，未能解决真正困难的深路径目标。智能体可能倾向于过早放弃深度探索。
- **未与其他最新LLM方法（如AOT*）对比**，仅与Retro-R1比较。
- **训练计算资源需求高**：8×H200 GPU，对学术界可能较高。
