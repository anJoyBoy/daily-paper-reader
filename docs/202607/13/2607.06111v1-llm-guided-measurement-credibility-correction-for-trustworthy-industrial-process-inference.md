## 摘要
工业预测和软测量依赖于可信的输入测量。在现场部署中，预测器可能接收到虽然看似合理但存在偏差、延迟、过时或导出的测量值。此时，在预测主干成为主要限制之前，预测就可能失败，因为输入窗口不再代表真实过程。传感器重构、数据协调和容错软测量可降低此风险，但它们通常依赖于数值相关性、报警、故障标签或显式过程方程。这些假设并非总是可用。当变量共享仪器、导出公式、软测量链或控制动作时，相关变量也可能成为不安全的参考。关键问题是在预测之前判断哪些外部测量能够可信地支持当前测量。为解决此问题，本文提出基于LLM的测量可信度修正（MCC）。MCC将过程文档中的测量含义转换为数值模型可用的测量语义。它从语义合格的外部测量中构建独立的过程参考，并在预测前修正局部测量冲突。因此，预测器获得更可信的输入窗口。在多个复杂工业预测和软测量任务中，+MCC在真实测试协议上实现了平均相对MAE降低30.7%，在受控损坏协议上降低了80.3%。它仅增加了0.5–2.0k在线参数，最慢的+MCC推理时间为0.089毫秒/步。这些结果表明，测量语义可以将过程文档转化为轻量级的预推理可信度修正，并提高预测精度。

## Abstract
Industrial prediction and soft sensing depend on credible input measurements. In field deployment, a predictor may receive biased, delayed, stale, or derived measurements that still look plausible. Prediction can then fail before the forecasting backbone becomes the main limitation, because the input window no longer represents the real process. Sensor reconstruction, data reconciliation, and fault-tolerant soft sensing reduce this risk, but they often rely on numerical correlation, alarms, fault labels, or explicit process equations. These assumptions are not always available. A correlated variable can also be an unsafe reference when variables share instruments, derived formulas, soft-sensing chains, or control actions. The key issue is to decide before prediction which external measurements can credibly support the current measurement. To address this issue, this article proposes LLM-Guided Measurement Credibility Correction (MCC). MCC converts measurement meanings in process documents into measurement semantics usable by numerical models. It builds independent process references from semantically qualified external measurements and corrects local measurement conflicts before prediction. The predictor therefore receives a more credible input window. Across multiple complex industrial forecasting and soft-sensing tasks, +MCC achieves average relative MAE reductions of 30.7% on real-test protocols and 80.3% on controlled-corruption protocols. It adds only 0.5--2.0k online parameters, with the slowest +MCC inference time at 0.089 ms/step. These results show that measurement semantics can turn process documents into lightweight pre-inference credibility correction and improve prediction accuracy.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：利用大语言模型（LLM）将过程文档中的测量含义转换为数值模型可用的测量语义，基于语义合格的外部测量构建独立过程参考，在预测前纠正局部测量冲突。
- **关键技术细节**：
  - **离线阶段**：
    - 利用LLM（如DeepSeek-v4-pro）分析变量文档（变量名、单位、采样周期、测量源、过程描述等），生成每个变量的**测量语义描述**（测量来源、过程角色、控制/观测属性、上下游位置、派生关系等）。
    - 通过固定文本渲染器R和嵌入模型E将语义描述转换为**语义方向向量** `u_i`，堆叠得到冻结的语义矩阵 `U ∈ R^{N×k}`。
  - **在线阶段**：
    - **测量语义参考构建**：对于每个可校正变量 `x_i`，仅使用外部变量（排除自身）及其历史滞后值构建独立参考 `x*_i(t)`。通过学习语义权重矩阵 `Ω_τ` 和路由权重 `α_{ij,τ}`（基于语义兼容性 `c_{ij,τ}=u_i^T Ω_τ u_j`，并应用top-k稀疏归一化）实现。
    - **支持强度与可靠性**：计算外部语义支持强度 `g_i` 和参考可靠性 `η_i`（由干净校准集上的残差中位数得到），得到支持权重 `p_i = g_i η_i`。
    - **局部不一致性检测**：标准化不一致性 `r_i(t) = |\bar{x}_i(t) - \bar{x}^*_i(t)| / s_i`，支持加权后得到 `d_i(t) = p_i r_i(t)`。通过减去背景中位数 `median_{ℓ≠i} d_ℓ(t)` 得到**支持的局部不一致性** `χ_i(t)`，用于区分真实操作变化与局部测量冲突。
    - **校正门控**：利用干净校准集上 `χ_i` 的经验分布 `bF_i`，计算当前不一致性的分位数 `q_i(t)`，当 `q_i(t) > κ`（默认0.95）时，生成校正强度 `a_i(t)`。最终校正输入：`\bar{x}_i^c(t) = (1-η_i a_i(t)) \bar{x}_i(t) + η_i a_i(t) \bar{x}^*_i(t)`。
  - **训练过程**：三步走——①学习观测器参数 `Θ_obs`（最小化参考与测量值的MSE）；②在干净校准集上估计 `s_i, η_i, bF_i`；③训练下游预测器 `G_θ` 使用校正后的窗口 `\bar{W}_t^c` 预测目标。LLM仅离线使用，在线推理无额外LLM调用。

### 3. 实验设计：数据集、基准、对比方法

- **数据集与场景**：三个工业过程数据集，涵盖不同难度的预测和软感知任务。
  - **钢包预热预测（Ladle Preheating）**：14个输入变量，采样间隔5分钟，窗口长度60，预测未来5步钢包温度。测试涉及完整过程留出。
  - **浓密机脱水（Thickener Dewatering）**：5个输入变量，采样间隔1分钟，窗口长度30，估计当前底流浓度。测试包括近域和远域场景，远域涵盖传感器偏差、信号延迟、负载变化等。
  - **IndPenSim青霉素发酵**：23个输入变量，采样间隔12分钟，窗口长度120，估计青霉素浓度。测试包括配方控制、操作员控制、APC控制和故障批次。
  - 每个数据集包含**真实测试（Real Test）** 和**受控污染测试（Corrupted Test）**，污染类型包括偏差、漂移、增益、尖峰、丢失和全局偏移。
- **基准（Baseline）**：直接使用原始测量窗口 `\bar{W}_t` 输入预测器，不进行MCC校正。
- **对比方法**：使用8种常见时序预测骨干网络（Backbone）：GRU、LSTM、Transformer、Informer、Mamba、iTransformer、PatchTST、ModernTCN。每种骨干网络下对比Base（基线）和+MCC（添加MCC校正）。评估指标：MAE、RMSE、R²。

### 7. 优点

- **方法创新**：首次将LLM的语义能力引入工业测量可信度判断，实现了“预推理校正”新范式，克服了纯数值方法的局限性（如无法区分真实过程变化与测量失真）。
- **轻量高效**：LLM离线使用，在线仅需极少量参数和计算，适合工业实时推理。
- **模型无关性**：可与任意时序预测骨干集成，通用性强。
- **保守校正机制**：通过支持权重、背景抑制、校准分布门控，仅在存在可靠外部证据且局部冲突足够罕见时才触发校正，避免误改。
- **实验充分**：覆盖多种工业过程、多种骨干、多种失真类型，并提供详尽的消融、可视化、敏感性分析，论证充分。

### 8. 不足与局限

- **对过程文档的依赖**：MCC需要准确的变量文档（名称、单位、测量源、描述等）。若文档不完整、过时或不一致，测量语义可能不准确，导致参考构建错误。论文指出未来需研究长期语义验证。
- **未考虑测量链随时间变化**：当前方法假设测量语义固定，未考虑传感器更换、控制变更等导致测量关系改变的情况。
- **实验覆盖的局限性**：仅在三个工业过程上验证，涉及冶金、矿物加工、发酵，其他行业（如化工、制药）的通用性尚需验证。受控污染测试为合成失真，实际现场失真模式可能更复杂。
- **离线LLM调用的成本**：虽然在线轻量，但离线使用LLM（DeepSeek-v4-pro等）生成语义描述仍需算力和人工审核，论文未报告离线成本。
- **校准集需求**：需要一段干净无失真的校准数据来估计参考可靠性、名义不一致分布，在工业现场可能不易获得。
- **偏差风险**：若LLM生成的语义存在偏差（如对变量测量方式的错误理解），可能错误选择或排除外部参考，导致校正效果下降。敏感性分析虽显示不同LLM/嵌入模型下性能稳定，但未评估极端错误语义场景。
