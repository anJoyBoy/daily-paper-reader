## 摘要
计算机辅助合成规划利用大量反应规则将目标分子分解为可获取的前体，每条规则赋予每个转化一个确定性的、可解释的标签。然而化学领域具有长尾特性，手动编码难以处理，现有工具依赖固定规则集，无法适应新化学反应。本文提出一种全自动流水线，其中基于大型语言模型的多智能体框架对665,901个美国专利反应进行分类并自动编写规则，每条规则均在验证循环中生成，通过与语料库的对照测试进行验证。该框架将标准分类体系从68类扩展至14,073类，无需人工干预。借助轻量级指纹分类器，它能对97.7%的未知反应进行分类，性能与领先的专有分类器相当，同时能更精细地解析化学反应，并按需扩展到训练分布之外的化学领域。结果形成了一个活的反应性数据库，以及将生成模型转化为可靠、自扩展符号系统的一般途径。

## Abstract
Computer-assisted synthesis planning breaks target molecules into accessible precursors using large libraries of reaction rules that assign each transformation a deterministic, interpretable label. But chemistry is long-tailed, making manual encoding intractable, and existing tools rely on fixed rulesets that cannot adapt to new chemistries. Here we present a fully automated pipeline in which a multi-agent framework of large language models (LLMs) classifies reactions and writes the rules themselves across 665,901 US patent reactions, generating each rule under a verification loop that tests it against the corpus. It expands a standard taxonomy from 68 to 14,073 classes without human curation. With a lightweight fingerprint classifier, it classifies 97.7\% of unseen reactions, matching a leading proprietary classifier while resolving chemistry more finely and extending on demand to chemistry outside its training distribution. The result is a living reactivity database and a general route to turning generative models into reliable, self-expanding symbolic systems.

## 2. 提出的方法论

### 核心思想
- **多智能体 LLM 框架**：将反应分类任务分解为五个专门化 LLM 智能体，每个负责不同子任务，并通过验证循环（Chain-of-Verification）减少幻觉。
- **动态分类体系**：从 68 个种子类（基于 RXNO 本体和 Carey 等分析）出发，通过生成-聚合机制自动扩充分类体系，最终达到 14,073 个类。
- **两阶段推理架构**：
  - **确定性符号层**：由 4,964 个广义 SMIRKS 模板（通过 LLM 自动生成并验证）组成的数据库，采用“第一次匹配获胜”策略，通过图排序消除假阳性。
  - **生成式 LLM 后备层**：当确定性层无法匹配时（未覆盖的反应），调用 LLM 分类并提议新分类条目，以动态扩展分类体系。
- **可验证的规则生成**：每个 SMIRKS 在生成后经过自动验证循环（训练集覆盖检查 + 跨类假阳性测试 + 迭代细化和回滚），确保规则的高精确性。

### 关键技术细节
1. **多智能体分类流水线**（图 1a）：
   - **层次智能体（Hierarchy Agent）**：根据反应 SMILES 和逆合成模板，分配粗粒度两级代码（L1/L2，共 68 类）。
   - **详细智能体（Detailed Agent）**：在 L2 子树内，根据反应物官能团和试剂，分配到最深入的层级（L3-L7），遵循“路径 A（精确匹配）”或“路径 B（附加 .Other）”。
   - **验证智能体（Verifier Agent）**：独立审核分类，区分“正确”、“标准不匹配”、“致命层次错误”三种结果。
   - **生成智能体（Generator Agent）**：当验证失败时，提出新的分类条目（包含代码、名称、层级位置）。
   - **聚合智能体（Aggregator Agent）**：批量去重重叠提议，解决冲突（代码重复但标签不同时标记为冲突），原子更新动态分类体系。
   - **关键设计**：利用模板级分组（最多 5 个反应组成批量）作为正则化，并采用“双阶段上下文”策略——先粗分类再在受限子树上精细分类，以避免全分类体系（>14,000 条目）超出上下文窗口。

2. **SMIRKS 通用化流水线**（图 1b、图 3a）：
   - **类过滤**：每个类至少 5 个训练反应（过滤掉 943 个稀有类）。
   - **少样本提示**：使用最多 10 个模板及工作示例，指导 LLM 遵循 6 条抽象规则（如处理原子映射、合并离去基团、拆分不同反应中心模式）。
   - **验证**：对每个返回的 SMIRKS，应用 RDKit `RunReactants` 测试训练集覆盖 >50%；否则重试 3 次。
   - **跨类假阳性测试**：每个 SMIRKS 对所有其他类的训练反应进行测试，记录假阳性。
   - **迭代优化**：若存在假阳性，重新提示 LLM 收紧约束（如添加环境原子、限制氢计数、环成员等），最多 3 轮，若召回下降 >20% 则回滚。

3. **SMIRKS 数据库排序**（图 3b）：
   - 构建加权有向图：节点为反应类，边 `A→B` 的权重为 A 的 SMIRKS 在 B 类反应上产生假阳性的次数。
   - 分解强连通分量（SCC），对 SCC 进行拓扑排序；在每个 SCC 内部使用贪心启发式（最大出度-入度差）排序。
   - 该排序消除了 95.8% 的假阳性，剩余 4.2% 来自相互依赖的 215 个 SCC。

4. **混合确定性分类器**（ReactionClassifier）：
   - **MDP 门控**：轻量 MLP（512 隐含层，GELU，dropout 0.1），输入 4096 维 Morgan 差异指纹（产品指纹 + 反应物-产品差异指纹），预测深层级类（L3-L5）。该预测仅作为门控，不单独输出。
   - **Hybrid Strict 模式**：MDP 预测后，仅在该类对应的模板子集（44,449 个）中进行模板匹配，只有当某个模板精确匹配时接受标签，否则返回 abstention。
   - **Generalised SMIRKS 模式**：跳过 MDP，直接应用 4,964 个 SMIRKS 的有序数据库进行第一次匹配。

## 6. 主要结论与发现

1. **自动化分类体系扩展的成功**：LLM 多智能体流水线将原始 68 个种子类扩展至 14,073 个类，覆盖 179,495 个代表性反应，通过模板外推得到 665,901 个反应标签。
2. **标签可靠性高**：内部噪声估计显示 LLM 标签噪声率约 0.33%（调整后），与 NameRXN 的 0.59% 相当。专家盲评中 LLM 正确率 82.6%（NameRXN 61.8%），错误率分别为 8.2% 和 7.2%（无显著差异）。
3. **分类准确率强**：Hybrid Strict 模式在频率加权测试集上水平 3 整体准确率 97.9%（覆盖准确率 98.7%），在模板平衡集上 94.1%（97.5%）。OOD 学术数据集上覆盖率达 95.3%（含 LLM 后备），超过 NameRXN（89.3%）。
4. **广义 SMIRKS 的泛化能力**：仅 4,964 个模板即可覆盖 68.3% 的 CRD-2025 反应和 77.3% 的 RingBreaker 反应，优于 Rxn-INSIGHT（6.9% 覆盖 RingBreaker），证明抽象化后模板可跨化学空间应用。
5. **排序优化显著**：假阳性最小化排序将覆盖准确率提升约 10-20 个百分点，相比于随机排序。
6. **LLM 后备有效扩展**：后门处理了约三分之一的 OOD 反应，新增了 135 个新反应类型（如 C-H 官能团化、还原交叉偶联），且这些新类是可识别、有名称的方法，而非随意分组。

## 7. 优点

- **完全自动化**：无需人工干预，从原始 SMILES 到分类体系+规则生成，端到端实现。
- **可验证性**：规则生成强耦合验证循环（假阳性测试+回滚），保证了规则质量。
- **动态可扩展**：分类体系可随新数据增长，不受固定本体限制。
- **确定性+灵活性的平衡**：确定性符号层提供快速、可解释分类；LLM 后备层处理边缘情况，两者互补。
- **细粒度高**：分类深度达到 7 级，分辨出 NameRXN 等无法区分的化学区别（如不同离去基团、试剂条件）。
- **匹配和超越基准性能**：在 OOD 环形成反应上覆盖率超过 NameRXN；专家评估中正确率更高；推理延迟在 ms 级别，与商业工具相当。
- **开源可用**：代码在 GitHub 公开，可复制。

## 8. 不足与局限

- **依赖种子分类体系**：系统需要合理的初始分类树才能开始；若从零开始可能无法可靠工作。
- **数据偏倚**：USPTO 主要覆盖医药专利化学，对有机金属、材料、工艺化学的代表性不足。扩展到电化学、流动化学、生物催化等领域需额外调整。
- **LLM 知识局限**：在罕见学术反应上的分类准确率（66.7%）低于专利反应（90.1%），说明 LLM 预训练知识对非常见化学的覆盖有限。
- **计算成本未量化**：LLM API 调用可能昂贵；SMIRKS 排序阶段 33 亿次模板应用的计算开销大（但可预先完成）。作者未提供总体时间和费用估计。
- **标签噪声估计的局限**：LLM-as-judge 可能存在循环性，尽管作者采取了隔离措施。实验样本量在专家评估中较小（69 反应，3 评委）。
- **未与最新 NameRXN 版本比较**：论文所用 NameRXN 版本为 3.7.0，新版本已包含更多类，可能改变交叉一致性结论。
- **冲突处理策略保守**：代码冲突时直接跳过并标记，未自动解析；部分稀有反应（2.6%）仍无最终标签。
- **回顾性本质**：系统仅组织已有化学，不能前瞻性发现新反应（虽然作者提到初步工作）。
