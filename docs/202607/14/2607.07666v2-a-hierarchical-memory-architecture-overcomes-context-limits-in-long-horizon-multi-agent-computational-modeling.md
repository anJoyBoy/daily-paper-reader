## 摘要
大语言模型展现出卓越的推理能力，但其无状态架构从根本上限制了需要多会话连续性和定量严谨性的长时域研究工作流的部署。这里我们提出Ensemble QSP，一个多智能体框架，具有三层分层记忆架构，通过限制每个状态类别并驱逐已完成的工作，将注入的上下文在项目持续时间内保持有界且恒定（中期项目状态：中位数301 tokens，最大4050 tokens，跨104次运行），从而实现无需上下文退化的连续自主操作。该系统在领域专家首席研究员的指导下协调五个专家工作者智能体，通过基于物理的检查表和结构化领域知识强制执行物理约束。全面的基准测试展示了无需人工干预的稳健自主药代动力学-药效学模型选择，在低成本与前沿LLM上一致的结果质量，相对于单智能体基线的改进PK参数恢复，以及跨同一任务的语言多样化提示的稳定模型选择。跨广泛复杂度的基于生理的药代动力学（PBPK）模型的特征级消融显示，PI智能体监督提高了调试效率，同时保持了各条件下的最终准确性。该架构在结构上领域无关，添加新的科学领域只需新的PI智能体配置。

## Abstract
Large language models (LLMs) demonstrate remarkable reasoning capabilities, yet their stateless architecture fundamentally limits deployment in long-horizon research workflows requiring multi-session continuity and quantitative rigor. Here we present Ensemble QSP, a multi-agent framework featuring a three-layer hierarchical memory architecture that keeps injected context bounded and constant in project duration (mid-term project state: median 301 tokens, max 4,050, across 104 runs) by capping each state category and evicting completed work, enabling continuous autonomous operation without context degradation. The system orchestrates five specialist worker agents under domain-expert principal investigators, enforcing physical constraints through physics-based checklists and structured-domain knowledge. Comprehensive benchmarking demonstrates robust autonomous pharmacokinetic-pharmacodynamic model selection without human intervention, consistent result quality across both lower-cost and frontier LLMs, improved PK parameter recovery relative to single-agent baselines, and stable model selection across linguistically diverse prompts of the same task. Feature-level ablation across physiologically based pharmacokinetic (PBPK) models spanning a broad complexity range shows that PI-agent oversight improves debugging efficiency while preserving final accuracy across conditions. The architecture is structurally domain-agnostic, adding a new scientific domain requires only a new PI agent configuration.

## 一、论文的核心问题与整体含义

- **研究动机**：大语言模型虽具备强大推理能力，但其无状态架构导致在多会话、长周期科学研究工作流中难以维持上下文连续性。真实科研项目需要数周至数月跨会话累积中间结果、遵守领域特定物理约束，而现有LLM多智能体框架（如AutoGen、CrewAI）采用简单拼接会话历史，导致令牌数随项目时长线性增长（O(N×T)），最终引发上下文窗口膨胀和性能退化。
- **核心问题**：如何在长时域多智能体计算建模中保持上下文有界且恒定，实现连续自主操作，同时保证结果质量和物理合理性。
- **整体含义**：提出一种结构领域无关的分层记忆架构，通过有界压缩和驱逐机制绕过上下文长度限制，使低成本模型在充分脚手架支撑下达到与前沿模型相当的任务精度，为自动化科学研究提供可行的工程方案。

## 二、方法论

### 2.1 核心思想：三层分层记忆架构

- **短期层**：每个turn注入的实时工作上下文，包括固定窗口的近期对话轮次（4-20轮）、有上限的工作记忆“草稿板”（≤20,000字符，记录精确事实/文件结构/参数索引）、以及最近5个跨智能体任务结果的滚动缓冲区。
- **中期层**：结构化项目状态JSON，仅注入有界、任务相关的切片：最近5个活跃用户请求（带运行总数）、最近修改的20个文件、最近作业、里程碑、最近3次会话摘要。配合单独的自摘要决策日志（≤16,000字符），记录每步决策原因。
- **长期层**：与项目无关的领域知识，包括约24,000字符的QSP建模手册、每个领域的知识文件和物理检查表、以及代码审查时的源论文文本检索。
- **核心优势**：每层都明确设有上限，已完成的工作被驱逐，使得注入的中期状态令牌数保持恒定（与项目时长无关），中位数仅301 tokens，取代了O(N×T)的增长模式。

### 2.2 关键技术细节

- **双层级智能体架构**：
  - **首席研究员（PI）智能体**（领域专家）：提供战略监督，路由任务，可配置为多个领域（代谢生理、心脏电生理、PKPD）。
  - **五个专家子智能体**：
    - 优化智能体（参数优化和统计）
    - 建模智能体（数学建模和ODE实现）
    - 报告智能体（数据分析和报告撰写）
    - 基础设施智能体（文献搜索和HPC协调）
    - 审查智能体（代码质量审查）
  - 中央协调器负责解析委托、工具执行、结果合成，支持线程池并行执行。
- **领域落地机制**（防止产生物理上不可能的幻觉）：
  - 物理检查表：领域特定的验证协议（心脏钙13条，能量平衡8条，PKPD 8条），在代码审查时自动注入。
  - 领域知识文件：结构化JSON格式，编码模型生理学、单位约定、参数范围、已知陷阱。
  - RAG：从索引项目出版物检索，在PI和审查智能体验证步骤中比较生成方程与源材料。
- **用户请求处理**：通过项目记忆层和PI智能体的标准化抽象，实现语言不变性和提示鲁棒性。

### 2.3 算法流程（文字说明）

1. 用户请求被PI智能体接收，经过标准化和与项目中远期记忆融合。
2. PI智能体根据任务类型、复杂度将请求路由至一个或多个专家子智能体。
3. 专家子智能体使用短期层（对话窗口 + 草稿板）和中期层（结构化项目状态 + 决策日志）执行任务，必要时从长期层检索领域知识。
4. 审查智能体审查代码质量和物理合理性，PI智能体进行最终验证。
5. 结果合成后返回，更新项目状态，完成的工作从短期上下文中驱逐。
6. 支持自主循环：多次迭代直至任务成功或达到失败阈值。

## 六、主要结论与发现

1. **分层记忆架构有效**：中期注入上下文保持恒定（中位数301 tokens），替代O(N×T)增长，实现了跨多月持续自主运行。
2. **MAS vs 单智能体**：MAS在PKPD模型选择上100%准确（20/20），GHCP 70%（需9次人类辅助迭代）；PK参数恢复MAS在10%误差内占比70%（14/20），GHCP 20%。
3. **低成本模型可匹敌前沿模型**：在完整脚手架（PI监督、代码审查、领域知识）支持下，Gemini 2.5 Flash与Claude 4.6 Opus在模型选择和参数恢复上精度无显著差异，成本约减半（$5.14 vs $10.51）。
4. **PI监督价值随复杂度增加**：在低复杂度下组件非决定性；在93 ODE模型下，去除PI监督导致壁钟时间翻倍（28min→60min），因无监督时需更多无效调试。
5. **语言不变性与提示鲁棒性**：9种措辞变体均100%正确模型选择（平均参数误差12.9%）；8种详细度提示中6种匹配变体成功，2种未指定模型类型的提示产生合理的简化模型，无幻觉。
6. **多步推理链自主执行**：GLP-1RA案例中，系统自动完成文献检索、PK模型实现、剂量特定拟合、联合5参数拟合，结果在校准药物效力排序与临床一致。
7. **自主检测物理不一致**：在复现Shah & Betts模型时，系统自动发现公开参数表中肺血浆流量与组织流量不平衡，并施加流量平衡约束。
