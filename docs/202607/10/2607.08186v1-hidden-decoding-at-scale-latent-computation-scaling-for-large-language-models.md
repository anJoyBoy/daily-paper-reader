## 摘要
扩展大语言模型（LLM）主要通过扩大Transformer主干网络来实现，但对于已经很强的模型，这需要另一轮昂贵的预训练。我们研究是否可以在保持Transformer主干网络固定的情况下，通过为每个token分配更多计算来持续改进现有模型。深度循环（环状）Transformer追求这一目标，但难以扩展，因为循环计算与训练最大模型所使用的流水线并行不兼容。我们在序列长度维度上增加计算，其中额外的计算仅仅相当于更长的输入，并且与标准的大模型训练兼容。我们提出隐式解码（Hidden Decoding），一种在持续预训练（CPT）期间应用的序列长度扩展方法。它将每个token扩展为n个流，每个流有独立的嵌入表，并保留中间流的键值缓存作为上下文，这样每个token在不增加或拓宽Transformer层的情况下执行更多的内部计算。为了实现大规模下的可负担性，我们引入了流因子化注意力（Stream-Factorized Attention），其中大多数层只在每个流内部进行注意力计算，只有少数层在流之间进行混合，从而将注意力成本从n的二次方降低到近似线性。实验结果支持两种扩展结果。在前沿规模上，我们在n=4时训练了WeLM-HD4-80B和WeLM-HD4-617B，并改进了它们对应的非HD基线，使隐式解码成为首个在100B+ MoE规模上得到验证的序列长度扩展方法。在不同扩展因子下，随着n的增加，增益也随之增加，表明序列长度扩展是前沿规模LLM的一种实用的固定主干网络扩展路径。

## Abstract
Scaling Large Language Models (LLMs) has been driven mainly by enlarging the Transformer backbone, but for an already-strong model this requires another round of costly pretraining. We study whether an existing backbone can keep improving by allocating more computation to each token while leaving the Transformer backbone fixed. Depth-recurrent (looped) Transformers pursue this goal but are hard to scale, because looped computation does not fit naturally with the pipeline parallelism used to train the largest models. We add computation along the sequence-length dimension, where the extra computation is simply a longer input and stays compatible with standard large-model training. We propose Hidden Decoding, a sequence-length scaling method applied during continued pretraining (CPT). It expands each token into n streams with independent embedding tables and keeps the intermediate streams' key-value cache as context, so each token performs more internal computation without adding or widening Transformer layers. To keep this affordable at scale, we introduce Stream-Factorized Attention, in which most layers attend only within each stream and only a few layers mix across streams, reducing the attention cost from quadratic to roughly linear in n. Experiments support two scaling results. At frontier scale, we train WeLM-HD4-80B and WeLM-HD4-617B at n=4 and improve their matched non-HD baselines, making Hidden Decoding the first demonstrated sequence-length scaling method at the 100B+ MoE scale. Across expansion factors, the gains grow as n increases, showing that sequence-length expansion is a practical fixed-backbone scaling path for frontier-scale LLMs.

- **整体含义**：本文旨在找到一种**工程上可行**的固定骨干扩展方式，能够兼容现代大规模训练栈，从而在已有强模型基础上继续提升能力，而无需重新预训练巨型骨干。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **隐式解码（Hidden Decoding, HD）**：将每个输入token沿序列长度方向扩展为 **n个并行流（streams）**，形成一个长度为 **nL** 的扩展序列，在单次前向传播中处理。每个流的初始表示由独立的嵌入表生成，中间流的Key-Value（KV）缓存被保留下来作为后续位置的上下文。**只有最后一个流（final stream）** 受下一个token预测的交叉熵损失监督，早期流无直接损失，作为潜伏计算状态。

### 关键技术细节
1. **多流Token扩展**：
   - 将标准模型的单个嵌入表替换为n个独立嵌入表 **E₁, E₂, ..., Eₙ**。
   - 对输入序列 **X = (x₁, ..., xₗ)**，扩展为 **S = (E₁(x₁), E₂(x₁), ..., E₁(x₂), E₂(x₂), ...)**，总长度nL。
   - 使用标准的causal attention，RoPE位置连续编号0,1,...,nL-1。
   - 损失函数只对物理位置 **t = i·n**（即每个token的最后流状态）计算下一个token的交叉熵。

2. **流因子化注意力（Stream-Factorized Attention, SFA）**：
   - 为了避免扩展序列上密集注意力带来的 **O(n²L²)** 成本，大部分Transformer层执行**流内注意力（intra-stream）**，只允许同一流内的位置相互关注（成本O(nL²)）。
   - 仅在**少数层**启用**跨流注意力（cross-stream）**，这些层使用模型原有的注意力模式（全局或滑动窗口）。跨流层数量很少，因此注意力总成本接近 **O(n)** 而非 **O(n²)**。
   - 跨流层复用基座模型已有的注意力层（如滑动窗口层），无需新增参数。

3. **渐进式扩展（Progressive Expansion）**：
   - 从较小的n开始（如n=1→2→4→8），每一步从上一个收敛的检查点初始化新嵌入表。采用**循环复制初始化**：从n到2n时，新表复制旧表 (Eₙ₊ₖ ← Eₖ)，使扩展模型最初复制小n行为。
   - 让每个n收敛后再继续扩大，节省计算。

4. **WeLM特有的KV镜像优化**：
   - WeLM架构中有一组“KV mirror”层（U型设计，后三分之一的层镜像前三分之一），在镜像层中，中间流的KV已被早期层固定，且中间流不贡献损失，因此只在镜像层处理**最终流**，跳过中间流，进一步减少计算。

## 7. 优点

- **创新性**：将额外计算放置在序列维度，而非深度维度，从根本上避免了流水线并行的不兼容问题，是首个在100B+ MoE规模上验证的序列长度扩展方法。
- **工程友好**：扩展后的序列直接适配标准训练栈，无需改变Transformer层结构和并行策略。
- **成本可控**：流因子化注意力实现注意力成本近似线性增长，加上WeLM的KV镜像进一步节省计算，使大规模训练成为可能。
- **全面验证**：从前沿模型对比、渐进扩展、消融实验到推理吞吐量、探针分析，提供了多维度证据。
- **设计清晰**：逐流独立嵌入表使不同流学习不同表示，仅监督最终流迫使中间流作为潜计算状态，机制直观。
