## 摘要
表格数据作为机器学习中的核心数据格式，往往由于特征信息不足而缺乏高性能建模所需的判别能力。自动化特征工程（AutoFE）通过自动化特征生成和选择来克服这一问题，确保模型性能和操作效率。然而，传统的AutoFE通常因为依赖盲目的数学变换而产生可解释性较差的特征，而基于大语言模型（LLM）的AutoFE面临挑战，需要昂贵的多轮迭代来生成高效用特征以有效提升模型性能，并且存在固有的偏差和幻觉风险。在本文中，我们将符号回归与LLM相结合用于特征工程（SymboLLM-FE）以解决这些挑战。我们通过符号回归提取与目标强相关的数学表达公式，这些公式可以增强模型性能，然后利用具有丰富先验知识的LLM对其进行优化以确保可解释性。在六个真实世界数据集和四个Kaggle竞赛上的实证结果表明，SymboLLM-FE优于现有的AutoFE。SymboLLM-FE还通过采用基于统计先验的LLM优化机制和个位数次LLM调用，解决了可解释性差和迭代次数多的双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

  - **传统AutoFE**（如AutoFeat、OpenFE）依赖盲目数学变换和穷举/优化搜索，生成的公式缺乏语义，可解释性极差，难以支撑风险敏感场景（如金融因子挖掘、医疗诊断）。
  - **LLM-based AutoFE**（如CAAFE、OcTree、FEBP等）虽能利用LLM语义理解生成可解释特征，但需要大量多轮迭代（如约50轮）才能有效提升模型性能，计算开销巨大；同时LLM固有的幻觉（hallucination）和隐含偏见会导致生成无效或不可靠的特征。
- 论文提出 **SymboLLM-FE**：将符号回归（Symbolic Regression, SR）与LLM结合，先利用符号回归高效挖掘与目标强相关、数学上明确且可提升性能的特征表达式，再让LLM注入领域先验知识进行精炼，使特征兼具高性能与人类可解释性。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
- 分工协作：符号回归负责“发现数学结构与模式”，LLM负责“注入语义与业务逻辑”，下游预测器负责“验证特征效用”。
- 关键转变：将LLM从“开放式特征生成器”重新定位为“受统计先验约束的特征精炼器”，避免幻觉和随机搜索，同时大幅减少迭代次数。

### 整体流程（两阶段协同管线）
- **阶段一：基于符号回归的公式构建（Formula Construction by Symbolic Regression）**
  1. **特征集合采样**：
     - 使用Spearman相关系数对特征进行排序。
     - 设计“扩展-滑动窗口”（expanding-sliding window）策略：
       - 初始窗口大小 k = ⌊n/2⌋；
       - “扩展阶段”：k逐步增至 n；
       - “滑动阶段”：每个固定k下窗口向右滑动，产生不同特征子集。
     - 该策略将候选子集数量从指数级 **O(2ⁿ)** 降为多项式级 **O(n²)**，公式如：偶数n时为 (n+2)(n+4)/8，奇数n时为 (n+3)(n+5)/8。
  2. **公式生成**：
     - 对每个特征子集训练一个符号回归模型（采用gplearn库，遗传编程），生成从该子集到目标的数学公式（如 `add(mul(c1,c2),c3)`）。
     - 最终构建公式库 R = {(Sᵢ, P_f(Sᵢ), τᵢ)}，其中包含特征子集、符号回归在验证集上的性能、公式本身。
- **阶段二：经由LLM的特征生成（Feature Generation via LLMs）**
  1. **LLM引导的代码生成**：将公式库中的公式转换成自然语言描述，与数据集背景信息和代码生成提示（prompt）拼接，利用链式思维（CoT）生成Python/pandas可执行代码。
  2. **下游预测器性能验证**：执行代码生成新特征，合并到原始数据，训练下游模型（TabPFN / CatBoost / XGBoost / MLP）并计算验证集性能。
  3. **迭代特征精炼**：将验证性能、已用特征和生成代码反馈给LLM，进行多轮优化（但论文实际仅需约4次API调用），直到验证性能达到相对最优。
  4. **特征控制与去冗余**：动态删除降低验证性能的特征；通过LLM作为语义过滤器识别数学上等价的特征，移除多重共线性；在符号回归阶段引入“奥卡姆剃刀”惩罚项抑制过拟合；严格将LLM操作限制在统计验证的子空间，抑制幻觉。

### 关键公式
- 优化目标：max P_f(S) = max P_f(C ⊕ C_new)，其中C为原始特征集，C_new为生成的特征集。
- Spearman相关系数公式：ρ_s = cov(rg_X, rg_Y) / (σ_rgX · σ_rgY)，或 ρ_s = 1 − 6Σdᵢ² / (n(n²−1))。

### 数据划分协议
- 训练集：仅用于符号回归的公式构建；
- 验证集：用于LLM特征生成时的性能反馈调参；
- 测试集：仅用于最终评估，严格防止数据泄漏。
