## 摘要
对新材料的探索日益依赖于跨越原子到宏观尺度的预测模型和综合模拟。然而，这些模型和模拟所需的关键数据往往以非结构化文本的形式嵌入在科学文献中，限制了可重用性，并为希望有效利用现有知识的研究人员带来了挑战。尽管使用大语言模型从非结构化文本中提取结构化数据日益流行，传统方法通常生成具有简单模式的键值对数据。相比之下，我们提出 eolas，一个模块化流水线，使用大语言模型将科学文档自动转换为与指定本体对齐的知识图谱。我们展示了 eolas 在为研究旨在承受聚变反应堆中极端温度和辐射水平的材料的科学家提取有用信息方面的有效性。人类专家从一篇文章中提取相关数据可能需要三十到九十分钟，而 eolas 仅需几分钟即可生成高质量的知识图谱。这些知识图谱以表格形式呈现，并带有分面导航，便于人工验证。此外，我们提出了首个基准数据集，旨在评估大语言模型在辐照材料领域构建知识图谱的能力。对使用我们的数据集、多种大语言模型和提示技术开展的 168 项实验进行分析，提供了关键洞见，我们将其总结为有效提取与输入本体对齐的知识图谱的实用指南。

## Abstract
The quest for new materials increasingly relies on predictive models and comprehensive simulations that span scales from atomic to macroscopic levels. However, essential data necessary for these models and simulations are often embedded in scientific literature as unstructured text, limiting reusability and posing challenges for researchers seeking to leverage existing knowledge effectively. While extracting structured data from unstructured text using large language models is gaining popularity, traditional methods typically generate key-value pairs data with straightforward schemas. In contrast, we introduce eolas, a modular pipeline that uses large language models to automatically transform scientific documents into knowledge graphs aligned with a specified ontology. We demonstrate eolas effectiveness in extracting useful information for scientists studying materials designed to endure the extreme temperatures and radiation levels found in fusion reactors. While a human expert might spend between thirty to ninety minutes extracting relevant data from an article, eolas can generate high-quality knowledge graphs in just a few minutes. These are presented in a tabular format with faceted navigation for easy human validation. Additionally, we introduce the first benchmark dataset designed to assess large language models capabilities in constructing knowledge graphs within the domain of irradiated materials. The analysis of 168 experiments using our dataset, various large language models and prompting techniques provides key insights that we summarize into practical guidelines for effectively extracting knowledge graphs aligned with an input ontology.

## 2. 方法论

- **核心思想**：以本体为中心，将文档级知识抽取分解为可配置的模块化步骤，LLM 仅负责从文本片段生成符合本体 schema 的 RDF/Turtle 三元组，再通过语义后处理合并为文档级 KG。
- **本体构建**：
  - 与领域专家协作，经 Protégé 迭代开发；最终含 **14 个类、111 个实例、13 个对象属性、25 个数据属性**。
  - 根节点 `MaterialsEnergetics` 连接所有节点；区分中间节点（如 `DefectsEnergetics`、`MethodologyEnergetics`）与叶节点（属性值）。
  - 支持功能约束（如 `owl:FunctionalProperty`）和实例字典（JSON，经 `rdfs:isDefinedBy` 关联），用于实体消歧。
- **eolas 流水线六步**：
  1. **文档摄取与预处理**：Docling 转换 PDF，Deep Search 构建可搜索集合，支持 OCR，解析句子、段落、表格、标题、图注等。
  2. **过滤**：基于字典标注的 schema 驱动启发式，丢弃无标注或引用类段落，降低 LLM 调用成本。
  3. **标注（可选）**：使用 LLM 标注器或零样本实体识别补充本体覆盖，辅助过滤、幻觉检测与实体匹配。
  4. **合并标注**：去重、消歧，可进一步过滤文本片段。
  5. **知识图谱提取（核心）**：
     - 三种提取器：**TTL Extractor**（Turtle 序列化本体）、**VERB Extractor**（文本化类与关系标签）、**BAML Extractor**（OWL→BAML，LLM 输出 JSON 再转 Turtle）。
     - 可配置：指令简单/详细、序列化格式、是否含实例、是否含少样本示例。
     - 段落级提取优于句子级（初步实验结论）。
  6. **合并启发式（可选）**：
     - 节点标识符合并（RapidFuzz 模糊匹配）。
     - 幻觉检测：数据属性值若在原文中无匹配则标记；未定义关系/类被排除。
     - 四类清理合并：相同属性值对节点合并；同类别子集节点删除；同类别非冲突信息合并；无连接节点按本体关系连接。
- **用户界面**：KG 以表格呈现（列=数据属性，行=实例），支持分面导航、过滤、片段级子图可视化与原文高亮，便于专家验证。
- **Graph-RAG 验证**：用本体与专家定义的 competency questions 构建简化 Graph-RAG，验证结构化 KG 可支持多跳问答。

## 6. 主要结论与发现

- **少样本显著优于零样本**：
  - \(NGED^*=0.1\)：最佳少样本 45.9%（LLAMA_3 + D, TTL + 实例 + 合并） vs 最佳零样本 15.3%，提升约 200%。
  - \(NGED^*=0.2\)：最佳少样本 67.6%（GPT_120，S+BAML+实例+合并 或 S+VERB 无实例） vs 最佳零样本 36.0%（MISTRAL，D+TTL+实例+合并），提升约 87.8%。
- **序列化格式影响**：
  - 严格阈值（0.1）下 TTL 最佳；较高阈值（0.2）下 BAML 在零样本和少样本中均表现更好。
  - VERB 因缺少约束信息，仅在少样本场景有效。
- **指令复杂度**：
  - TTL 下详细指令一致优于简单指令；BAML 下简单指令已足够。
- **实例包含**：总体影响不显著，仅在零样本严格阈值（0.1）下略有帮助；高质量示例的归纳信号强于实例列表。
- **合并启发式**：对零样本严格阈值（≤0.2）和小模型有成本效益；少样本场景下作用减弱。
- **统计检验**：少样本分布显著优于零样本；BAML 在零样本高阈值下显著优于 TTL；指令/序列化在严格阈值 0.1 下差异不显著，阈值 ≥0.2 时差异显著。
- **实用指南**：用零样本+简单指令+BAML+实例+合并生成初始示例，经专家验证后用于少样本；推荐 10–15 个高质量示例 + 详细指令 + TTL；少样本提示优先于实例列表；合并启发式适合简单场景。

## 8. 不足与局限

- **应用限制**：当前主要面向文本型科学文献，表格与图像中的复杂数据提取仍具挑战；本体需专家维护。
