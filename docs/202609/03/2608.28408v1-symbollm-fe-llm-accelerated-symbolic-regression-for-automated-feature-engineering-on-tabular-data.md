## 摘要
表格数据作为机器学习中的核心数据格式，常常因特征信息量不足而缺乏高性能建模所需的判别能力。自动特征工程（AutoFE）通过自动化特征生成与选择克服了这一问题，确保了模型性能与运行效率。然而，传统AutoFE由于依赖盲目的数学变换，往往产生可解释性较差的特征；而基于大语言模型（LLM）的AutoFE则面临需要昂贵的多轮迭代来生成高效用特征以有效提升模型性能的挑战，且存在固有的偏差与幻觉风险。本文中，我们将符号回归与LLM相结合用于特征工程（SymboLLM-FE），以解决上述挑战。我们通过符号回归提取与目标强相关且具有数学表达式的特征，这些特征能够提升模型性能，随后利用具有丰富先验知识的LLM对其进行优化，以确保可解释性。在六个真实世界数据集和四个Kaggle竞赛上的实证结果表明，SymboLLM-FE优于现有AutoFE方法。此外，SymboLLM-FE通过采用基于统计先验的LLM优化机制和个位数次LLM调用，解决了可解释性差与迭代次数多这双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

  - LLM 固有的幻觉与隐含偏见会导致生成语义无效、不公或有偏的特征，损害下游模型可靠性。

基于上述分析，作者提出核心研究问题：**能否设计一种 AutoFE 框架，同时兼顾高性能、可解释性和低迭代成本？**

## 2. 方法论：SymboLLM-FE

### 2.1 核心思想

SymboLLM-FE 采用“**符号回归负责模式发现，LLM 负责语义精炼**”的分工协同范式。关键洞察在于：

- 符号回归能以低计算成本发现与目标强相关的数学表达式——解决**特征有效性**问题；
- 但符号回归生成的公式晦涩难懂、缺乏语义；
- LLM 擅长将不可读的数学公式转化为语义清晰的领域知识表达——解决**可解释性**问题；
- 将 LLM 限定在由统计先验（符号回归公式）锚定的子空间内操作，能杜绝幻觉与无根据的特征生成，从而压缩迭代轮数。

### 2.2 关键算法流程

整个框架遵循严格的数据隔离协议（训练集/验证集/测试集分离），由两个阶段构成：

**阶段一：符号回归的公式构建（Formula Construction）**

1. **Spearman 相关性排序**：计算每个特征与目标的 Spearman 相关系数（ρ_s），按相关系数单调升序排列特征，得到有序序列 C′。选择 Spearman 而非 Pearson 的原因是它对非线性单调依赖更鲁棒。

2. **扩展-滑动窗口特征子集采样**：总特征子集数为 2^n−1（指数级），为将搜索空间降至多项式复杂度：
   - **扩展阶段**：窗口大小 k 从 ⌊n/2⌋ 逐步递增至 n；
   - **滑动阶段**：对每个固定 k，窗口以单特征步长向右滑动生成不同特征子集。
   - 产生的子集总数满足等差级数上界：偶数时 (n+2)(n+4)/8，奇数时 (n+3)(n+5)/8——将搜索空间从 **O(2^n) 降至 O(n²)**。

3. **公式生成**：对每个特征子集 S_i 训练一个符号回归模型（gplearn，遗传编程实现），生成从该子集到目标的显式公式 τ_i，构建公式仓库：
   
   R = {(S_i, P_f(S_i), τ_i)}, i = 1, …, |S|
   
   其中每个三元组包含特征子集、符号回归性能 P 和公式 τ。

**阶段二：LLM 驱动的特征生成（Feature Generation via LLMs）**

1. **LLM 引导代码生成**：将 R 中每个公式 τ 转为自然语言描述，结合数据集背景信息和代码生成提示词，通过链式推理（Chain-of-Thought）使 LLM 生成可执行的 Python/pandas 特征工程代码。

2. **下游预测器性能验证**：执行代码生成新特征 C_new，合并至原数据集形成 C_final，训练下游预测器并评估模型性能。

3. **迭代特征精炼**：将验证集性能、已用特征及对应代码反馈给 LLM，迭代优化直至预测器达到相对最优。特征管理上：动态剪枝验证性能下降的特征，通过 LLM 语义筛选检测特征间的数学等价性以去除多重共线性，并在符号回归阶段施加简洁性惩罚（Occam's razor）抑制过拟合。

### 2.3 关键设计选择

| 设计维度 | 具体机制 |
|---|---|
| 搜索空间管理 | Spearman + 扩展-滑动窗口，O(2ⁿ) → O(n²) |
| 幻觉消除 | LLM 仅作为“精炼器”而非“生成器”，在符号回归验证的子空间内操作 |
| 可解释性提升 | LLM 注入领域先验，将公式转化为带注释、带业务逻辑的可执行代码 |
| 迭代缩减 | 公式直接锚定统计现实，避免盲目的语义搜索，仅需 4 次 API 调用 |

## 7. 方法亮点

- **“分工协同”的架构创新**：将符号回归视为“模式发现器”、LLM 视为“语义精炼器”，从根本上规避了传统方法的黑箱缺陷与 LLM 方法的幻觉风险，方法论设计优雅且自洽。
- **搜索空间降维**：Spearman 引导 + 扩展-滑动窗口将指数级子集搜索降至二次多项式，理论边界有明确的数学推导（式 2），具有可验证的复杂度保证。
- **统计先验锚定 LLM**：将所有 LLM 操作约束在已验证的符号规则子空间内，既保证特征数学有效性，又杜绝了无约束生成带来的幻觉与偏差——这一“grounding”式 LLM 应用思路极具启发价值。
- **LLM 调用次数 O(1)**：与数据维度和样本量解耦，稳定 4 次调用，这相比现有 LLM-based AutoFE 数量级地降低了 API 成本。
- **防泄漏设计**：严格的训练/验证/测试划分，验证集仅用于超参选择，下游模型固定，实验协议严谨。
- **实验报告细致**：附带完整的提示词模板、符号回归算子表、超参数配置，可复现性强。

- **LLM 成本与知识产权**：对闭源商业 LLM（GPT-o1、DeepSeek-R1）存在依赖，涉及 API 费用、数据隐私和不可复现的版本更新风险；若用户使用本地小模型，效果可能大幅下降（表 3 显示 GPT-4 明显弱于 GPT-o1/DeepSeek-R1）。
- **特征冗余控制的隐忧**：尽管声称有 de-redundancy 机制，但平均生成特征数为 70 个，相比基线 OpenFE 的 1436 个已大幅减少，仍可能引入一定维度膨胀；且 LLM 判断特征冗余的主观性较强，可能因模型偏见犯错误删除。
- **统计显著性不全**：表 14 表明在 Credit-g 和 Ailerons 两个数据集上，SymboLLM-FE 相对最佳基线的提升未达到统计显著（p = 0.22、0.95），说明在部分场景下优势并非压倒性。
- **对符号回归质量的强依赖**：符号回归本身可能因超参数、种群大小而收敛到局部最优；若第一阶段的公式质量不佳（如趋势噪声、过拟合），LLM 在精炼阶段没有能力修正底层结构的错误。
