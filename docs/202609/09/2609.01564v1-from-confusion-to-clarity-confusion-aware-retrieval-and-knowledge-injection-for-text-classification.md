## 摘要
大型语言模型（LLMs）在将文本分类为具有许多语义相似标签的分类体系时存在困难，因为这些区分是领域特定的，且未被预训练所捕获。为处理大规模标签空间，一种常见方法是通过嵌入相似性检索前$K$个候选标签，并提示LLM在其中进行选择。然而，top-$K$检索减少了候选数量，但并未帮助模型区分相似标签。当两个相似标签同时作为候选出现时，模型缺乏正确选择所需的信号。我们提出了一个框架，该框架（1）识别模型难以区分的标签对，（2）扩展候选集以纳入易混淆标签，并（3）生成针对性规则以区分相似候选。该框架无需微调，且生成的规则可迁移至更小、更便宜的模型。在三个基准测试（WOS、Flipkart、LEDGAR）上，我们的方法相较于检索基线将Macro F1提升了最多10.0个百分点，较小的模型（2B--20B）通过跨模型迁移获得最多11.5个百分点的提升。

## Abstract
Large language models (LLMs) struggle to classify text into taxonomies with many semantically similar labels, as the distinctions are domain-specific and not captured by pre-training. To handle large label spaces, a common approach retrieves top-$K$ candidate labels by embedding similarity and prompt the LLM to choose among them. However, top-$K$ retrieval reduces the number of candidates but does not help the model tell similar ones apart. When two similar labels both appear as candidates, the model lacks the signal to choose correctly between them. We propose a framework that (1) identifies which label pairs the model struggles to distinguish, (2) expands the candidate set to include confusable labels, and (3) generates targeted rules to differentiate between similar candidates. The framework requires no fine-tuning, and the generated rules transfer to smaller, cheaper models. On three benchmarks (WOS, Flipkart, LEDGAR), our approach improves Macro F1 by up to 10.0pp over retrieval baselines, with smaller models (2B--20B) gaining up to 11.5pp via cross-model transfer.

## 2. 方法论

- **核心思想**：利用分类器自身的错误分析，找出系统性的混淆标签对；检索阶段主动纳入混淆标签，扩大召回；推理阶段向 LLM 注入由大模型离线生成、可跨模型迁移的判别规则。
- **三个阶段/流程**：
  1. **混淆感知检索（Confusion-Aware Retrieval）**：
     - 通过训练集上的 baseline 分类错误构建有向混淆计数。
     - 选择覆盖 ≥75% 训练错误的最少有向标签对集合 $P$。
     - 定义混淆伙伴规则：对每个检索候选标签，将与其互相混淆频率最高的标签一并加入候选集。
     - 目的：提高正确标签出现在候选集中的概率。
  2. **知识生成（Knowledge Generation）**：离线三阶段管线生成成对判别规则：
     - Stage 1（单例推理）：针对每个 misclassified 查询询问 LLM："这条文本中的什么信号表明它属于真实标签而非错误标签？"得到细粒度观察。
     - Stage 2（合并归纳）：把同一 (A→B) 方向上的所有观察蒸馏为一条规则，保留重复出现、可泛化的信号。
     - Stage 3（双向合并）：若 A→B 和 B→A 两个方向的规则均存在，合并成一条对称规则；若只有单向证据则直接保留。
     - 输出为针对每个混淆标签对的知识库 K，每条规则用于注入分类 prompt，指导区分一对候选标签。
  3. **推理（Inference）**：
     - 检索 top-K 候选标签后扩展混淆伙伴，得到扩展候选集合。
     - 筛选出当前候选集中覆盖的判别规则。
     - 将候选标签和规则共同注入 LLM prompt，由 LLM 一次生成最终分类结果。
- **关键特点**：
  - 无需微调模型参数；
  - 离线错误分析只需运行一次；
  - 生成的知识可供任何小模型直接使用。

## 6. 论文的主要结论与发现

- 加混淆伙伴可将候选标签 Recall 提升到高水位（如 Flipkart L3 从 86.0% 升至 98.1%），但会引入更多混淆标签；知识注入则能将由此增加的 LLM 选择失误从 21.9% 降回 17.1%。
- **两个机制互为补充**：前者解决"正确标签不在候选集"问题，后者解决"正确标签在但模型选错"问题，组合可带来稳定收益。
- 主实验（Qwen3-32B）中完整方法每列均取得最佳 Macro F1，最高相对对照基线提升 10.0pp（Flipkart L3 较 retrieval K=20 提升 4.4pp，较 Zero-shot 提升 11.2pp）。
- 知识从大模型 Qwen3-235B 转移至 2B–20B 小模型同样一致有效：小模型最高提升 11.5pp，中模型最高 11.1pp。
- 与 fine-tuning 相比：在干净数据上被 RoBERTa/ModernBERT 反超，但在标签噪声、数据稀缺、测试扰动等生产环境下鲁棒性明显更高。
- 训练误差本身即可告诉模型哪些标签容易混淆，这种"错误引导的知识注入"优于通用的 label description、也无须依赖专门训练的分类模型。
