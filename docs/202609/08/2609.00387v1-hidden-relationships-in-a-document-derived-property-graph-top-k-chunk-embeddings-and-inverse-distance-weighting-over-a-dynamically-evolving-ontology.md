## 摘要
从文本中提取知识图谱的大型语言模型通常只捕获明确陈述的事实，往往使语义相关的实体在文档之间处于断开状态。我们提出了一种附加式的、与引擎无关的第二遍处理方法，在不改变已提取事实的情况下发现这些潜在联系。每篇文档被分块并嵌入一次；对现有分块执行top-k最近邻查询，通过实体成员映射生成候选节点对。使用基于重标定弦距离度量的谢泼德反距离加权对候选对进行打分，避免了k-NN门控后仿射余弦评分导致的阈值坍缩缺陷。非门控的逐对累加器构成交换幺半群，确保流程严格顺序无关，并且无需重新计算先前文档即可增量扩展。在FalkorDB、Kinetica、ArangoDB和Neo4j上的实现表明，与3072维基线相比，我们的方法在768维和240维嵌入下分别保留了92%和72%的边保真度，同时实现了25倍更快的top-k计算。

## Abstract
Large language models extracting knowledge graphs from text capture only explicitly stated facts, often leaving semantically related entities disconnected across documents. We present an additive, engine-neutral second pass that discovers these latent ties without altering extracted facts. Each document is chunked and embedded once; top-k nearest- neighbor queries across existing chunks yield candidate node pairs via entity membership maps. Candidate pairs are scored using Shepard inverse-distance weighting with a rescaled chord distance metric, avoiding the threshold-collapsing flaw of affine cosine scoring behind a k-NN gate. Un-gated per-pair accumulators form a commutative monoid, ensuring the pipeline is strictly order-independent and scales incrementally without recomputing prior documents. Implemented across FalkorDB, Kinetica, ArangoDB, and Neo4j, our method shows that 768- and 240-dimensional embeddings retain 92% and 72% edge fidelity against a 3072-D baseline while achieving a 25x faster top-k formulation.

## 一、核心问题与研究动机

- **背景**：利用大语言模型（LLM）从非结构化文本构建属性图（property graph）已成为常规做法——文档被切分为段落，模型按约束输出模式抽取实体与关系，再折叠进规范化本体。
- **根本问题**：这种抽取方法的“忠实性”同时也是“天花板”。模型只会断言某句话明确陈述的事实；当跨段落、跨文档的关联只隐含在语料中、而不存在于任何单独句子中时，抽取结果就会产生**断裂的连通分量**。论文给出典型例子：描述同一家庭的三段话被正确抽取为两个互不相连的组件（{Gulgun, FSI} 与 {Kaan, Tan, BabelStreet, Bloomberg}），因为没有任何句子直接写出 Gulgun 与 Tan 的联系。
- **论文主张**：可以在不触碰抽取结果的前提下，用**纯加法（purely additive）的第二遍处理**恢复这些隐含联系——新增一种独立边标签 `embedded`，携带权重与支持计数，且绝不修改或删除抽取产生的任何内容，并对自然语言问答路径隐藏，避免把余弦相似度产物误报为抽取事实。

## 二、方法论

### 1. 核心思想
将“寻找隐藏关系”重构成**插值问题**：一个节点对在多个“观测点”（其端点共同出现的分块对）上被观测，每个观测点同时带有相似度值（value）与距离（weight），用 Shepard 反距离加权（IDW）让“近处观测”支配“远处观测”，得到单一分数。

### 2. 七个阶段流程
论文以七个阶段组织：**embed → persist → k-NN → expand → accumulate → select → link**：

- **embed**：文档按段落切分为 chunk（而非固定 token 窗口），每段落用 gemini-embedding-001 嵌入一次，宽度可选 240 或 768 维，写入时做 L2 归一化。
- **persist**：向量以固定宽度存储（`(graph, doc_uri, chunk_index, vec, char_len, preview)`），upsert 幂等。
- **k-NN**：对每个新段落，在整个图的全部段落向量上做**穷尽式自连接 top-k**（不是近似搜索——它是对比而非检索）；查询侧只限新文档，搜索侧为全量。另将同一段落内的共现以 cos=1 的自配对（self-pair）注入。
- **expand**：通过 chunk→实体成员映射 μ 将每个分块对展开为候选节点对（去重、规范化、每分块对至多贡献一次）。
- **accumulate**：每个节点对维护累加器三元组 (Σwv, Σw, support)，按 IDW 公式合并；**持久化时不设门槛（un-gated）**。
- **select**：读出节点对的全历史累加结果，若权重 ≥ θ 且属于任一端点 top-n（并集语义）则通过。
- **link**：通过抽取所用的同一加法缝隙写入 `embedded` 边。

### 3. 核心公式与关键推导
- 距离、权重与价值项定义（对 cos = s）：
  - d = 1 − s
  - w = 1/(ε + d)，ε = 10⁻⁶
  - **v = 1 − √(d/2)**（重标定弦距离）

- 由于向量 L2 归一化：∥a − b∥² = 2(1 − cos) = 2d，因此 w = 1/(ε + ∥a − b∥²/2) 恰好是 **Shepard p = 2** 的反平方距离权重（常数因子 2 在比值中抵消，Proposition 1）。
- 节点对权重：
  - weight({a,b}) = Σ(wₑ·vₑ) / Σwₑ = S_wv / S_w，对所有证据分块对 e 求和。

- **两个关键陷阱（Proposition 2 与 3）**：
  - 在 k-NN 门控（cos ≥ 1 − β，默认 β = 0.35）之后，仿射价值项 v_aff = (1 + cos)/2 = 1 − d/2 被限制在宽度 β/2 的区间内（β=0.35 时为 [0.825, 1]），使写入阈值完全失效（阈值设到 0.825 以下全部放行）。
  - 重标定弦距离 v = 1 − √(d/2) 不塌缩；其导出约束为 **θ > 1 − √(β/2)**，默认 β=0.35 时下限为 0.582，默认阈值取 0.7。
  - 近失方案 Shepard p=1（把 L2 放进权重）也不可取：它把近邻与门边界邻居的影响比从 350× 压到 19×，且不解决 cos=1 尖峰（尖峰由 ε 决定，不是指数决定）。

- **增量与顺序无关性**：累加器三元组在逐分量加法下构成**交换幺半群（commutative monoid）**；因此到达顺序不影响最终权重，新文档只需加法合并，无需重算历史文档。
- 单文档成本为 Θ(cN)（c 为新文档 chunk 数，N 为全库 chunk 数），非 Θ(N²)；超过约 10⁵ 向量后可用 HNSW 索引候选集，候选仍用精确内积打分。
