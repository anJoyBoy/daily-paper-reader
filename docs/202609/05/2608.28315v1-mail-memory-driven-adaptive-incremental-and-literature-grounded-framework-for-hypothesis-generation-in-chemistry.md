## 摘要
化学文献的不断扩展为生成新颖且有影响力的假设提供了前所未有的机遇。然而，瓶颈在于如何高效地浏览这一庞大的知识库，以形成高质量、具有实验意义的见解。尽管大型语言模型（LLMs）在此任务中显示出潜力，但现有方法往往依赖于静态的灵感语料库、预定义的启发式规则，或是繁琐的人机交互流程及决策支持框架，这些限制了可扩展性和新颖性。在本工作中，我们提出了一种自动化方法，即用于化学假设生成的记忆增强、自适应、增量式与文献基础（MAIL）框架。我们的MAIL方法将假设生成表述为一种基于时间、由记忆驱动的推理过程，其中假设源于一条不断演变的概念路径，该路径持续积累并重新解读先前知识。我们在公开的TOMATO-Chem数据集以及一个新整理并发布的高新颖性自然/科学挑战（HN-NS）数据集上评估了MAIL框架。在两个数据集上，MAIL均能生成结构连贯且机制上合理的假设，通过更有效地恢复历史目标假设的核心思想与方法学要素，取得了最高的MIOS和MPOS，并在科学质量方面获得了最高的专家综合评分。这些结果表明，LLMs有潜力自主探索化学领域并生成既创新又具有化学合理性的假设。

## Abstract
The ever-expanding volume of the chemical literature offers unprecedented opportunities to generate novel and impactful hypotheses. However, the bottleneck lies in efficiently navigating this vast knowledge base to formulate high-quality, experimentally meaningful insights.   While Large Language Models (LLMs) show promise for this task, existing methods often rely on static inspiration corpora, predefined heuristics, or laborious human-in-the-loop pipelines and decision-support frameworks that limit scalability and novelty. In this work, we propose an automated approach, a Memory-augmented, Adaptive, Incremental, and Literature-grounded (MAIL) framework for hypothesis generation in chemistry. Our MAIL method formulates hypothesis generation as a temporally grounded, memory-driven reasoning process, where hypotheses emerge from an evolving conceptual path that continuously accumulates and reinterprets prior knowledge. We evaluated the MAIL framework on a public TOMATO-Chem dataset and a newly curated and disseminated high-novelty nature/science challenge (HN-NS) dataset. Across both datasets, MAIL generates structurally coherent and mechanistically plausible hypotheses, achieves the highest MIOS and MPOS by more effectively recovering the central ideas and methodological elements of the historical target hypotheses, and obtains the highest overall expert-evaluation scores for scientific quality. These results demonstrate the potential of LLMs to autonomously explore chemical domains and generate hypotheses that are both innovative and chemically plausible.

## 2. 论文提出的方法论

- **核心思想**：MAIL（Memory-driven, Adaptive, Incremental, and Literature-grounded）将假设生成建模为**时间基础（temporally grounded）的、记忆驱动的推理过程**——假设产生于一条不断演化的概念路径，该路径在多个轮次中持续积累并重新解读先前知识，实现假设的自主迭代演化，全程无需人工干预。
- **三大核心组件**：
  1. **文学启发式检索（Literature-based inspiration retrieval）**：不依赖预定语料库，而是由 LLM 从背景知识中提取高精度、领域特定的关键词 → 构造结构化布尔检索式 → 通过 PubMed、CrossRef、Semantic Scholar 三个 API 执行检索 → 每个轮次以出版物时间区间作为日期过滤器，仅获取时间上先于当前轮的知识 → 检索结果聚合去重后形成候选灵感论文集合 I(t)。
  2. **增量式精炼与自评估（Incremental refinement with self-evaluation）**：t=1 时仅用背景 b 和初始灵感集合 S(1) 生成初始假设 h1；t>1 时，LLM 先按有效性（validity）、新颖性（novelty）、重要性（significance）和潜力（potential）四个维度对 h(t-1) 自动生成结构化反馈 f(t-1)，再利用 b、h(t-1)、f(t-1) 和新一轮检索到的精选灵感 S(t) 联合精炼出新假设 h(t)——既保留上轮优点又引入新见解。
  3. **提示自适应与假设选择（Prompt adaptation and hypothesis selection）**：引入压缩记忆（compressed memory summary），每轮后将先前选出的灵感材料总结成结构化的机制/材料/主题摘要，注入后续提示以维持概念连续性而不压垮输入上下文；最终轮通过目标盲（target-blind）选择提示从 N 条候选轨迹中挑出最优的最终假设。
- **关键公式与流程**（文字说明）：
  - 查询构建：q1 = Q(b)；qt = Q(b, h(t-1), f(t-1))，其中 t ≥ 2。
  - 时间过滤检索：I(t) = Retrieve(qt, Δt)。
  - 灵感选择：S(1) = Sel(I(1)|b)；S(t) = Sel(I(t)|b, h(t-1), f(t-1))。
  - 递归精炼：h1 = G(b, ∅, ∅, S(1))；ht = G(b, h(t-1), f(t-1), S(t))，t ≥ 2。
  - 候选生成与最终选择：运行 N 条独立候选轨迹得到候选集 H(T) = {h(T)j}，最终 h* = A(H(T)|b)。
  - 联合概率建模：P(h(1:T), S(1:T)|b, I) = Π P(S(t)|x(t-1), I(t)) × P(h(t)|x(t-1), S(t))，即检索与灵感选择、假设生成的分解式序列化执行。
- **反馈闭环性质**：MAIL 的反馈回路不由人类评估者参与，而是 LLM 对当前假设的自我评价，基于上下文学习调整生成行为以增强新颖性、机制深度和领域一致性。

## 6. 论文的主要结论与发现

- **MAIL 在两个数据集上的 MIOS 和 MPOS 均全面优于所有基线**。TOMATO-Chem 上 MAIL 达到 Avg MIOS 3.69 / Avg MPOS 2.38、Top MIOS 4.27 / Top MPOS 3.91，显著高于最强基线 MOOSE-Chem（Avg MIOS 3.15 / Avg MPOS 2.14）。HN-NS 上也维持领先优势（Avg MIOS 2.61 / Avg MPOS 2.09 vs MOOSE-Chem 2.23 / 1.88）。
- **消融实验证明四大模块均不可或缺**：移除任一核心组件均造成 MIOS/MPOS 明显下降（尤其去掉提示优化后 Avg MIOS 仅 2.29、去掉上下文感知检索后 2.35），说明迭代精炼、反馈推理、上下文感知检索和提示优化共同支撑了 MAIL 的性能。
- **逐轮精炼带来稳定提升**：图 3 和附录 A 案例展示了从 Round 1 到 Round 3 的 MIOS 与 MPOS 持续攀升（案例中第 1 轮 MIOS=1.30/MPOS=0，最终 MIOS=4.40/MPOS=4.00），说明科学假设确需分阶段累积推理而非单次生成。
- **专家评分上 MAIL 优于 MOOSE-Chem**：TOMATO-Chem 上 MAIL 总分 10.80 vs 10.32（TOMATO-Chem 为两项，表 4 标签疑似重复但正文具体数值为 10.80 vs 10.32；HN-NS 上 MAIL 为 8.63 vs 8.33）；MAIL 在化学合理性、物理可行性、概念新颖性、完整性、科学影响和广泛实用性上占优，MOOSE-Chem 仅在技术新颖性单项更高。
- **MAIL 的改进是模型无关（model-agnostic）的**：在 Qwen2.5、Llama-3.1 全系列上均稳定优于 MOOSE-Chem；模型规模越大假设质量越高，小模型（8B）上 MAIL 的优势会因基础推理能力不足而收窄，但仍保持正增益。
- 整体结论：LLM 在恰当的文献接地和时间感知引导下，能够自主探索化学领域并生成**兼具新颖性和化学合理性的研究假设**，展示了 AI 辅助早期科学发现的潜力。

## 7. 优点

- **方法设计层面**：
  - 完全自动化，消除人工选择的灵感源、启发式分解和手工排序等劳动密集型干预，提升可扩展性。
  - 独特的"时间分片 + 动态多轮检索 + 压缩记忆"融合设计，使每轮检索都受上一轮假设与反馈引导，突破了静态语料库和单次 RAG 的局限。

- **数据与实验层面**：
  - 公开了新发布的 HN-NS 挑战数据集（50 篇 Nature/Science 高新颖论文），属于领域内稀缺资源，填补了高难度假设生成测试集的空白。
  - 刻意选择 2023 年 10 月后的论文作为数据集，规避 LLM 预训练数据泄漏问题，提升评测可信度。
  - 严格去除了检索结果中命中目标论文的记录，防止贴合泄露。
  - 既保留了 MIOS/MPOS 自动指标复用原基准协议，又增加了 7 维双盲专家评审，兼顾了可量化性和科学质量的深层评估。
  - 提供了多维度消融、参数敏感性（K、温度）、底层 LLM 规模泛化、逐轮演化可视化等多角度证据链，实验体系完整。
  - 方法被明确表述为与 RL/GFlowNet 等分子生成方法**互补而非替代**，为后续混合系统留出接口。

## 8. 不足与局限

- **缺乏湿实验验证**：生成的假设未在真实实验室中物理验证，其合理性依赖专家审查和文献接地推断，实际验证仍有待未来工作。
- **计算成本高**：多次轮次、三库实时检索、每执行约 35-40 次 LLM 调用及多候选轨迹并行，API 延迟与调用成本显著高于单次生成方法；且论文未披露确切算力开销数据，增加复现成本评估难度。
- **领域覆盖局限**：评估集中于有机化学和材料化学，框架在高分子、无机、生物化学以及物理、生物学等其他学科的泛化能力尚无证据。
- **评估指标的本质局限**：MIOS/MPOS 在实质上衡量的是对历史目标假设的"恢复程度"，而非对独立生成备选假设原创性的直接测量，可能低估 MAIL 产出非目标但同样有价值的原创想法的能力。
- **自动评估器的潜在偏差**：使用 LLM（GPT-4o）评估 LLM 生成内容可能引入同源偏差，尽管论文声称使用了无方法标识的双盲评分流程做了缓解，但由于所有方法均基于同一底层产生器，相关残留偏差对公平比较的系统性影响难以完全排除。
- **回顾性评价范式限制**：以事后发表的论文作为"参考标准"，可能对未来预测能力验证不足；历史新颖论文的发展路径无法代表所有潜在发现路径。
- **候选数量限制**：每轮 8-10 个候选假设相对于化学假设空间仍非常有限，对高维组合空间的覆盖有限。
- **超参数与实现细节的额外因素**：时间区间划分（pre-2015、2015-2020、2021-2023）、候选数（N）、检索深度、每轮灵感论文数（2 篇）等是人为设定的固定值，论文未全面探讨其联合敏感性或潜在更优配置。
- **双面使用风险**：论文本身承认系统存在潜在滥用风险——模型可能被误用来生成涉及危险化学物质的假设，虽然作者在未来工作中提出了增加安全性过滤方向，但当前版本未实现相应防护机制。
