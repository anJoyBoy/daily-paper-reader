## 摘要
表格数据作为机器学习中的核心数据格式，通常由于特征信息量不足而缺乏高性能建模所需的判别能力。自动特征工程（AutoFE）通过自动化特征生成与选择克服了这一局限，兼顾模型性能与运行效率。然而，传统AutoFE往往因依赖盲目的数学变换而产生可解释性较差的特征，而基于大语言模型（LLM）的AutoFE则面临挑战：需要昂贵的多轮迭代以生成高效用特征来有效提升模型性能，并且存在固有的偏差与幻觉风险。在本文中，我们结合符号回归与LLM进行特征工程（SymboLLM-FE）以解决这些挑战。我们通过符号回归提取与目标强相关且具有数学表达式的特征，以增强模型性能，随后利用具有丰富先验知识的LLM对其进行精炼，确保可解释性。在六个真实世界数据集和四个Kaggle竞赛上的实证结果表明，SymboLLM-FE优于现有AutoFE。SymboLLM-FE还通过采用基于统计先验的LLM精炼机制和个位数次LLM调用，解决了可解释性差与迭代次数多这双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

## 2. 论文提出的方法论：核心思想、关键技术细节、流程

SymboLLM-FE 采用两阶段协作式流水线，核心思想是：**符号回归负责“找形”**（从数据中发现数学结构），**LLM 负责“赋义”**（注入领域语义将其转化为可解释、可执行的特征代码）。具体流程如下：

1. **特征子集采样（Feature Set Sampling）**：
   - 利用 Spearman 相关系数对特征进行排序，衡量各特征与目标之间的单调依赖强度；
   - 设计**扩张滑动窗口（expanding-sliding window）**机制，从窗口大小 ⌊n/2⌋ 开始逐步扩张到 n，并在每个固定窗口大小下向右滑动生成连续特征子集；
   - 将候选特征子集的数量从指数级 O(2ⁿ) 降为多项式级 O(n²)，有效控制搜索空间的规模。
2. **符号回归公式生成（Formula Generating）**：
   - 对每个特征子集分别训练一个符号回归模型（基于 gplearn 遗传编程，函数算子集合包含 14 种算术、三角函数、分段等）生成从特征子集到目标的数学表达式；
   - 建立公式仓库 R = {(Sᵢ, P(Sᵢ), τᵢ)}，每个三元组记录特征子集、符号回归性能以及公式；
   - 使用保护算子（如除法分母为零时返回 1）保证数值稳定，并通过精简压力（parsimony pressure）正则化控制公式复杂度。
3. **LLM 引导的代码生成（LLM-guided Code Generation）**：
   - 将公式仓库中的每个公式转换为自然语言描述，与数据集背景信息和代码生成提示词拼接后输入 LLM；
   - 采用思维链推理，由 LLM 生成可执行的 Python/pandas 特征工程代码。
4. **下游预测器性能验证（Downstream Predictor Performance Validation）**：
   - 执行生成的代码构造新特征，将新特征并入原始数据集，训练下游预测器并评估性能。
5. **迭代精炼（Iterative Feature Refinement）**：
   - 将下游预测器的性能指标、所用特征及相关代码反馈给 LLM，指导其进行代码优化与特征精炼；
   - 通过“生成 → 执行 → 反馈”的自循环持续迭代，直至模型性能相对收敛；
   - 通过动态剪枝（去除降低验证性能的特征）和语义去冗余（识别符号回归公式与已有特征的数学等价性）控制生成特征的预算与冗余度，避免维度灾难和多共线性。

## 7. 优点

- **协同架构有创意**：不强依赖 LLM 直接生成特征，而是让符号回归先做统计挖掘（数学锚点），LLM 只做语义翻译与整合，是一种新颖的混合分工范式。

- **特征控制与去冗余机制完善**：具备动态剪枝、语义去冗余、数学等价性识别、限制 LLM 只处理统计验证子空间等策略，对过拟合与维度灾难有针对性措施。
