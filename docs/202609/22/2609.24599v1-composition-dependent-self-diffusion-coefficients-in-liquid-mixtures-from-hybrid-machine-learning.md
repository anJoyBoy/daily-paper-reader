## 摘要
自扩散系数是描述分子迁移率的关键描述符，但实验数据仍然稀缺，凸显了对可靠预测方法的需求。在先前的工作中，我们引入了混合增强型 Stokes-Einstein（ESE）模型，该模型通过将 Stokes-Einstein 方程与机器学习（ML）相结合，在无限稀释条件下纯溶剂中溶质自扩散系数的物理一致预测方面推进了当前最优水平。在此，我们利用 HADES 将该方法扩展到浓度依赖的自扩散系数和多组分溶剂。这种混合架构利用深度集合神经网络，在单一框架内连接纯组分预测与混合物预测。HADES 可预测任意组分数量、任意组成和温度下液体混合物中的自扩散系数。唯一需要的输入是组分的 SMILES 编码分子结构和纯组分黏度，使该方法具有广泛适用性。在包含 600 个体系、2526 个数据点的综合数据集上训练和评估后，HADES 显著优于基准预测方法。训练好的模型及其源代码完全公开，应用可通过交互式网站 https://ml-prop.mv.rptu.de/ 获取。

## Abstract
Self-diffusion coefficients are key descriptors of molecular mobility, yet experimental data remain scarce, highlighting the need for reliable prediction methods. In previous work, we introduced the hybrid Enhanced Stokes-Einstein (ESE) model, which advanced the state of the art in the physically consistent prediction of self-diffusion coefficients of solutes at infinite dilution in pure solvents by integrating the Stokes-Einstein equation with machine learning (ML). Here, we extend this approach to concentration-dependent self-diffusion coefficients and multicomponent solvents with HADES. This hybrid architecture leverages a deep-set neural network to connect pure-component and mixture prediction within a single framework. HADES predicts self-diffusion coefficients in liquid mixtures with any number of components at any composition and temperature. The only required inputs are SMILES-encoded molecular structures of the components and the pure-component viscosities, making the method broadly applicable. Trained and evaluated on a comprehensive dataset of 2526 data points for 600 systems, HADES significantly outperforms benchmark prediction methods. The trained model and its source code are fully disclosed, and the application is available via an interactive website https://ml-prop.mv.rptu.de/.
